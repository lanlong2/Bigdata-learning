# 学习方法

2026-10-23起按每天90分钟、每周6次、每周9小时安排。先完成大模型应用整条路线，再进入Java整条路线；复习和维护旧成果可以穿插，学习两套新技术不并行推进。

| 范围 | 入口 | 用途 |
|---|---|---|
| 共用方法 | [90分钟学习与工程实践](共用工程/README.md) | 计划、独立实现、排错、周复盘与AI边界 |
| 大模型应用 | [大模型应用方法](大模型应用/README.md) | 先让接口跑通，再做来源核对、评测和失败分析 |
| Java后端 | [Java学习方法](Java/README.md) | 语言基础、业务建模、算法、测试和后端排障 |
| SQL共用基础 | [SQL学习方法](SQL/README.md) | 解释查询口径，核对行数、排序和边界 |
| Python基础历史 | [原阶段方法](Python/README.md) | 保留旧学习方法与背景，当前时间口径以共用方法为准 |

700小时是规划预算：大模型应用175小时、Java后端450小时、额外技术巩固与返修75小时。前两阶段已包含练习、排错和项目，不能重复计时；75小时仍用于学习，不是停学假期。简历、投递、模拟和正式面试另计，算法练习、技术解释和项目排障计入学习预算。

建议用时是安排参考，实际用时按用户提供的事实记录。用户明确说明完成、订正、已学完、掌握或复测通过时，直接更新对应状态；资料创建、助手示例或助手测试不计为用户学习完成。
