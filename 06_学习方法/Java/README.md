# Java后端怎样学

Java是主要就业方向，在整条大模型应用路线完成后集中学习。预算450小时，目标是常规Java后端实习的核心知识、独立实现和技术排障能力；不以覆盖所有框架为目标。

| 模块 | 小时 | 练习重点 |
|---|---:|---|
| J00 Java基础与面向对象 | 95 | 类型、控制流程、方法、类、接口、异常与对象关系；自己写完整小程序 |
| J01 集合、IO、并发与JVM基础 | 55 | 选择合适容器，读写数据，理解线程风险、内存与常见异常 |
| J02 算法、网络与操作系统基础 | 60 | 常用数据结构、复杂度、基本算法；HTTP、进程线程与资源使用 |
| J03 数据库、JDBC、索引与事务 | 45 | 复用SQL基础，从Java访问数据库，核对事务边界与执行计划 |
| J04 Spring Boot与MyBatis | 75 | 请求到SQL的完整调用链，配置、校验、异常、分层与测试 |
| J05 Redis与工程基础 | 20 | 明确缓存用途与一致性边界，掌握必要构建、运行和部署步骤 |
| J06 独立业务项目 | 100 | 完成可解释、可排障、可复现的[工单管理后端](../../05_项目实践/Java/00_工单管理后端/README.md) |
| 合计 | 450 | 练习、排错和项目已包含 |

Java与Python有共通概念，但语法、类型约束和工具链不同。先自己写变量、分支、循环、方法和类，再进入框架；不能从“能运行Spring Boot模板”推断语言基础已掌握。术语、示例、结果和边界应先在对应教材学习。

每天使用[90分钟共用方法](../共用工程/README.md)。基础练习先闭卷写，再用运行结果反馈；保留自己的变量名，核对题目要求的类型、逻辑、结果和排序。读框架示例时，沿请求、参数校验、业务方法、数据库和响应逐层解释。

算法练习优先理解数据结构和复杂度，再独立解少量有代表性的题，解释边界和取舍；不以题库数量为目标。J02集中建立基础后，后续学习单元仍可用短回忆保持，所有用时计入技术预算。

项目先列角色权限与状态转换表，再写代码。数据库操作正确后再讨论优化；学习事务和并发时，明确“失败后哪些修改要一起撤销”“两个请求同时修改会发生什么”。讲解案例见[状态变化与事务](../../08_案例学习/Java/01_状态变化与事务.md)，不要在基础未学时强行实现。

技术解释练习包括“为什么这样设计”“哪里可能失败”“怎样定位”“另一种方案有什么代价”，计入学习预算。简历、投递、模拟和正式面试另计，但不能把Java、数据库和算法知识延后到这些活动中补学。

基础阶段不使用AI代写；复杂项目可部分使用AI，必须能修改、测试并解释关键路径。完成与用时按用户事实记录，后续复习不撤销已经完成的学习记录。
