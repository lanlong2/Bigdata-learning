# SQL · 学习方法

当前统一使用MySQL 8.4 LTS与DBeaver，课程数据库为`sql_learning`；查询前执行`USE sql_learning;`。方法、题目与结果核对标准按同一课程数据执行。

2026-10-23起，SQL是大模型应用和Java后端的共用基础。每天90分钟、每周6次，SQL学习计入A00的35小时预算，Java阶段另按J03学习JDBC、索引和事务的应用；复用已经学会的查询，不重复安排一整轮SQL入门。

1. [每次怎么学](01_每次怎么学.md)：把一个问题写成查询，解释每列与每行的含义。
2. [排错与结果核对](02_排错与结果核对.md)：查连接、字段、过滤、重复与空值。
3. [复习与AI协作](03_复习与AI协作.md)：按实际学习时间复习，保留自己的思路。
