# SQL每次怎么学

每次90分钟，只选一个当前模块的小主题。第一次按教材完成环境与关系表模块，再进入查询练习；仅按实际学习记录推进，不因材料已生成跳过学习。

| 建议用时 | 活动 | 具体做法 |
|---|---|---|
| 10分钟 | 回忆与接续 | 合上教材解释一个概念，查看上次保留的下一步 |
| 20分钟 | 学新知识 | 阅读一节，预测示例结果，再选中该条SQL执行 |
| 40分钟 | 自己写题 | 先写需要的列、数据表、条件和排序，再写SQL |
| 15分钟 | 核对与订正 | 比较结果表的列名、行数、值和顺序，换一个边界条件核对 |
| 5分钟 | 保存 | 保存.sql与学习记录，写下一次第一件事 |

查询前先用一句话说清问题，例如“只统计已付款订单，按商品汇总数量”。先在小样例上手算一两行，再执行SQL，能更快看出条件和统计口径是否一致。

SQL文件放语句与注释，结果解释写Markdown。不要把终端命令、提示符或Markdown反引号复制进查询窗口。一次执行一道题，确认DBeaver连接的是MySQL 8.4 LTS，并先执行`USE sql_learning;`选中课程数据库；切换编辑器或连接后重新确认。
