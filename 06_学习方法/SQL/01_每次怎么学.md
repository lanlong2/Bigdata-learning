# SQL每次怎么学

每次只选一个已学到的小主题，时长可以按当天情况调整。第一次先完成环境与关系表模块，再进入查询练习。

| 建议用时 | 活动 | 具体做法 |
|---|---|---|
| 5分钟 | 回忆 | 合上教材解释一个概念，例如WHERE筛选哪一层数据 |
| 15分钟 | 学新知识 | 阅读一节，预测示例结果，再选中该条SQL执行 |
| 20分钟 | 自己写题 | 先写需要的列、数据表、条件和排序，再写SQL |
| 10分钟 | 核对与订正 | 比较结果表的列名、行数、值和顺序，解释差异 |
| 5分钟 | 保存 | 保存.sql与学习记录，写下一次第一件事 |

查询前先用一句话说清问题，例如“只统计已付款订单，按商品汇总数量”。先在小样例上手算一两行，再执行SQL，能更快看出条件和统计口径是否一致。

SQL文件放语句与注释，结果解释写Markdown。不要把终端命令、提示符或Markdown反引号复制进查询窗口。一次执行一道题，确认连接的数据库和课程schema正确。
