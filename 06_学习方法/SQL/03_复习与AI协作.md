# SQL复习与AI协作

学完一个主题后，合上解析写相似查询；之后换筛选值、排序或分组条件再练。复习间隔从实际学习日期算起，不从教材创建日期算起。只按已学知识选题，不提前要求窗口函数等后续语法。

可以这样向AI求助：

```text
我学到SQL模块____，目前会使用____。
我的环境：MySQL 8.4 LTS＋DBeaver，数据库sql_learning；已执行USE sql_learning;。
题目要求：____。
我的SQL：____。
预期结果：____；实际结果或报错：____。
我尝试过：____。
请先给思路提示，并只使用已学语法。
```

得到解释后说明错误原因，保存自己的订正。日常练习可以逐题核对；阶段测验按卷首规则完成整卷后统一批改，使用过的帮助按题号记录。

你说明完成、订正、已掌握、复测通过或提供实际用时，就直接记录对应事实。额外复习是巩固建议，不把已经完成的内容改回待完成。新建教材、安装配置、AI示例和助手核对与自己的学习分别记录。

SQL错题仍由你指定收录，AI不自动写入04。Git保存步骤可使用[共用Git说明](../../01_学习笔记/Git/README.md)，将示例中的Python文件名换成你实际编辑的SQL文件名。
