# 怎样使用AI和处理卡点

> 2026-10-23用途说明：本页保留Python基础阶段求助方法。当前约定为基础学习不使用AI代写代码；复杂项目阶段可部分使用AI，但必须能解释、修改和验证代码。完整边界见[当前共用方法](../共用工程/README.md)。

## 卡住先按这个顺序

1. 读报错最后一行，找到出错位置。
2. 用 `print(type(value), repr(value))` 看清变量的类型和实际内容。
3. 把问题缩小为几行能复现的代码；一次只改一个原因。
4. 尝试约10～15分钟仍没进展，再带着尝试求助。这个时长可按题目难度调整。

不要为了凑时间一直猜，也不要只复制整段答案。

## 可以直接复制的求助模板

```text
我正在学习：____；已学到：____。
题目要求：____。
我的代码：____。
我希望得到：____；实际输出或完整报错：____。
我尝试过：____。
请先指出思路问题，给一个提示，不直接给完整答案。
```

## 得到帮助后怎么做

- 先说明“原来为什么错”，再修复。
- 合上回答，重新写一次，换一组数据检查。
- 按实际情况记录“借助提示完成”或“独立完成”；完成时直接更新，后续复测另记。
- 不熟悉的复杂写法可以要求换成普通循环和已学知识；不要把短代码误认为更好的学习答案。

## 试卷时的规则

测试自己的掌握情况时，按卷首要求作答；完成整卷后再请AI评分或解释。
如果中途使用了提示，记录提示涉及的题号，成绩标注“有辅助”，不要与独立测验混用。

## Git保存

先保存文件，再查看改动，再提交。完整步骤见[Git说明](../../01_学习笔记/Git/README.md)。
不懂的报错先在对应练习或项目旁写下现象和下一次动作，不必每次都打断整个学习计划。是否写入[疑问清单](../../04_错题与疑问/Python/疑问清单.md)由用户选题决定，助手不自行收录。

## AI如何记录你的学习事实

你说“我完成了”“修正了”“已经学习完毕”“达标了”或说明实际用时，AI直接按事实更新文件，无需你证明，也不加“待验证”的状态。后续复习建议与已经完成的学习记录分别保存。具体约定见[项目AI规则](../../AGENTS.md#ai记录学习事实的规则)。
