## 目标与顺序

目标为Python大模型应用开发实习基础：SQL → Python工程补齐 → HTTP／FastAPI → 模型API及结构化输出 → RAG与评测 → 独立资料问答服务。已有Python基础直接复用，不重新从头学习；完整预算与收尾目标见[阶段路线](../../00_学习计划/大模型应用/阶段路线与验收.md)。

## 项目与阶段收尾

[资料问答服务](../../05_项目实践/大模型应用/00_资料问答服务/README.md)应有完整导入检索回答链路、引用与无答案、固定评测集、异常处理、测试、日志及可复现说明。项目小而完整，能够自己解释、修改和排查问题；训练、微调、复杂Agent和本地模型不列为必修。
