## 开始数据项目还需要做什么

当前已有示例订单CSV、任务书和代码起步模板。第一个项目先使用这份数据，按下面的顺序准备：

1. 读任务书，明确四个字段、校验规则、去重规则以及两个输出文件。
2. 先实现读取并打印原始行，再依次实现单行校验、按编号去重、数量与销售额汇总、CSV/JSON输出。
3. 检查样例、只有表头和单条有效订单；重复运行结果一致。样例应为有效5、重复1、无效5、总数量13、销售额68。
4. 在项目README写运行步骤、规则、结果和已知限制；用Git保存实际成果。

08、09已完成，直接开始项目。遇到转换、路径或CSV/JSON卡点时，可回查教材或选做I01—I06中的对应题。

更详细的启动步骤及后续分析项目准备见[开始数据项目的准备清单](../05_项目实践/开始数据项目的准备清单.md)。本地项目使用已有Python环境与自带库，当前无需新增必需支出。
