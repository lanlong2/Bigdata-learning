# Java后端阶段与下一步

**2026-10-23建立路线，当前尚未开始。** Java为主要就业方向，等大模型应用路线核心成果收尾后进入，不并行开始。主预算450小时，额外巩固从全局75小时总池分配，示例Java60小时；合计属于700小时总计划。

## 开始后按顺序推进

Java基础与面向对象 → 集合／IO／异常／并发／JVM → 算法／网络／操作系统 → 数据库工程／JDBC → Maven／Spring Boot／MyBatis → Redis与工程 → 独立工单管理后端。

从[Java教材入口](../../01_学习笔记/Java/README.md)开始，从零学Java语言，复用已有SQL与共用工程能力；详细范围见[Java阶段路线](../../00_学习计划/Java/阶段路线与验收.md)。目前继续[SQL当前计划](../../00_学习计划/SQL/近期执行计划.md)。

## 阶段目标

目标为常规Java后端实习核心能力准备充分：自己实现业务接口，解释类型、对象、集合、框架行为、SQL与事务，掌握必要算法与计算机基础，能够根据新需求修改并排查问题。

[工单管理后端](../../05_项目实践/Java/00_工单管理后端/README.md)需要独立运行，体现角色权限、状态变化、数据一致性、异常、测试、部署和排错。项目数量不设硬指标，优先业务深度与可靠性；微服务全家桶、复杂分布式和大量中间件不列为必修。

学习所需技术解释与算法包含在预算里，简历、投递、模拟与正式面试另计。700小时是范围规划，不意味着按时学满就保证录用。实际完成与学习用时按你明确说明直接记录；新教材或任务书不标为本人已学完。
