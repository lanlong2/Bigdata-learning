# 容器对比与拓展

原笔记对比内容在这里简化整理。先完成基础，再选读本页。

| 特点 | 字符串str | 列表list | 元组tuple |
|---|---|---|---|
| 装什么 | 文本字符 | 任意对象 | 任意对象 |
| 索引、切片、len | 支持 | 支持 | 支持 |
| 改外层元素 | 不可以 | 可以 | 不可以 |
| in判断 | 连续子串 | 是否有这个元素 | 是否有这个元素 |
| 当字典键 | 可以 | 不可以 | 所有元素可哈希时可以 |
| 典型用途 | 文本清洗 | 可变数据集合 | 固定结构记录 |

## in 与比较

```python
print("ell" in "hello")               # True
print((1, 2) in (1, 2, 3))           # False
print((1, 2) in ((1, 2), (3, 4)))     # True
```

`==`比较内容，`is`比较是否同一个对象。不依赖字符串或整数是否被实现复用，不把一次实验的is结果当成普遍规律。

## 去重和稳定顺序

```python
ordered = sorted(set("banana"))
print(ordered)            # ['a', 'b', 'n']
print("".join(ordered))   # abn
```

set不保证展示顺序；sorted返回列表，要使用返回结果。

## 拓展：zip与星号

```python
points = [(1, 2), (3, 4)]
xs, ys = zip(*points)
print(xs, ys)  # (1, 3) (2, 4)
```

这个示例要求points非空。先会用普通循环分别取x、y，再理解星号拆包。
列表浅复制、元组转换都不等于递归复制。内存和速度随版本、实现与测试方式变化。
