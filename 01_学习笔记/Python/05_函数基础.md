## 1. 为什么要写函数：同一个过程，换一批数据再做

你已经调用过 `len(values)` 和 `sum(values)`：给它们一个列表，它们把长度或总和交回来。自己定义函数，就是给一段处理过程起一个名字。

例如，计算两个数字的和：

```python
def add(a, b):
    result = a + b
    return result

first = add(2, 3)
second = add(10, 4)
print(first)
print(second)
```

输出：

```text
5
14
```

`add` 的处理过程只写了一次，调用时却可以给它不同的数据。它不会记住“这次总是算 2 加 3”。

### 定义这一行怎样读

`def add(a, b):` 拆开来看：

- `def`：告诉 Python“接下来定义一个函数”。
- `add`：这个函数的名字，命名规则与变量相同。
- `(a, b)`：函数接收两个数据，在函数内部暂时叫 `a`、`b`。
- `:`：这一行结束，下面开始函数体。

**函数体**就是属于这个函数的代码。函数体统一缩进四个空格；取消缩进后，就回到函数外面。`return result` 的意思是“把 result 的值交给这次调用，然后结束这次函数执行”。

### 定义与调用不是同一件事

程序执行到 `def` 时，建立函数，供后面使用；此时不会执行函数体。遇到 `add(2, 3)` 才进入函数。

上面的第一次调用按这个顺序执行：

1. 读到 `def`，建立名为 `add` 的函数，继续向下。
2. 执行 `first = add(2, 3)` 的右侧，进入 `add`，内部的 `a` 得到 2，`b` 得到 3。
3. 执行 `result = a + b`，内部 result 得到 5。
4. `return result` 把 5 交回来，离开 add。
5. 现在外面的赋值相当于 `first = 5`，随后继续下一行。

函数要在调用发生前定义好。只写定义而不调用，里面的处理过程不会自行执行。`add` 是函数本身，`add(2, 3)` 才表示调用它。

**就地练习 1：**定义 `subtract(a, b)`，返回前一个数字减后一个数字。分别调用 `(8, 3)` 和 `(0, 4)`，在函数外打印结果。

<details>
<summary>参考与核对输出</summary>

```python
def subtract(a, b):
    return a - b

print(subtract(8, 3))
print(subtract(0, 4))
```

输出依次为 `5`、`-4`。`return a - b` 也可以直接交回计算结果，不必先保存到内部变量。

</details>

## 2. 参数：外面的数据怎样进入函数

**参数**可以先理解为函数处理时需要的数据。这里再区分两个名字：

- **形参**：定义函数时写在括号里的名字，如 `price`、`quantity`。
- **实参**：调用时实际提供的值，如 8、3，或保存这些值的变量。

```python
def total_cost(price, quantity):
    return price * quantity

unit_price = 8
count = 3
cost = total_cost(unit_price, count)
print(cost)
print(total_cost(8, 0))
```

输出：

```text
24
0
```

调用 `total_cost(unit_price, count)` 时，先读取外面两个变量的值，再按位置把 8 交给 price，把 3 交给 quantity。外面的变量不必也叫 price 和 quantity。

这里的输入约定是“单价和数量都是非负整数”。数量 0 是合法边界，计算结果就是 0。函数不会自动把所有输入都转换成你想要的类型：`"8"` 是字符串，8 是整数。数字计算需要按题目约定传入数字。

普通函数的参数数量要与调用匹配。`total_cost(8)` 缺一个参数，`total_cost(8, 3, 2)` 多一个参数，都会产生 `TypeError`。报错时先核对定义括号与调用括号，不要通过随意加参数来猜。

函数也可以没有参数：

```python
def welcome():
    return "开始练习"

print(welcome())
```

输出为 `开始练习`。定义和调用都仍然需要括号。

**就地练习 2：**定义 `score_label(name, score)`，输入姓名字符串和分数整数，返回 `"小林:86"` 这样的文本，中间是英文冒号，没有空格。检查分数为 0 的情况。

<details>
<summary>参考与核对输出</summary>

```python
def score_label(name, score):
    return f"{name}:{score}"

print(score_label("小林", 86))
print(score_label("小周", 0))
```

```text
小林:86
小周:0
```

f-string 会把分数放进文本。也可以使用 `name + ":" + str(score)`；`name + ":" + score` 会把字符串与整数直接相加，产生类型错误。

</details>

## 3. return 与 print：一个交回结果，一个显示结果

`print` 负责把内容显示到终端，供人看。`return` 负责把值交给调用处，供程序继续使用。这两个动作可以分别发生。

```python
def show_sum(a, b):
    print(a + b)

def calculate_sum(a, b):
    return a + b

first = show_sum(2, 3)
print(first)
second = calculate_sum(2, 3)
print(second * 2)
```

输出：

```text
5
None
10
```

追踪这段程序：

1. `show_sum(2, 3)` 内部 print 先显示 5。
2. 它执行到函数末尾，没有 return 一个值，所以调用结果是 `None`，first 接到 None。
3. 外面的 `print(first)` 显示 None。
4. `calculate_sum(2, 3)` 内部不打印，把 5 交给 second；外面可以继续乘 2，得到 10。

**None**表示“这里没有具体结果”。它不是 0，也不是字符串 `"None"`，不能拿它继续当数字计算。`print(...)` 自己的返回值也为 None，所以 `return print(a + b)` 仍不会把和交回来。

### 两种“没有具体返回值”的写法

没写 return，或只写 `return` 而不带值，调用结果都为 None。

```python
def finish_without_return():
    message = "已结束"

def finish_with_empty_return():
    return

print(finish_without_return())
print(finish_with_empty_return())
```

输出是两行 `None`。如果你希望取得 message，应当明确写 `return message`。

### 执行 return 后，当前函数就结束

```python
def label_quantity(quantity):
    if quantity == 0:
        return "没有库存"
    return f"库存：{quantity}件"
    print("这行不会执行")

print(label_quantity(0))
print(label_quantity(3))
print("调用结束")
```

输出：

```text
没有库存
库存：3件
调用结束
```

quantity 为 0 时，第一个 return 就结束本次调用；为 3 时，执行第二个 return。最后一个 print 位于函数内部且在 return 后，无论哪次调用都到不了。真实代码应删掉这种无法执行的语句。

return 只结束当前函数，不会结束整个脚本。外面的 `print("调用结束")` 仍然执行。return 必须写在函数体内，不能在普通脚本最外层使用。

**就地练习 3：**下面这段函数调用后，result 是什么？把函数改为返回清洗后的字符串，保留打印在调用处。


## 4. 输入约定和空数据：先决定特殊情况该交回什么

写函数前先用一句话说明：传入什么类型、正常返回什么、特殊情况如何处理。这样不会把“没有数据”与“数值为 0”混在一起。

**输入约定**就是调用者与函数之间的约定。例如：`scores` 是数字列表；非空返回平均数，空列表返回 None。本模块按约定输入，不要求处理字符串混入数字列表等非法类型。

```python
def average(scores):
    """scores 是数字列表；非空返回平均数，空列表返回 None。"""
    if not scores:
        return None
    return sum(scores) / len(scores)

print(average([60, 80, 100]))
print(average([]))
print(average([0, 0]))
```

输出：

```text
80.0
None
0.0
```

函数内第一行的三引号字符串叫**文档字符串**，用于解释函数怎样使用；它不会自动检查输入类型，也不会自动打印。简单函数也可以先用注释说明，关键是把规则写清楚。

空列表调用按这个过程执行：`if not scores` 为真 → `return None` → 离开函数。因此不会计算 `0 / 0`。非空时，空列表分支不进入，继续求总分除以个数。

`sum([])` 为 0，`len([])` 为 0；所以空列表不能直接求平均。`[0, 0]` 则确实有两个分数，平均分 0.0 是有效结果。

需要区分这两种情况时，用 `is None`：

```python
def average(scores):
    if not scores:
        return None
    return sum(scores) / len(scores)

result = average([0, 0])
if result is None:
    print("没有成绩")
else:
    print(f"平均分：{result:.1f}")
```

输出为 `平均分：0.0`。如果使用 `if not result`，合法的 0.0 也会被当作假值，误判成没有成绩。

### return 在循环里的位置也决定结果

寻找第一个及格分数，需要找到后立刻返回；只有全部找完还没有找到，才返回 None：

```python
def first_pass(scores):
    for score in scores:
        if score >= 60:
            return score
    return None

print(first_pass([40, 70, 90]))
print(first_pass([40, 50]))
print(first_pass([]))
```

```text
70
None
None
```

第一次调用先看 40，再看到 70，return 就离开函数，不再查看 90。最后的 `return None` 与 for 对齐，属于循环结束后的代码。如果把它缩进到循环内，第一项 40 不及格时就提前结束，后面的 70 永远没有机会被检查。

**就地练习 4：**写 `maximum_or_none(values)`。输入数字列表；非空返回最大值，空列表返回 None。检查 `[-5, -2]`、`[0]`、`[]`。

<details>
<summary>参考与核对输出</summary>

```python
def maximum_or_none(values):
    if not values:
        return None
    return max(values)

print(maximum_or_none([-5, -2]))
print(maximum_or_none([0]))
print(maximum_or_none([]))
```

输出依次为 `-2`、`0`、`None`。不应把“最大值从 0 开始”写死，否则全是负数时会得到错误结果。

</details>

## 5. 返回多个信息：实际交回的是一个元组

函数一次调用可以把相关信息打包交回。`return name, score` 等价于 `return (name, score)`，返回的是一个元组。

```python
def parse_record(raw):
    """raw 恰有一个英文逗号，右侧能转整数；返回 (姓名, 分数)。"""
    name_text, score_text = raw.split(",")
    name = name_text.strip()
    score = int(score_text.strip())
    return name, score

record = parse_record(" 小林 , 86 ")
print(record)
print(type(record))
name, score = record
print(name)
print(score + 4)
```

输出：

```text
('小林', 86)
<class 'tuple'>
小林
90
```

执行顺序是：

1. `split(",")` 把字符串分成 `" 小林 "` 与 `" 86 "`，拆给两个变量。
2. 去掉姓名两端空白，把分数字符串转换为整数。
3. return 把姓名和整数装进同一个元组。
4. 外面的 record 保存这个元组；随后 `name, score = record` 再拆开它。

接收时也可以直接写 `name, score = parse_record(...)`。左边有两个变量，要求返回结果正好有两项。

这段函数没有处理 `""`、`"小林,八十"` 或有多个逗号的文本，因为这些输入不符合这里的约定。空数据要不要接受、接受后返回什么，由题目或工具需求决定；不能把所有函数的空输入都统一返回 None。

**就地练习 5：**定义 `count_and_total(values)`，输入数字列表，返回 `(元素个数, 总和)`。`[2, 4, 4]` 应得到 `(3, 10)`，空列表应得到 `(0, 0)`。

<details>
<summary>参考与核对输出</summary>

```python
def count_and_total(values):
    return len(values), sum(values)

print(count_and_total([2, 4, 4]))
print(count_and_total([]))
```

```text
(3, 10)
(0, 0)
```

</details>

## 6. 函数互相调用：先取得里面的结果，再继续外面的处理

一个函数可以调用另一个函数。这叫**嵌套调用**：当前函数暂时把一部分工作交出去，等结果回来后再继续。它不要求把一个 def 写进另一个 def。

```python
def clean_name(raw):
    return raw.strip().lower()

def greeting(raw):
    name = clean_name(raw)
    return "你好，" + name

print(greeting(" Alice Smith \n"))
```

输出：

```text
你好，alice smith
```

追踪时从真正发生的调用开始：

```text
外面调用 greeting(" Alice Smith \n")
    greeting 内部调用 clean_name(raw)
        clean_name 返回 "alice smith"
    greeting 的 name 接到 "alice smith"
    greeting 返回 "你好，alice smith"
外面的 print 显示这句问候
```

`strip()` 只去两端空白，名字中间的空格仍然保留。换成 `replace(" ", "")` 会把内部空格一起删掉，改变了输入规则。

### 把总分、平均分与报告分成三个小工具

```python
def total(scores):
    return sum(scores)

def average(scores):
    if not scores:
        return None
    return total(scores) / len(scores)

def summarize(scores):
    score_sum = total(scores)
    score_average = average(scores)
    return score_sum, score_average

print(summarize([60, 80]))
print(summarize([]))
```

输出：

```text
(140, 70.0)
(0, None)
```

对于 `[60, 80]`：summarize 先调用 total 得到 140，再调用 average；average 又调用 total 得到 140，除以 2 后交回 70.0；summarize 最后交回 `(140, 70.0)`。

对于 `[]`：total 交回 0；average 先识别空列表并交回 None；summarize 交回 `(0, None)`。没有尝试除以 0。

这三个工具没有在内部打印，因此结果既能显示，也能继续计算或放进其他容器。组合时要传递实际收到的数据，不能把内部调用写死为某个样例列表。

**就地练习 6：**定义 `clean_name(raw)` 和 `make_label(raw, score)`。后者必须调用前者，返回 `"alice smith:86"` 这样的标签。检查 `make_label(" Alice Smith ", 86)` 和 `make_label(" BOB ", 0)`。

## 7. 遇到问题，先检查调用与返回路径

看到报错最后一行后，再回到下面这些具体位置：

| 现象 | 优先检查 |
|---|---|
| 写了函数，运行却没有任何处理 | 有没有调用它；是否只写了 def |
| TypeError 提到参数数量 | 定义需要几个实参，调用实际提供几个 |
| 字符串与整数不能相加 | 返回文本时有没有 `str(...)` 或 f-string |
| 屏幕显示正确，变量却是 None | 函数是否只写了 print，没有 return 结果 |
| 某些输入得到 None，另一些有结果 | 是否有分支走到函数末尾但没有 return |
| 只处理了列表第一项 | return 是否误放在循环内部 |
| 空列表出现除以 0 | 是否在计算平均数之前处理空列表 |
| 返回后面的代码不执行 | return 本来就结束本次函数调用；检查代码位置 |
