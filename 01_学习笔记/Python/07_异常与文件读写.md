# 异常与文件读写：让数据进来、处理后能保存

## 对能预料的错误作处理

```python
def parse_count(text):
    try:
        count = int(text)
    except ValueError:
        return None
    if count <= 0:
        return None
    return count

print(parse_count(" 3 "))  # 3
print(parse_count("abc"))  # None
```

这里只处理预期的数字转换错误。不要用一个无差别except把所有程序问题隐藏。
先读报错位置和最后一行；None表示未得到有效数量，不能直接参与加法。

## 路径从当前脚本出发

```python
from pathlib import Path
BASE = Path(__file__).resolve().parent
data_file = BASE / "练习数据" / "names.txt"
output_dir = BASE / "我的输出"
output_dir.mkdir(exist_ok=True)
```

将代码保存到.py文件再运行。路径里的/由pathlib处理，适合Windows；不要手写容易误转义的反斜杠路径。

## 文本：with、模式和编码

```python
with open(data_file, "r", encoding="utf-8") as file:
    names = [line.strip().lower() for line in file if line.strip()]
print(names)

with open(output_dir / "names.txt", "w", encoding="utf-8") as file:
    file.write("\n".join(names))
```

with会在离开代码块时关闭文件。r读取，w覆盖写入，a在末尾追加。
原始题目数据保存在练习数据里，结果写到我的输出；不要把输出路径写成原始数据路径。
encoding="utf-8"用于正确读写中文。

## JSON：保存字典和列表

```python
import json
record = {"姓名": "小林", "分数": [80, 90]}
with open(output_dir / "record.json", "w", encoding="utf-8") as file:
    json.dump(record, file, ensure_ascii=False, indent=2)
with open(output_dir / "record.json", encoding="utf-8") as file:
    restored = json.load(file)
print(restored == record)  # True
```

dump/load面向文件，dumps/loads面向字符串。JSON不能原样保存任意Python对象；本阶段先保存普通字典、列表、数字、字符串、布尔值和None。

## CSV：表格的每一列先是文本

```python
import csv
with open(BASE / "练习数据" / "orders.csv", encoding="utf-8", newline="") as file:
    rows = list(csv.DictReader(file))
print(rows[0]["quantity"])  # 这是字符串，需要int转换后再计算
```

文件必须有与题目一致的表头。CSV写入也用newline=""，以便由csv模块处理换行。
不要用split(",")代替所有CSV解析：字段本身可能包含逗号或引号。

## 保存CSV

```python
clean = [{"product": "pen", "quantity": 2}]
with open(output_dir / "clean.csv", "w", encoding="utf-8", newline="") as file:
    writer = csv.DictWriter(file, fieldnames=["product", "quantity"])
    writer.writeheader()
    writer.writerows(clean)
```

## 自查边界

空文件、只有表头、空字段、非法数字、重复记录、输出路径是否正确。程序能运行不代表结果正确，要与题目要求逐项核对。
