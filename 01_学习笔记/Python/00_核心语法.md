## 1. 顺序与代码块：下一行到底会不会执行

脚本就是保存在 `.py` 文件中的程序。普通语句从上到下执行；后面会学到的判断会选择分支，循环会重复一组代码。

```python
a = 2
print(a)       # 2
a = a + 3
print(a)       # 5
```

第三行使用的是第二行打印之后仍然保存的a，即2。把3加上以后，a重新变成5。

冒号和缩进共同表达代码块。if、elif、else、for、while、def等结构的开头需要冒号；其内部代码统一缩进，建议用4个空格。同一层的语句对齐，不要混用Tab和空格。

```python
score = 50
if score >= 60:
    print("及格")
    print("这行也属于if")
print("检查结束")
```

这里只输出`检查结束`。两行缩进的print属于if条件成立时才执行的代码；最后一行没有缩进，在这个判断结束后执行。

`#`后面到这一行末尾是注释，用来解释代码，不参与执行：

```python
a = 3  # 当前数量
# a = a + 100  这一整行是注释，不会执行
print(a)  # 3
```

三引号主要用于多行字符串；普通代码注释使用#。冒号、括号、引号等代码符号使用英文半角字符，中文可写在字符串和注释中。

## 2. 变量：先计算右边，再把结果交给左边

```python
a = 3
b = a + 2
print(a, b)  # 3 5
a = 10
print(a, b)  # 10 5
```

`b = a + 2`在当时计算出5，随后b保存这个结果。它不会建立“a每次变化，b自动跟着变化”的公式关系。

`=`是赋值，`==`是比较两边是否相等。赋值时先算右侧，再更新左侧：

```python
sum1 = 2
i = 3
sum1 = sum1 + i
print(sum1)  # 5
```

右侧使用旧sum1，即2；`2 + 3`算出5，再把5交给左侧sum1。对这里的整数累计，也可以简写成`sum1 += i`。

初始化、累计、最后使用结果要用同一个名字。你可以选a或sum1；下面这段一致地使用sum1：

```python
sum1 = 0
sum1 = sum1 + 10
sum1 = sum1 + 20
print(sum1)  # 30
```

如果初始化sum1，却写`sum = sum + i`，操作的是另一个名字；sum本来还是Python内置求和函数的名字，可能出现“函数加整数”的TypeError。问题是读写不一致，不是必须换成示例变量名。

初学时可以使用英文字母、数字和下划线命名，不能以数字开头，区分大小写，不能使用if、for等关键字。a、i、sum1、initial_stock都是合法名称。相同名字重新赋值可能改变其类型，每次都要知道它当前是什么。尽量避免把自己的变量叫作 `print`、`int`、`sum` 或 `list`，否则会遮住 Python 提供的同名功能；合法的自选名字不需要改成示例名字。

**先预测：** `a = 4`、`b = a + 1`、`a = 9` 依次执行后，a是9，b是5。自己保存运行验证，再解释为什么b没有变成10。

## 3. 类型：看起来像数字，不一定能计算

| 类型 | 示例 | 常见含义 |
|---|---|---|
| int | `3`、`0`、`-2` | 整数数量、次数、下标 |
| float | `3.5`、`0.0` | 小数、除法结果 |
| str | `"3"`、`"stop"`、`""` | 文本；引号内的数字仍是文本 |
| bool | `True`、`False` | 判断结果，首字母大写 |
| NoneType | `None` | 没有结果或没有数据，需要与0区分 |
| list | `[10, 20]`、`[]` | 一排数据；本页循环部分先使用最简单的列表 |

```python
a = "3"
b = 3
print(type(a))  # <class 'str'>
print(type(b))  # <class 'int'>
print(a + "2") # 32：字符串拼接
print(b + 2)   # 5：整数相加
print("7" * 3) # 777：字符串乘整数，是重复文字三次
# print(a + 2) # 错误示例：TypeError，字符串不能直接与整数相加
```

`None`不是0，也不是字符串`"None"`。例如没有学习记录时平均数可为None；有记录但分钟数都为0时，平均数应为0.0。具体返回什么以题目约定为准。

`type(值)` 用来查看类型。引号只是写代码时标记字符串的边界，`print("3")` 显示时通常不带引号，所以判断类型不能只看输出长得像什么。列表、字符串、元组、字典与集合会在后续模块逐个学习。

本页的判断和循环先需要一点列表知识：`[10, 20, 30]` 把三个元素按顺序放在一起，`[]` 表示空列表；`values[0]` 读取第一个元素，`values[1]` 读取第二个，因为位置从0开始。这种位置编号叫作**下标**或**索引**。空列表没有第0项，直接读取会报IndexError。列表的其他操作将在下一模块展开。

## 4. 输入与转换：input取得的是字符串

```python
raw = input("输入到货数量：")  # 运行时输入7，然后按回车
a = int(raw)
print(type(raw))  # <class 'str'>
print(a + 2)     # 9
```

input括号里的字符串是提示文字。你输入数字7，raw仍是`"7"`；int把它转换成整数7，之后才能作数量累计。

| 转换 | 示例 | 结果 |
|---|---|---|
| int，转整数 | `int("7")` | 整数7 |
| float，转小数 | `float("3.5")` | 小数3.5 |
| str，转文本 | `str(7)` | 字符串`"7"` |

```python
raw = " 7 "
a = int(raw)
print(a)       # 7，整数转换可以接受数字两端的空白
print(str(a))  # 7，显示相似，但这里的值是字符串
# int("stop") # 错误示例：ValueError
# int("3.5")  # 错误示例：ValueError，这不是整数字符串
```

C01保证非stop指令能转int，所以先识别stop，再转换。未来清洗工具会遇到非法数字，需要用[异常处理](09_异常与文件读写.md)跳过坏行。

## 5. 输出：区分计算结果与显示格式

```python
a = 2
b = 1
print(a, b)  # 2 1：多个参数默认用一个空格隔开
print(a, b, sep="|")  # 2|1
print("A", end="|")
print("B")  # 上面两次print合起来显示A|B这一行
```

print默认在每次输出末尾换行。`sep`设置多个参数之间的分隔符；`end`设置这次输出如何结尾。

f-string把变量或表达式放进字符串：

```python
sum1 = 10
box_size = 4
print(f"总库存：{sum1}件")
print(f"每箱容量：{box_size}件")
```

字符串前面要有f，花括号里面的表达式才会被计算。冒号、单位和文字都是你写入的显示内容。

```python
average = 80
print(f"平均分：{average:.1f}")  # 平均分：80.0
print(f"平均分：{77.64:.1f}")    # 平均分：77.6
```

`.1f`表示按固定小数格式显示一位小数。`round(value, 1)`产生舍入后的数值，f-string控制显示形式；它们的用途不同。

如果题目只要三行，优先写三次print。三引号字符串的开头或结尾若额外换行，会增加空白行。更多格式写法见[字符串笔记](02_字符串.md)。

## 6. 运算：整除算箱数，余数算剩余

| 运算符 | 含义 | 示例结果 |
|---|---|---|
| `+` | 加 | `10 + 4`得到14 |
| `-` | 减 | `10 - 4`得到6 |
| `*` | 乘 | `10 * 4`得到40 |
| `/` | 普通除法 | `10 / 4`得到2.5 |
| `//` | 向下取整的除法 | `10 // 4`得到2 |
| `%` | 余数 | `10 % 4`得到2 |
| `**` | 乘方 | `2 ** 3`得到8 |

```python
sum1 = 10
box_size = 4
boxes = sum1 // box_size
remaining = sum1 % box_size
print(boxes, remaining)  # 2 2
print(boxes * box_size + remaining)  # 10
```

10件里可以取走两个完整的4件箱，剩下2件。对非负库存和正箱容量，`整箱数 × 每箱容量 + 剩余 = 总库存`，可用来核对结果。

`//`不是简单去掉小数：例如`-5 // 2`是-3，向下取整。本题使用非负库存，先理解装箱场景即可。

先算括号里的表达式，再按运算优先级计算；容易混淆时加括号：

```python
print(2 + 3 * 4)    # 14
print((2 + 3) * 4)  # 20
```

除数不能为0；空列表平均数计算前要处理没有数据的情况。

## 7. 比较与逻辑：写出你真正想判断的条件

| 表达式 | 含义 |
|---|---|
| `a == b` | 两边内容是否相等 |
| `a != b` | 是否不相等 |
| `a > b`、`a < b` | 大于、小于 |
| `a >= b`、`a <= b` | 大于等于、小于等于，包含边界 |
| `a in values` | a是否在这个容器中；字典默认检查键 |
| `a not in values` | a是否不在其中 |
| `a is None` | 是否为None |

```python
score = 60
print(score > 60)   # False
print(score >= 60)  # True
print(60 <= score <= 79)  # True
print("stop" in ["3", "stop"])  # True
```

题目要求“达到门槛”，一般包含相等，写>=；只写>会漏掉恰好达到门槛的记录。

在布尔条件中，and要求两边都成立，or要求至少一边成立，not把真假反过来：

```python
score = 80
print(score >= 60 and score < 90)  # True
print(score < 0 or score > 100)    # False
print(not (score >= 60))          # False
```

这几个例子参与逻辑运算的是比较结果，所以得到True/False。一般表达式中的and/or会返回其中一个操作数，不保证总是bool；当前先用它们组合明确的条件。

不要把“或”写成`a == "stop" or "quit"`：右侧`"quit"`是一个非空字符串，本身就为真。应分别比较，或判断是否属于指令集合：

```python
a = "go"
print(a == "stop" or a == "quit")  # False
print(a in ["stop", "quit"])        # False
```

**真假值与是否为空。** 对当前常用类型，0、0.0、None、False、空字符串及空容器在条件中为假；非零数字和非空字符串/容器为真。

```python
print(bool(0))       # False
print(bool([]))      # False
print(bool("0"))     # True：这是非空字符串
print(bool("stop"))  # True
print(bool("   "))  # True：空格也是字符
print(bool("   ".strip()))  # False：去空白后变为""
print([] == False)   # False：空列表不等于布尔值False
```

因此`if not rows:`可以判断列表为空；`rows == False`不等价。想只判断没有结果，用`value is None`，不能用`not value`把合法的0一起当成没有结果。

上例的 `.strip()` 是字符串的方法，作用是去掉两端空白并得到新文本；此处只是展示“原文本含空格”与“清洗后为空”的区别，详细用法放在字符串模块。

and/or会短路：and左边为假时不再计算右边，or左边为真时不再计算右边。

```python
rows = []
if rows and rows[0] >= 60:
    print("首项及格")
else:
    print("没有首项，或首项不及格")
```

rows为空，右侧rows[0]不会被读取，因而不越界。

## 8. if/elif/else：多个条件怎样选一个

本节成绩示例约定分数是0—100的整数。

```python
score = 80
if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("待加强")
```

输出`良好`。一整组if/elif/else从上到下判断，选中第一个成立的分支后，跳过后续分支。

这里优先检查高分。走到`elif score >= 80`，已经说明之前的`score >= 90`不成立，所以这一档实际对应80—89。类似地，下一档对应60—79。分数约定为0—100整数时，剩余情况就是0—59。

| 分数 | 选中哪档 |
|---:|---|
| 59 | 待加强 |
| 60、79 | 及格 |
| 80、89 | 良好 |
| 90、100 | 优秀 |

多个独立if会分别判断：

```python
score = 95
if score >= 90:
    print("达到90")
if score >= 80:
    print("达到80")
if score >= 60:
    print("达到60")
```

三行都会输出。需要互斥分档时用if/elif/else；同一条记录可以同时做多件事时，可以使用独立if，例如既累计总分，又把及格姓名加入名单。

条件内还可以有判断，缩进表示所属层级。先把简单分支写清楚，再增加嵌套。

## 9. for、range与下标：重复做同一件事

重复执行一组代码叫作**循环**。先用列表放一排数字：`[10, 20, 30]` 有三个元素，逗号把元素分开；空列表写成 `[]`。`len(values)` 得到列表有多少项，`values[0]` 读取第一个元素，位置从0开始计数。列表的增删改查将在下一模块详细学习。

**遍历**就是依次取出一组数据中的元素。下面的 `for i in values:` 表示“让i依次接收values中的每个元素，对每一个元素执行缩进的代码”：

```python
values = [10, 20, 30]
for i in values:
    print(i)
```

三行依次为10、20、30。i只是你选的变量名，在这里代表元素的值，并不是下标。

range按指定规则产生整数，结束值不包含在内：

```python
print(list(range(3)))          # [0, 1, 2]
print(list(range(1, 4)))       # [1, 2, 3]
print(list(range(2, 7, 2)))    # [2, 4, 6]
print(list(range(3, 0, -1)))   # [3, 2, 1]
```

单个参数表示结束位置，默认从0开始、步长1；两个参数表示起点和终点；三个参数再指定步长。步长不能为0。

要同时使用下标和元素，可以这样写：

```python
values = [10, 20, 30]
for i in range(len(values)):
    print(i, values[i])
```

输出为`0 10`、`1 20`、`2 30`。`range(len(values))` 在这里产生0、1、2三个位置，而 `values[i]` 读取对应位置的值。要直接处理值，优先使用 `for i in values`；确实需要位置时才使用下标写法。后面的元组模块会教同时取得位置和值的 `enumerate` 及拆包，此时不需要提前使用。

for会自动取得下一项；把for里的i加1不等于“让迭代器跳过下一项”，也不会自动修改原列表的元素。while用下标读取列表时，下标推进由自己负责。

不要在遍历同一列表时直接删除它的元素来筛选；可以把需要的值收集到新列表，详见第13节和[列表笔记](01_列表.md)。

## 10. while：每轮先判断，执行后再判断

```python
i = 0
while i < 3:
    print(i)
    i = i + 1
print("结束")
```

输出：

```text
0
1
2
结束
```

while开头的条件每一轮都要重新判断；为真进入循环体，为假离开。它不会因为条件里写了i，就自动替你修改i。

| 判断前的i | i < 3 | 本轮打印 | 本轮结束的i |
|---:|---|---:|---:|
| 0 | True | 0 | 1 |
| 1 | True | 1 | 2 |
| 2 | True | 2 | 3 |
| 3 | False | 不再进入 | — |

写while时先明确三个部分：循环前的初始状态、循环能继续的条件、循环内让状态变化的代码。没有推进，也没有可到达的break时，条件可能一直为真。

当i是非空字符串`"3"`时，`while i:`只是在反复判断这个字符串的真假。如果循环里没重新赋值i，它一直为真；这不是在顺序读取列表。

不要把无穷循环的错误示例直接运行。若程序卡在循环中，可在终端按Ctrl+C中断，再检查条件和推进位置。

<a id="loop-control"></a>

## 11. break、continue、pass：三个不同的执行动作

| 写法 | 当前这一轮 | 后续轮次 | 常见用途 |
|---|---|---|---|
| break | 立即结束 | 结束所在的这一层循环 | 收到stop，停止读取 |
| continue | 跳过这一轮剩余代码 | 回到循环的下一轮流程 | 跳过无效数量 |
| pass | 什么也不做，继续下一句 | 不负责停止或跳过 | 暂时占据语句位置 |

**break结束当前循环：**

```python
commands = ["3", "stop", "100"]
for a in commands:
    if a == "stop":
        break
    print(a)
print("读取结束")
```

输出3和读取结束，100不会被打印。这里用for展示break的作用；C01明确要求while，实现时仍要按题目要求使用while。

**continue只跳过本轮：**

```python
values = [3, 0, -2, 5]
for a in values:
    if a <= 0:
        continue
    print(a)
```

只打印3和5。for负责取得下一项；while里的continue回到条件判断，下标不会因此自动增加。

**pass不跳过后续语句：**

```python
values = [0, 1]
for a in values:
    if a == 0:
        pass
    print(a)
```

0和1都打印。执行pass之后，依然会到达下面的print。

**嵌套循环中的break只退一层：**

```python
for a in ["A", "B"]:
    for i in range(3):
        if i == 1:
            break
        print(a, i)
```

输出`A 0`和`B 0`。内层for结束后，外层for继续处理B。把while放在for里面时，也要同样检查break究竟退出哪一层。

函数里的return则离开当前函数，即使它写在循环里，也不只是退出一轮；详见[函数基础](05_函数基础.md)。

<a id="arrival"></a>

## 12. 完整例子：C01到货指令

把前面学到的知识组合起来：仓库原有2件商品，依次接收到货指令；正数加入库存，0和负数跳过，读到stop停止。每箱装4件，最后打印总库存、整箱数和剩余件数。约定其他指令都是能转换成整数的文本，箱容量为正整数。

```python
commands = ["3", "0", "-2", "5", "stop", "100"]
initial_stock = 2
box_size = 4

sum1 = initial_stock
i = 0

while i < len(commands):
    a = commands[i]
    i = i + 1

    if a == "stop":
        break

    a = int(a)
    if a <= 0:
        continue

    sum1 = sum1 + a

print(f"总库存：{sum1}件")
print(f"整箱：{sum1 // box_size}箱")
print(f"剩余：{sum1 % box_size}件")
```

输出：

```text
总库存：10件
整箱：2箱
剩余：2件
```

这段代码里，i始终表示下标；a先是当前指令字符串，非stop时转换成整数；sum1表示当前库存。

| 读取时的i | a先取得什么 | 下标先增加到 | 操作 | 库存 |
|---:|---|---:|---|---:|
| 0 | "3" | 1 | 转整数，加入3 | 5 |
| 1 | "0" | 2 | 转整数，continue | 5 |
| 2 | "-2" | 3 | 转整数，continue | 5 |
| 3 | "5" | 4 | 转整数，加入5 | 10 |
| 4 | "stop" | 5 | break，离开while | 10 |

顺序是“读取→推进下标→stop则结束→转整数→非正数则跳过→正数累计”。四个位置决定行为：

1. sum1从initial_stock开始，因此原库存不会丢失。
2. i在continue之前推进，跳过0或负数后可以读取下一条。
3. stop判断在int之前，避免尝试转换非数字指令。
4. 三行print在while外面，只输出最终结果。

读到stop时，i虽然变成5，但break已经离开循环，所以不会读取commands[5]的100。读取`commands[i]`不会修改commands。

如果把下标推进只放在累计之后，遇到continue会跳过推进，下一轮可能再次读取同一个0。若下标也会在其他地方更新，还要避免一轮增加两次而漏读。

保留原例，单独换数据核对以下情形；initial_stock仍为2、box_size仍为4：

| 输入commands | 总库存 | 整箱 | 剩余 | 如何结束 |
|---|---:|---:|---:|---|
| `[]` | 2 | 0 | 2 | 0 < 0为假，不进while |
| `["stop", "100"]` | 2 | 0 | 2 | 第一轮break，100未读 |
| `["3", "0", "-2", "5"]` | 10 | 2 | 2 | 下标到4，4 < 4为假 |
| `["0", "-2"]` | 2 | 0 | 2 | 两次continue，下标仍正常推进 |

原题和逐项要求见[综合卷C部分](../../03_阶段试卷/Python_当前所学综合卷/试卷.md)。

## 13. 常用模式：求和、计数、收集分别保存什么

| 目标 | 初始状态 | 每轮更新 |
|---|---|---|
| 求数值总和 | `sum1 = 0`，已有库存则从实际初始值开始 | `sum1 += 当前数量` |
| 数有几条符合要求 | `h = 0` | 符合时`h += 1` |
| 保存符合要求的值 | `a = []` | 符合时`a.append(当前值)` |

**求和是把多个数合成一个数：**

```python
minutes = [20, 0, 40]
sum1 = 0
for i in minutes:
    sum1 = sum1 + i
print(sum1)  # 60
```

**计数只加1，不加当前值：**

```python
minutes = [20, 0, 40]
h = 0
for i in minutes:
    if i >= 20:
        h = h + 1
print(h)  # 2条，不是60分钟
```

**收集结果用新列表：**

`a = []` 建一个空列表，`a.append(i)` 把本轮i加入末尾。这里先用这一种方法收集数据，下一模块再学列表的其他操作。

```python
values = [4, -1, -2, 0, 3, 3]
a = []
for i in values:
    if i >= 0:
        a.append(i)
print(a)       # [4, 0, 3, 3]
print(values)  # [4, -1, -2, 0, 3, 3]，输入未改变
```

初始化放在循环前。若在循环内每轮都写sum1=0，就会反复清空以前累计的结果。

**平均数先处理没有数据：**

```python
scores = []
sum1 = 0
for score in scores:
    sum1 += score
if scores:
    print(f"平均分：{sum1 / len(scores):.1f}")
else:
    print("平均分：无")
```

输出为 `平均分：无`。把scores换成 `[0, 0]` 时应显示 `平均分：0.0`：有记录但都为0，与没有记录不同。空输入不要直接除以len(scores)。本页先按要求打印；后面学函数时再学习怎样返回一个可继续使用的结果。

按不同类别分别累计、保存不重复的主题，需要另外两种容器，后面的[字典与集合](04_字典与集合.md)模块会从头讲。

## 14. 括号与调用：append必须被调用

| 写法 | 这里在做什么 |
|---|---|
| `print(a)` | 调用函数，把a作为参数传入 |
| `a.append(i)` | 调用列表的方法，追加i |
| `a[0]` | 读取a的第0项，不是调用 |
| `[1, 2]` | 创建列表 |

```python
a = []
i = 3
result = a.append(i)
print(a)       # [3]
print(result)  # None
# a.append = i # 错误示例：AttributeError，给append赋值不是追加元素
```

append修改a并返回None。需要的是更新后的列表a，不能把append的返回值重新当列表用。

**函数**可以先理解为按名字使用的一个功能，例如 `len(a)` 求长度；**方法**是附在某个对象上的功能，例如 `a.append(3)`。圆括号表示“现在执行”，括号里的内容叫作参数。返回值就是调用完成后交回来的结果，例如 `len(a)` 交回整数；有些方法只做修改，交回None。下一模块会仔细比较这些方法。

`a.append` 只取得这个方法，`a.append(3)` 才真正把3加入列表。自己定义函数、把函数作为参数传入，分别放在[函数基础](05_函数基础.md)和[函数进阶](06_函数进阶.md)学习。

## 15. match/case：按固定指令选择操作，选读

match/case从Python 3.10开始支持，当前Python 3.12可运行。这里先用字符串常量匹配，不展开复杂模式。

```python
code = "buy"
quantity = 7
match code:
    case "buy":
        print(quantity * 4)
    case "sell":
        print(quantity * 3)
    case _:
        print("未知指令")
```

输出28。match查看code，按case顺序选择第一个匹配分支；`case _`接住其他情况，放在最后。这里匹配一个分支后不会继续执行后面的case，不需要用break结束case。

固定命令可用match表达；成绩区间和门槛判断继续使用if/elif/else。当前先掌握前面的判断和循环，再看本节。

## 16. 排查：沿执行过程找问题

先看报错的最后一行是什么，再回到指出的代码行。常见类型及本阶段对应情况：

| 报错 | 常见原因 |
|---|---|
| SyntaxError | 冒号、括号、引号或语句结构写错 |
| IndentationError | 缩进层级不合法 |
| NameError | 读取了还没定义的名字 |
| TypeError | 字符串加整数、整数加列表等类型不匹配 |
| ValueError | int("abc")等转换失败，或普通拆包数量不匹配 |
| IndexError | 读取列表/字符串不存在的下标 |
| KeyError | 读取字典不存在的键 |
| AttributeError | 对象没有该方法，或试图给列表append属性赋值 |
| ZeroDivisionError | 除数为0，包括空列表直接求平均 |

程序没有报错也可能算错或一直循环。追踪while时，记录每轮“下标→当前值→采取的分支→更新后的库存”；遇到continue和break，明确接下来跳到哪里。核对输入是否改变、初始化是否反复清空、打印是否在正确缩进层级。

局部的print可以帮助观察下标和值；提交时按题目规定输出，工具函数需要return结果时，将演示打印放在调用处。
