# 字符串：读取文本，拆分、清洗，再得到需要的结果

**开始前需要会：**[核心语法](00_核心语法.md)和[列表](01_列表.md)。这一模块会用到索引、切片、循环、列表收集与推导式，不需要先会元组、字典或自己定义函数。

**学完后你应该能：**区分文本与数字，读取文本的一部分，判断和查找内容，按步骤清洗数据，用 `split` 和 `join` 在字符串与列表之间转换，并把变量排成易读的输出。

请按顺序读。每个 Python 代码块都能单独运行；预期报错的行先注释起来。先预测，再运行，不要只看输出。

## 1. 字符串保存的是文本

字符串的类型名是 `str`，可以保存文字、数字字符、标点和空白。**引号内的 `"18"` 是文本，整数 `18` 才能直接参与数值计算。**

```python
text = "18"
number = 18
empty = ""

print(type(text))
print(type(number))
print(text + "1")
print(number + 1)
print(len(empty))
```

输出：

```text
<class 'str'>
<class 'int'>
181
19
0
```

字符串的 `+` 是拼接，数字的 `+` 是相加。`text + 1` 把字符串和整数相加，会报 `TypeError`。要拼接年龄，可以先用 `str(18)` 得到文本。

单引号和双引号都可以创建字符串，里面需要哪种引号，外面可以换另一种：

```python
message = '他说："你好"'
print(message)
print("哈" * 3)
```

输出：

```text
他说："你好"
哈哈哈
```

`* 3` 是重复三次。字符串的 `+` 和 `*` 都得到处理后的结果，不改变原字符串。

### 换行、制表符与反斜杠

**转义**是用反斜杠开头的写法表示特殊字符。例如 `\n` 在字符串里表示一个换行，不是字母 n。

```python
print("第一行\n第二行")
print("他说：\"你好\"")
path = r"C:\Users\data"
print(path)
```

输出：

```text
第一行
第二行
他说："你好"
C:\Users\data
```

| 写法 | 字符串中的含义 |
|---|---|
| `\n` | 换行 |
| `\t` | 制表符，显示宽度由终端决定 |
| `\\` | 一个反斜杠 |
| `\"`、`\'` | 引号本身 |

字符串前面加 `r` 是原始字符串写法，让反斜杠通常按原样保存，适合写路径。它仍然需要正确的结束引号，不能以奇数个反斜杠紧挨结束引号；例如想表示末尾反斜杠时，可用普通字符串的 `"C:\\data\\"`。

三引号可以保存跨行文本：

```python
notice = """今天学字符串
明天做练习"""
print(notice)
```

输出是两行文本。三引号创建的仍是字符串，不是普通注释；写注释用 `#`。

## 2. 索引、切片与长度

字符串和列表一样有顺序，索引从 0 开始，负索引从末尾数。

```python
s = "Python"
print(s[0])
print(s[-1])
print(s[1:4])
print(s[:3])
print(s[::2])
print(s[::-1])
print(len(s))
print(type(s[0]))
```

输出：

```text
P
n
yth
Pyt
Pto
nohtyP
6
<class 'str'>
```

`s[1:4]` 取索引 1、2、3，不取 4，和列表切片规则相同。**取一个字符的结果仍是字符串**，Python 没有单独的字符类型。

`s[6]` 会报 `IndexError`，而 `s[:100]` 会取到现有末尾，得到 `"Python"`。空字符串没有可读取的索引，但可以切片，`""[:3]` 仍是 `""`。

`len` 统计的是字符串中保存的字符数量，不是终端占几格。普通中文一个字通常计一个字符；某些表情和组合文字可能由多个字符组成，不必把屏幕宽度和 `len` 当成同一个概念。

**小练习 1：**对于 `text = "Data2026"`，打印前 4 个字符、后 4 个字符和反向文本，再判断它是否正着反着一样。

<details>
<summary>参考写法与输出</summary>

```python
text = "Data2026"
print(text[:4])
print(text[-4:])
print(text[::-1])
print(text == text[::-1])
```

输出 `Data`、`2026`、`6202ataD`、`False`。最后的比较可以用于判断回文。

</details>

## 3. 不可变：处理结果要用起来

列表可以写 `items[0] = 新值`；字符串不能用索引替换字符。这叫**不可变**：已经创建的字符串内容不能在原处改写。

```python
s = "hello"
# s[0] = "H"  # TypeError：字符串不允许索引赋值

result = s.upper()
print(s)
print(result)

s = s.upper()
print(s)
```

输出：

```text
hello
HELLO
HELLO
```

`upper()` 返回转成大写的文本，原来的 `"hello"` 没有被改写。`s = s.upper()` 是让变量名 `s` 接住结果。只写 `s.upper()`，不赋值、不打印、不传给下一步，程序就没有使用这个处理结果。

`s += "!"` 也不是在原字符串上增加字符，而是拼接后再让 `s` 指向结果。和列表的 `append()` 原地修改要区分开。

没有圆括号的 `s.strip` 只是取到这个方法，并未执行去空白。需要调用时写 `s.strip()`。后面的方法会返回字符串、列表、整数或布尔值，读代码时先确定结果类型。

## 4. split 与 join：拆成列表，再合成文本

### 4.1 按指定分隔符拆分

**分隔符**就是表示两段之间边界的字符，如逗号。`字符串.split(分隔符)` 返回一个列表，列表中的元素是拆出来的字符串。

```python
line = "苹果,香蕉,,橘子"
parts = line.split(",")
print(parts)
print(len(parts))
print(parts[1])
```

输出：

```text
['苹果', '香蕉', '', '橘子']
4
香蕉
```

两个逗号之间没有内容，所以产生一个空字符串。指定分隔符时，连续分隔符、开头或结尾的分隔符都可能产生空字段。

可以给第二个参数，限制最多拆几次：

```python
print("a-b-c".split("-", 1))
print("a,,b,".split(","))
print("".split(","))
```

输出：

```text
['a', 'b-c']
['a', '', 'b', '']
['']
```

分隔符不能是空字符串，`"abc".split("")` 会报 `ValueError`。想逐个取字符，可以用循环或 `list("abc")`，后面会练习。

### 4.2 不给参数时，按空白拆分

```python
text = "  a b  c\n d  "
print(text.split())
print("a  b".split(" "))
print("  ".split())
```

输出：

```text
['a', 'b', 'c', 'd']
['a', '', 'b']
[]
```

`split()` 会把空格、制表符、换行等空白作为边界，把连续空白合并处理，不保留两端空字段。`split(" ")` 是只按那个空格字符拆分，规则不同。

### 4.3 用 join 合并

```python
parts = ["苹果", "香蕉", "橘子"]
result = " | ".join(parts)
print(result)
print("".join(parts))
print(parts)
```

输出：

```text
苹果 | 香蕉 | 橘子
苹果香蕉橘子
['苹果', '香蕉', '橘子']
```

`join` 的写法是 **`分隔符.join(字符串列表)`**，分隔符写在前面。它插在元素之间，不额外放在开头和结尾。结果是字符串，原列表不变。空列表合并得到空字符串。

`join` 要求参与合并的元素都是字符串。数字要先逐个转成文本：

```python
numbers = [1, 2, 3]
texts = [str(n) for n in numbers]
print("-".join(texts))
# print("-".join(numbers))  # TypeError：元素是整数
```

输出是 `1-2-3`。

**小练习 2：**把 `"红,,蓝,绿"` 按逗号拆分，去掉空字段，用 `" / "` 合并。不要改原文本。

<details>
<summary>参考写法</summary>

```python
line = "红,,蓝,绿"
parts = line.split(",")
kept = [part for part in parts if part != ""]
print(" / ".join(kept))
print(line)
```

输出 `红 / 蓝 / 绿` 和 `红,,蓝,绿`。题目中也会出现 `if part`：在条件判断里空字符串为假，非空字符串为真，因此这里能简写成 `[part for part in parts if part]`。只有空格的字符串不是空字符串，不会被这条条件去掉。

</details>

## 5. strip：去掉两端，保留中间

空白包括空格、换行、制表符等。`strip()` 去两端空白，`lstrip()` 只去左端，`rstrip()` 只去右端。

```python
s = "  Hello World  \n"
print("|" + s.strip() + "|")
print("|" + s.lstrip().rstrip() + "|")
print("|" + "  hello  ".lstrip() + "|")
print("|" + "  hello  ".rstrip() + "|")
```

输出：

```text
|Hello World|
|Hello World|
|hello  |
|  hello|
```

用竖线标出边界，就能看到剩余空格。`Hello` 和 `World` 中间的空格不会被 `strip()` 删掉。先给整行 `strip`，也不代表每一个逗号字段都已经清洗；拆开后仍可能要对每段再处理。

`strip(字符)` 还可以指定要从两端反复去掉的字符：

```python
print("xxhixx".strip("x"))
print("abbaXba".strip("ab"))
```

输出 `hi` 和 `X`。`strip("ab")` 把 a 和 b 当成“可去掉的字符”，不是要求匹配整个单词 `"ab"`。不要用它删除指定单词前缀或后缀。

## 6. replace 与大小写：每次接住结果

`replace(旧文本, 新文本)` 替换匹配内容，默认替换所有匹配。第三个参数可限制最多替换几次。

```python
print("a-b-c".replace("-", "+"))
print("aaa".replace("a", "b", 2))
print("Zhang San".replace(" ", ""))
```

输出：

```text
a+b+c
bba
ZhangSan
```

用空字符串作替换结果，就能去掉对应内容。`replace(" ", "")` 只去普通空格，不会顺便去换行或制表符，也不是通用的“去掉所有空白”。

```python
text = "Hello WORLD"
print(text.lower())
print(text.upper())
print(text.title())
print(text.capitalize())
print(text)
```

输出：

```text
hello world
HELLO WORLD
Hello World
Hello world
Hello WORLD
```

`lower` 转小写，`upper` 转大写。对于本例，`title` 把每个单词开头大写、其余小写；`capitalize` 把整个字符串第一个字符大写、其余小写。这些方法不会把中文变成另外一种文字。

是否忽略大小写要看任务要求。如果要求把英文 `"Python"`、`"python"` 当作同一个词，可以先转小写。处理复杂语言时还会有额外规则，现在先用简单英文练习。

可以连续调用方法，但先拆成几步更容易看懂：

```python
raw = "  Zhang San  "
step1 = raw.strip()
step2 = step1.replace(" ", "")
clean = step2.lower()
print(clean)
print(raw.strip().replace(" ", "").lower())
```

两行都输出 `zhangsan`。第二行先去两端空白，再删普通空格，再转小写；每一步的结果都是字符串，所以下一步还能调用字符串方法。

## 7. 查找、统计和判断开头结尾

```python
text = "hello world"
print("world" in text)
print(text.find("world"))
print(text.find("cat"))
print(text.index("world"))
print(text.count("l"))
print(text.startswith("hello"))
print(text.endswith(".txt"))
```

输出：

```text
True
6
-1
6
3
True
False
```

| 想知道什么 | 操作和结果 |
|---|---|
| 是否包含这段文本 | `in`，得到布尔值 |
| 第一次出现在哪 | `find`，得到起始索引，找不到是 `-1` |
| 必须存在时取位置 | `index`，找不到报 `ValueError` |
| 出现几次 | `count`，得到整数，找不到是 0 |
| 开头、结尾是否匹配 | `startswith`、`endswith`，得到布尔值 |

`find` 和 `index` 找的是**起始位置**，而不是字符数量。字符索引从 0 开始，所以不能用 `if text.find("hello")` 判断是否找到：在开头找到会返回 0，在条件里反而为假；没找到返回的 `-1` 反而为真。

```python
text = "hello world"
position = text.find("hello")
if position != -1:
    print("找到了，索引是", position)
```

输出是 `找到了，索引是 0`。如果不需要位置，直接用 `if "hello" in text` 更清楚。

`count` 统计的是**不重叠**的匹配，`"aaaa".count("aa")` 是 2。字符串计数也不自动理解单词边界；`"this".count("is")` 是 1，要按完整单词统计，可以先拆成单词列表，再用列表的 `count`。

## 8. 数字文本与类型转换

`isdigit()` 是判断：字符串非空，且每个字符都是它认可的数字字符时才返回 `True`。它不会把文本变成数字。

```python
print("314".isdigit())
print("3.14".isdigit())
print("-18".isdigit())
print(" 18 ".isdigit())
print("".isdigit())
print("abc".isalpha())
print("a1".isalnum())
```

输出：

```text
True
False
False
False
False
True
True
```

小数点、正负号和空白都不是数字字符。`isalpha` 判断是否全是字母，`isalnum` 判断是否全是字母或数字；它们也要求非空，并且不限于英文字母。

真正转换时，用 `int` 或 `float`：

```python
print(int("18") + 1)
print(int(" 18 "))
print(int(" -18 "))
print(float("3.14"))
print(str(18) + "岁")
# print(int("1 8"))   # ValueError：中间有空格
# print(int("3.14"))  # ValueError：不是整数文本
# print(int("abc"))   # ValueError：不是数字文本
```

输出：

```text
19
18
-18
3.14
18岁
```

**`int` 可以接受整数文本两端的空白和正负号，但不能接受数字中间的空格。**因此 `int(" 18 ")` 本来就能成功；清洗时先 `strip` 是为了让各字段形式一致，不是说整数转换一定要先删两端空白。

不要直接记成“`isdigit()` 为真就一定能用 `int` 转换”。`isdigit` 也认可某些 Unicode 数字，例如上标 `"²"`，但 `int("²")` 会报 `ValueError`。如果这次规则只允许**无正负号的十进制数字文本**，可以先去两端空白，再用 `isdecimal()` 判断：

```python
age_text = " 18 ".strip()
if age_text.isdecimal():
    age = int(age_text)
    print(age)
else:
    print("请输入无正负号的整数")
```

输出是 `18`。这条校验不接受负数、小数或空文本，它是否合适取决于输入规则。实际任意输入的转换还要处理异常，在异常模块继续学习。

**小练习 3：**分别预测 `" 20 ".isdigit()`、`" 20 ".strip().isdigit()`、`int(" 20 ")`。再解释 `"3.14".isdigit()` 为什么不能完成“小数转换”。

<details>
<summary>核对</summary>

前三个结果是 `False`、`True`、整数 `20`。`isdigit()` 只返回真假，`float("3.14")` 才返回浮点数 `3.14`。

</details>

## 9. f-string：把变量放进文字里

格式化就是按照要求，把值表示成文本。**f-string 在引号前加 `f`，用 `{}` 放变量或计算。**

```python
name = "小林"
age = 18
score = 86.3456
print(f"{name}今年{age}岁")
print(f"分数：{score:.2f}")
print(f"总分：{60 + 80 + 100}")
```

输出：

```text
小林今年18岁
分数：86.35
总分：240
```

`{score:.2f}` 分成三部分：`score` 是要显示的值，冒号后面是格式要求，`.2f` 表示按定点小数显示并保留两位小数。它只是产生显示文本，没有把变量 `score` 改成 86.35。

```python
print(f"{86.3456:.0f}")
print(f"{1234567:,}")
print(f"{0.256:.1%}")
print(f"|{'Lin':<8}|")
print(f"|{'Lin':>8}|")
print(f"|{'Lin':^8}|")
```

输出：

```text
86
1,234,567
25.6%
|Lin     |
|     Lin|
|  Lin   |
```

`<8` 左对齐，`>8` 右对齐，`^8` 居中，8 表示至少占 8 个字符宽度。文本超过 8 个字符不会被截断。百分比格式会把 0.256 显示成 25.6%，不要先乘 100 再使用 `%` 格式。

打印成绩表，可以先用已学的嵌套列表和索引：

```python
rows = [["Lin", 88], ["Chen", 95], ["Wang", 79]]
total = 0
for row in rows:
    name = row[0]
    score = row[1]
    print(f"{name:<8}{score:>6}")
    total = total + score
average = total / len(rows)
print(f"平均分：{average:.1f}")
```

输出：

```text
Lin         88
Chen        95
Wang        79
平均分：87.3
```

循环里每一行有姓名和分数，分数逐轮累加；平均分在循环结束后计算。题目使用元组保存行数据并直接拆包，学完下一模块后再练那个写法。中文显示占的屏幕宽度受终端影响，按题目写对格式即可。

f-string 中引用的变量必须已经定义。`print(f"{name}")` 在 `name` 从未定义时会报 `NameError`。

## 10. 逐个字符处理，或转成列表

```python
word = "hello"
for ch in word:
    print(ch)
```

输出是五行，依次为 `h`、`e`、`l`、`l`、`o`。循环变量每次接住一个长度为 1 的字符串。

可以用列表推导式筛选字符：

```python
vowels = [ch for ch in "hello world" if ch in "aeiou"]
print(vowels)
print("".join(vowels))
```

输出：

```text
['e', 'o', 'o']
eoo
```

`list(字符串)` 把每个字符装进列表；`split` 按分隔规则切成片段，二者不能互换。

```python
print(list("hello"))
print("hello".split())
print(sorted("cab"))
print("".join(sorted("cab")))
```

输出：

```text
['h', 'e', 'l', 'l', 'o']
['hello']
['a', 'b', 'c']
abc
```

`sorted` 无论输入字符串还是列表，都返回列表。要得到排序后的字符串，再 `join` 回去。字符串按字符编码顺序比较，不是所有语言的词典顺序；简单的小写英文字母按 a 到 z 排列，混用大小写时结果会不同。

字符去重可以沿用列表模块的方法：

```python
word = "banana"
unique = []
for ch in word:
    if ch not in unique:
        unique.append(ch)
print(unique)
print("".join(sorted(unique)))
```

输出：

```text
['b', 'a', 'n']
abn
```

不要混淆“把全部字符排序”和“先去重再排序”：`sorted(word)` 会保留所有重复字符，`sorted(unique)` 才是对唯一字符排序。

## 11. 把清洗步骤连成一个小程序

任务：一行文本用逗号分开姓名和年龄，姓名可能有空格，年龄两端可能有空白。把它整理成 `zhangsan|18`，同时得到可以参与计算的整数年龄。

```python
raw = "   Zhang San ,  18  \n"
line = raw.strip()
fields = line.split(",")
name_text = fields[0]
age_text = fields[1]

name = name_text.strip().replace(" ", "").lower()
age_text = age_text.strip()
age = int(age_text)

result = "|".join([name, age_text])
print(fields)
print(result)
print(age + 1)
```

输出：

```text
['Zhang San ', '  18']
zhangsan|18
19
```

先给整行去两端空白，再按逗号拆字段，此时 `fields` 是列表。分别取字段后，对姓名做文本处理，对年龄做数字转换。合并时使用字符串 `age_text`，计算时使用整数 `age`。

这里的输入是题目给定的两字段格式。如果换成没有逗号的文本，读取 `fields[1]` 就会越界；多了逗号也会改变字段数量。实际输入要先检查 `len(fields)` 是否等于 2，再按照数据规则判断年龄是否合法。

**小练习 4：**把 `"  LI Si , 20 \n"` 清洗成 `lisi|20`，再输出 `明年年龄：21`。从空文件独立写，不复制上面的程序。

处理顺序是拆字段、清洗姓名、清洗年龄、按需要转整数。变量名可以用自己的，重点是字段类型和结果正确。
