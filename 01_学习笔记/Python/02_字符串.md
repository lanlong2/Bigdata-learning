# 字符串：读懂文本清洗的每一步

练习入口：[字符串与元组习题册](../../02_习题册/Python/02_字符串与元组/README.md)。报错示例要分开验证。

## 1. 字符串是什么

字符串就是**一串字符**（文字、数字、符号都算），用引号包起来。

形象理解：字符串像一张**过了塑封的字条**——你能看、能数、能复印，**但不能在上面涂改**。想改？只能重新打印一张新的。

```python
a = "hello"           # 双引号
b = 'hello'           # 单引号，完全等价
c = """第一行
第二行"""              # 三引号：可以跨行，单独放在特定位置可作说明字符串；普通注释仍用 #
d = ""                # 空字符串，长度是 0
e = "123"             # ⚠️ 这是字符串，不是数字！"123" + 1 会报错
```

**为什么有单双引号两种？** 为了方便嵌套：

```python
s1 = "他说：'你好'"      # 里面有单引号，外面就用双引号
s2 = '他说："你好"'      # 反过来也行
s3 = "他说：\"你好\""    # 或者用反斜杠转义
```

**常用转义字符**（反斜杠 `\` 开头，表示"这个字符有特殊含义"）：

| 写法 | 含义 | 例子 |
|------|------|------|
| `\n` | 换行 | `print("A\nB")` 打印成两行 |
| `\t` | 制表符（对齐用） | `print("姓名\t分数")` |
| `\\` | 一个真正的反斜杠 | `"C:\\Users"` |
| `\"` `\'` | 引号本身 | `"他说\"好\""` |

```python
# path = "C:\Users\new"    # 错误示例：\U 会被当成 Unicode 转义开头，产生 SyntaxError
path = r"C:\Users\new"      # ✓ 前面加 r（raw 原始字符串），反斜杠全当普通字符
```

## 2. 索引与切片：给每个字符发门牌号

字符串是**有序**的，每个字符都有编号，**从 0 开始数**。

```python
s = "Python"
#  正索引:  0 1 2 3 4 5
#  负索引: -6-5-4-3-2-1     负数从右往左数

s[0]        # "P"      第一个字符
s[-1]       # "n"      最后一个字符
s[1:4]      # "yth"    切片：从1取到4，【含头不含尾】
s[:3]       # "Pyt"    从头开始
s[3:]       # "hon"    一直到结尾
s[::2]      # "Pto"    步长2，隔一个取一个
s[::-1]     # "nohtyP" 步长-1 →【反转字符串的经典写法】
len(s)      # 6        总长度
```

形象理解：切片就像用**剪刀在两个字符之间下剪**，剪口编号写在字符**左边**，所以 `s[1:4]` 剪下来的是 1、2、3 号位，**4 号位不要**。

⚠️ `s[0]` 拿到的还是**字符串**——Python 里没有"单个字符"这种类型，`"P"` 就是一个长度为 1 的字符串。

⚠️ 索引越界会报错，但**切片越界不会**：

```python
s[6]        # ✗ IndexError: string index out of range
s[0:100]    # ✓ "Python"   切片越界自动止步，很安全
```

## 3. 不可变性 🔴 字符串最重要的一条

```python
s = "hello"
s[0] = "H"       # ✗ TypeError: 'str' object does not support item assignment
```

**塑封字条模型**：字条塑封了，涂改不了。所有"修改字符串"的方法，本质都是**重新印一张新字条给你**，老字条一个字都没变。

```python
s = "hello"
s.upper()          # 返回了 "HELLO"
print(s)           # 还是 "hello"！  ← 原字符串没有改变

s = s.upper()      # ✓ 想让 s 指向结果，可以重新赋值；也可以直接打印或传给其他函数
print(s)           # "HELLO"
```

> 🔑 口诀：**字符串方法不会原地改字符串。要用结果时，赋值、打印或传入下一步；先弄清返回的是字符串、列表、整数还是布尔值。**

## 4. 常用方法：不改原字符串，返回类型各不相同

**清洗与变形**

```python
s = "  Hello World  "

s.strip()               # "Hello World"   去掉【两端】空白（最常用！）
s.lstrip()              # "Hello World  " 只去左边
s.rstrip()              # "  Hello World" 只去右边
"xxhixx".strip("x")     # "hi"            也可以指定去掉哪些字符

s.upper()               # 全大写
s.lower()               # 全小写（做"忽略大小写的比较"时必用）
"hello world".title()   # "Hello World"   每个单词首字母大写
"hello".capitalize()    # "Hello"         只有第一个字母大写

"a-b-c".replace("-", "+")     # "a+b+c"   替换（默认全部替换）
"aaa".replace("a", "b", 2)    # "bba"     第三个参数 = 最多替换几次
```

**拆与合** ⭐（字符串和列表之间的两扇门）

```python
# split：字符串 →【列表】
"a,b,c".split(",")        # ["a", "b", "c"]
"a b  c".split()          # ["a", "b", "c"]  不给参数 = 按任意空白拆，自动忽略连续空格
"a-b-c".split("-", 1)     # ["a", "b-c"]     第二个参数 = 最多拆几次
"a,b,,c".split(",")       # ["a", "b", "", "c"]  ⚠️ 连续分隔符会拆出空串

# join：列表 →【字符串】
"-".join(["a", "b", "c"])   # "a-b-c"
"".join(["a", "b", "c"])    # "abc"
"、".join(["张三", "李四"])  # "张三、李四"
```

⚠️ `join` 的写法反直觉：**分隔符写在最前面**，而且列表里必须**全是字符串**：

```python
"-".join([1, 2, 3])                    # ✗ TypeError
"-".join([str(x) for x in [1, 2, 3]])  # ✓ "1-2-3"
```

**查找与判断**

```python
s = "hello world"

"world" in s          # True    判断包不包含（最简单，优先用）
s.find("world")       # 6       返回位置，【找不到返回 -1，不报错】
s.find("xyz")         # -1
s.index("world")      # 6       返回位置，【找不到直接 ValueError】
s.count("l")          # 3       出现几次
s.startswith("hello") # True    以什么开头
s.endswith(".txt")    # False   以什么结尾（判断文件类型常用）

"314".isdigit()       # True    纯数字吗
"3.14".isdigit()      # False   ⚠️ 小数点不算数字！
"abc".isalpha()       # True    纯字母吗
"a1".isalnum()        # True    字母或数字
```

## 5. 拼接与重复

```python
"abc" + "def"        # "abcdef"    加号 = 拼接
"ab" * 3             # "ababab"    乘号 = 重复
"-" * 30             # "------..." 画分割线的经典写法

"年龄" + 18          # ✗ TypeError: 只能字符串拼字符串
"年龄" + str(18)     # ✓ "年龄18"
```

大量片段拼接时，可以先收集后合并，写法更清楚：**先把碎片装进列表，最后 `join` 一次**。 

```python
parts = []
for w in ["a", "b", "c"]:
    parts.append(w)          # 列表可变，加起来很快
result = "".join(parts)      # 最后一次性合成
```

## 6. f-string 格式化 ⭐（日常用得最多）

```python
name = "lanlong"
score = 86.3456

f"{name}的分数是{score}"      # 直接把变量塞进大括号
f"{score:.2f}"                # 86.35        保留2位小数
f"{score:.0f}"                # 86           不要小数
f"{1234567:,}"                # 1,234,567    千位分隔符
f"{0.256:.1%}"                # 25.6%        转百分比
f"|{name:<10}|"               # |lanlong   | 左对齐占10格
f"|{name:>10}|"               # |   lanlong| 右对齐
f"|{name:^10}|"               # | lanlong  | 居中
f"{name!r}"                   # 'lanlong'    带引号显示
f"{len(name)=}"               # len(name)=7  调试神器：变量名和值一起打印
f"{2 + 3}"                    # 5            大括号里可放任意表达式
```

对齐在做**表格输出**时特别香：

```python
for name, score in [("张三", 88), ("李四", 95)]:
    print(f"{name:<8}{score:>5}")
```

## 7. 遍历字符串

```python
for ch in "abc":
    print(ch)              # a / b / c   直接拿到每个字符

for i, ch in enumerate("abc"):
    print(i, ch)           # 0 a / 1 b / 2 c

vowels = [ch for ch in "hello world" if ch in "aeiou"]
print(vowels)              # ['e', 'o', 'o']   推导式对字符串同样好使
```

## 8. 类型转换（字符串 ↔ 其他）

```python
str(123)               # "123"                   任何东西 → 字符串
int("123")             # 123                     字符串 → 整数
float("3.14")          # 3.14                    字符串 → 小数
int("abc")             # ✗ ValueError

list("hello")          # ['h','e','l','l','o']   字符串 →【拆成单字符的列表】
"hello".split()        # ['hello']               ⚠️ 和上面完全不同！
"".join(['h','i'])     # "hi"                    列表 → 字符串
tuple("hi")            # ('h', 'i')              字符串 → 元组
sorted("cab")          # ['a','b','c']           ⚠️ sorted 永远返回【列表】
"".join(sorted("cab")) # "abc"                   想要字符串就再 join 回去
```

## 返回类型速查

| 表达式 | 返回类型 | 用途 |
|---|---|---|
| `s.strip()`、`s.lower()`、`s.replace(...)` | str | 处理后的文本 |
| `s.split(",")` | list | 分段列表 |
| `s.count("a")`、`s.find("a")` | int | 次数或位置 |
| `s.startswith("a")`、`s.isdigit()` | bool | 判断 |

`"3.14".isdigit()` 是合法表达式，返回False；小数点不是数字字符。处理这种给定的小数字面量，可以用 `float("3.14")`；输入可能非法时还要处理异常。
中文的视觉对齐会受终端影响，不等于Python格式宽度有误。
