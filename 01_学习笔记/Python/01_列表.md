# 列表：把多份数据装在一起，再逐个处理

这一模块是学习新知识的教材。请从第 1 节开始读，每读完一段就运行示例、做小练习，不需要先看某一节视频。

**开始前需要会：**[核心语法](00_核心语法.md)中的变量、基本类型、`print`、运算、`if`、`for`、`range` 和调用的基本写法。如果你还不能解释 `for n in range(3)` 为什么循环三次，先回去练习循环。

**学完后你应该能：**创建列表，读取和修改元素，跟踪列表连续变化，区分索引与切片，遍历、筛选和统计数据，选择合适的排序与复制方法。最后再学用推导式简化已经会写的循环。

除非特别说明，每个 Python 代码块都可以单独复制运行。输出块展示运行后的内容；输出中的单引号和创建列表时的双引号，都可以表示字符串。预期报错的行会先注释起来，想观察错误时一次只取消一行注释。

## 1. 为什么需要列表

只有一个分数时，一个变量够用。要保存全班的分数，如果写几十个变量，就很难统一求和、排序或筛选。**列表是一种容器，用来把多个值放在一起。里面的每个值叫一个元素。**

```python
scores = [88, 62, 95]
names = ["小林", "小陈"]
record = ["小林", 18, True]
empty = []

print(scores)
print(len(scores))
print(type(scores))
print(empty)
```

输出：

```text
[88, 62, 95]
3
<class 'list'>
[]
```

创建列表时，`[]` 围出整个列表，逗号分开元素。`len(scores)` 数的是元素个数。`record` 说明一个列表可以装不同类型，但做成绩统计时最好都装数字，否则相加或比较可能失败。

列表有两个特点：**有序**表示保留元素的先后顺序；**可变**表示创建后还可以增、删、替换元素。有序不等于已经从小到大排好序，`[88, 62, 95]` 也有序。

## 2. 索引：取出一个位置的元素

**索引就是位置编号，从 0 开始。**第一个元素的索引是 0，第二个是 1。负索引从末尾数，`-1` 表示最后一个，`-2` 表示倒数第二个。

| 元素 | 苹果 | 香蕉 | 橘子 |
|---|---|---|---|
| 正索引 | 0 | 1 | 2 |
| 负索引 | -3 | -2 | -1 |

```python
fruits = ["苹果", "香蕉", "橘子"]
first = fruits[0]
last = fruits[-1]

print(first)
print(last)
print(type(first))
print(len(fruits))
```

输出：

```text
苹果
橘子
<class 'str'>
3
```

`fruits[0]` 的方括号是“从现有列表取元素”，不是创建列表。取出的类型取决于这个位置原本装什么；这里装字符串，所以取出的不是列表。

长度为 3 的列表，有效正索引只有 0、1、2。索引 3 已经超出范围，叫**越界**。

```python
fruits = ["苹果", "香蕉", "橘子"]
# print(fruits[3])  # IndexError：没有索引为 3 的元素
# print([][-1])    # IndexError：空列表连最后一个元素也没有

if len(fruits) > 0:
    print(fruits[-1])
```

输出是 `橘子`。先判断非空，就可以安全取末尾元素。

**小练习 1：**创建 `colors = ["红", "绿", "蓝", "紫"]`，打印第二个和最后一个元素，再写出最后一个元素的正索引。

```python
colors = ["红", "绿", "蓝", "紫"]
print(colors[1])
print(colors[-1])
print(len(colors) - 1)
```

</details>

## 3. 方法、参数和返回值怎么读

有些操作写成 `len(scores)`：把列表交给函数。另一些写成 `scores.append(100)`：让列表使用自己的操作。后一种操作叫**方法**，点号前面是要操作的对象。

在 `scores.append(100)` 中，`append` 是方法名，圆括号表示调用，`100` 是传给它的**参数**。参数就是告诉操作“这次具体处理什么”。只有 `scores.append` 而没有圆括号，并没有执行添加。

**返回值是调用交回来的结果。**它和“列表本身发生了什么变化”是两件事，不能只看其中一个。

```python
scores = [88, 62]
result = scores.append(95)

print(scores)
print(result)
```

输出：

```text
[88, 62, 95]
None
```

`append` 已经把 95 加进原列表，但它交回的值是 `None`，不是添加后的列表。`None` 表示这里没有另外一个结果交给你。不要写 `scores = scores.append(95)`，否则名字 `scores` 最后会指向 `None`。

后面每学一种方法，都问两句：**它是否改变原列表？它返回什么？**

## 4. 修改列表：增、删和替换

### 4.1 在末尾加一个，或在指定位置插一个

```python
cart = ["牛奶", "面包"]
cart.append("水果")
print(cart)

cart.insert(0, "鸡蛋")
print(cart)

cart[1] = "酸奶"
print(cart)
```

输出：

```text
['牛奶', '面包', '水果']
['鸡蛋', '牛奶', '面包', '水果']
['鸡蛋', '酸奶', '面包', '水果']
```

`append(值)` 一次接收一个元素，把它加到末尾。`insert(位置, 值)` 接收两个参数，插到指定位置前，后面的元素往后移。`cart[1] = "酸奶"` 是替换已有位置，长度不变。

每行都接着上一行的结果执行。插入鸡蛋以后，牛奶已经从索引 0 移到了索引 1。

`insert` 的位置超过末尾会加在末尾，过小的负位置会插到开头；索引赋值不会这样自动处理。`cart[100] = "茶"` 不能用来添加新位置，会报 `IndexError`。

### 4.2 append 和 extend 的区别

要把另一个列表的几个元素加进来，可以用 `extend`。

```python
a = [1, 2]
a.append([3, 4])

b = [1, 2]
b.extend([3, 4])

print(a)
print(len(a))
print(b)
print(len(b))
```

输出：

```text
[1, 2, [3, 4]]
3
[1, 2, 3, 4]
4
```

`append` 把整个 `[3, 4]` 当成一个元素，所以形成“列表里装列表”。`extend` 把传入的列表逐个取出，加进原列表。能被 `for` 逐个取值的东西叫**可迭代对象**，列表就是其中一种；`extend` 接收这样一个对象。

`append("水果", "蔬菜")` 给了两个参数，会报 `TypeError`。可以分别调用两次，也可以用 `extend(["水果", "蔬菜"])`。这两种方法都改变原列表，返回 `None`。

### 4.3 按值删，或按位置删

```python
cart = ["牛奶", "面包", "牛奶", "鸡蛋"]
cart.remove("牛奶")
print(cart)

taken = cart.pop()
print(taken)
print(cart)

first = cart.pop(0)
print(first)
print(cart)

del cart[0]
print(cart)
```

输出：

```text
['面包', '牛奶', '鸡蛋']
鸡蛋
['面包', '牛奶']
面包
['牛奶']
[]
```

`remove("牛奶")` 按**值**删，只删第一次匹配的牛奶。`pop()` 按**位置**删，省略位置就删末尾，并返回被删的元素。`pop(0)` 删当前第一个。`del cart[0]` 是删除语句，删指定位置，不提供可接收的返回值。

| 操作 | 改原列表吗 | 返回值 |
|---|---|---|
| `append(值)`、`insert(位置, 值)`、`extend(列表)` | 改 | `None` |
| `remove(值)` | 改，删第一个匹配值 | `None` |
| `pop()`、`pop(索引)` | 改 | 被删的元素 |
| `clear()` | 改，清空全部元素 | `None` |

`remove` 找不到值会报 `ValueError`；`pop` 和 `del` 的索引不存在会报 `IndexError`。需要判断值是否存在时，可以这样写：

```python
cart = ["牛奶", "面包"]
if "茶" in cart:
    cart.remove("茶")
print(cart)

cart.clear()
print(cart)
```

输出：

```text
['牛奶', '面包']
[]
```

`"茶" in cart` 检查元素是否存在，结果是布尔值；这里是 `False`，所以没有执行删除。`clear()` 清空列表，名字 `cart` 仍然指向一个列表。

**小练习 2：**从 `[10, 20, 30]` 开始，末尾加 40，删除值 20，取出第一个元素并保存为 `taken`。每一步都打印当前列表，最后打印 `taken`。

<details>
<summary>核对状态和代码</summary>

```python
nums.append(40)
print(nums)
nums.remove(20)
print(nums)

```

## 5. 查找和计数：四种问题，四种操作

```python
grades = ["A", "B", "A", "C"]
print(len(grades))
print(grades.count("A"))
print(grades.index("A"))
print("D" in grades)
print("D" not in grades)
```

输出：

```text
4
2
0
False
True
```

`len` 求总数；`count(值)` 数这个值出现几次；`index(值)` 找第一次出现的索引；`in` 回答这个值是否在列表里，`not in` 回答它是否不在列表里。

注意 `grades.index("A")` 的结果 0 表示第一个位置，不表示“没有”。`grades.index("D")` 找不到会报 `ValueError`，但 `grades.count("D")` 会得到 0。`grades.count()` 少了要数的值，会报 `TypeError`。

## 6. 切片：取出一段，而不是一个元素

切片写成 `列表[起始:结束:步长]`。**起始位置包含，结束位置不包含。**先只看前两个位置：

```python
words = ["red", "green", "blue", "black"]
print(words[1])
print(words[1:2])
print(words[1:3])
print(words)
```

输出：

```text
green
['green']
['green', 'blue']
['red', 'green', 'blue', 'black']
```

`words[1]` 取一个元素，结果是字符串。`words[1:2]` 取一段，只包含索引 1，结果仍是列表。`words[1:3]` 取索引 1、2，排除索引 3。**读取切片不改变原列表，它得到一个新的外层列表。**

省略边界和指定步长的常用写法：

```python
nums = [0, 1, 2, 3, 4, 5, 6]
print(nums[:3])
print(nums[-3:])
print(nums[1:-1])
print(nums[::2])
print(nums[1:6:2])
print(nums[::-1])
print(nums[5:2:-1])
```

输出：

```text
[0, 1, 2]
[4, 5, 6]
[1, 2, 3, 4, 5]
[0, 2, 4, 6]
[1, 3, 5]
[6, 5, 4, 3, 2, 1, 0]
[5, 4, 3]
```

省略起始表示从这一方向的开头取；省略结束表示一直取到这一方向的末尾。省略步长默认 1，向右取；步长 2 表示索引每次增加 2。步长 `-1` 表示向左取，`[5:2:-1]` 依次经过 5、4、3，仍然排除结束索引 2。

| 容易出错的写法 | 实际情况 |
|---|---|
| `nums[2, 5]` | 逗号不是切片分隔符，普通列表会报 `TypeError` |
| `nums[0:3:]` | 正确，省略步长就是 1 |
| `nums[5:2]` | 默认向右，无法从 5 走到更小的 2，结果是 `[]` |
| `nums[-1:-2]` | 同样默认向右，结果是 `[]` |
| `nums[:100]` | 取到现有末尾，不因结束超范围而报错 |
| `nums[::0]` | 步长不能为 0，会报 `ValueError` |

切片赋值是另一个操作，会改变原列表。例如 `nums[1:3] = [9]` 会把这一段替换为一个元素，长度也可能改变；本模块的切片练习首先练习**读取**。

**小练习 3：**对于 `[0, 1, 2, 3, 4, 5]`，写切片得到 `[1, 2, 3]`、`[5, 4, 3]` 和 `[0, 2, 4]`。

<details>
<summary>参考写法</summary>

```python
nums = [0, 1, 2, 3, 4, 5]
print(nums[1:4])
print(nums[5:2:-1])
print(nums[::2])
```

</details>

## 7. 遍历：逐个读取，或用索引修改

只需要每个值时，让循环变量依次接住元素：

```python
prices = [10, 20, 30]
for price in prices:
    print(price)
print(prices)
```

输出：

```text
10
20
30
[10, 20, 30]
```

循环变量可以使用你自己的名字，只要含义清楚。不要把它也命名为 `prices`：`for prices in prices` 虽然可以开始循环，但每轮赋值会覆盖这个名字，循环后 `prices` 会成为最后一个整数 30。

需要位置时，用 `range(len(prices))` 生成有效索引。要真正修改列表，赋值给 `prices[i]`：

```python
prices = [10, 20, 30]
for i in range(len(prices)):
    prices[i] = prices[i] + 5
    print(i, prices[i])
print(prices)
```

输出：

```text
0 15
1 25
2 35
[15, 25, 35]
```

如果写 `for price in prices: price = price + 5`，只是让循环变量接住另一个数，没有替换列表中的位置。

遍历时增删同一个列表可能让位置变化，导致漏处理或重复处理。要筛选，可以把符合条件的值收进**另一个列表**：

```python
scores = [55, 80, 45, 90]
passed = []
for score in scores:
    if score >= 60:
        passed.append(score)
print(passed)
print(scores)
```

输出：

```text
[80, 90]
[55, 80, 45, 90]
```

后面学完元组与拆包，还会学 `enumerate` 同时得到编号和值。先会用索引遍历，读到那个位置就能顺利衔接。

## 8. 统计：总数、总和、最大值和平均数

```python
scores = [60, 80, 100]
print(len(scores))
print(sum(scores))
print(max(scores))
print(min(scores))
print(sum(scores) / len(scores))
```

输出：

```text
3
240
100
60
80.0
```

`sum` 把数字加起来，`max` 找最大值，`min` 找最小值。平均数要用总和除以个数，`/` 的结果通常是浮点数。

列表为空时，`len([])` 和 `sum([])` 都是 0，但用 0 作除数会报 `ZeroDivisionError`；不提供默认值的 `max([])`、`min([])` 会报 `ValueError`。先判断有数据再算：

```python
scores = []
if len(scores) > 0:
    print(sum(scores) / len(scores))
else:
    print("没有成绩，不能计算平均分")
```

输出是 `没有成绩，不能计算平均分`。如果要去掉一个最高分和一个最低分再平均，至少需要 3 个成绩；少于 3 个时，去掉两端就没有足够的数据了。

## 9. 排序与反转：是否改变原列表

排序是按值比较大小；反转只是把现有顺序倒过来，它们不是同一件事。

```python
nums = [3, 1, 2]
ordered = sorted(nums)
descending = sorted(nums, reverse=True)

print(nums)
print(ordered)
print(descending)
```

输出：

```text
[3, 1, 2]
[1, 2, 3]
[3, 2, 1]
```

`sorted(nums)` 得到新的升序列表，原列表不变。`reverse=True` 是**按名字传参数**：参数名是 `reverse`，这次的值是布尔值 `True`，告诉排序按降序处理。它不是把外面的某个变量赋值为 `True`。

不需要保留原顺序时，用 `sort` 改原列表：

```python
nums = [3, 1, 2]
result = nums.sort()
print(nums)
print(result)

nums.sort(reverse=True)
print(nums)
```

输出：

```text
[1, 2, 3]
None
[3, 2, 1]
```

`sort` 返回 `None`。要拿排序结果，应在调用后使用 `nums`，或用 `ordered = sorted(nums)` 创建新列表。

```python
nums = [3, 1, 2]
reversed_nums = nums[::-1]
print(reversed_nums)
print(nums)

result = nums.reverse()
print(nums)
print(result)
```

输出：

```text
[2, 1, 3]
[3, 1, 2]
[2, 1, 3]
None
```

`[::-1]` 得到反向的新列表，`reverse()` 反转原列表并返回 `None`。这里的 `[2, 1, 3]` 并没有按大小排好序。

排序需要元素之间能够比较。例如普通数字可以互相比较，字符串也可以按字符顺序比较，但 `[1, "2"].sort()` 会报 `TypeError`。按记录的某个字段排序涉及 `key` 与函数，留到函数进阶和容器综合再学。

**小练习 4：**用 `[90, 60, 100, 80]`，在不改变原列表的前提下，去掉一个最高分和一个最低分，打印剩余成绩与平均分。

<details>
<summary>参考写法与输出</summary>

```python
scores = [90, 60, 100, 80]
middle = sorted(scores)[1:-1]
print(middle)
print(sum(middle) / len(middle))
print(scores)
```

输出：

```text
[80, 90]
85.0
[90, 60, 100, 80]
```

先排序，把一个最小值和一个最大值放到两端；再切掉两端。即使最高分或最低分重复，这个切片也只去掉各一个。

</details>

## 10. 赋值、复制与嵌套列表

### 10.1 两个名字可以指向同一个列表

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)
print(b)
```

两行都输出 `[1, 2, 3, 4]`。`b = a` 没有创建新列表，只是给同一份列表多起了一个名字。通过哪个名字修改，看到的都是同一份内容。

如果让 `b = [9]`，那是把名字 `b` 改为指向另一个列表，原列表 `a` 不会因此变成 `[9]`。**重新给名字赋值**和**修改列表内容**要分开看。

### 10.2 复制外层，保留原列表

```python
original = [3, 1, 2]
copied = original.copy()
copied.sort()
copied.append(4)

print(original)
print(copied)
```

输出：

```text
[3, 1, 2]
[1, 2, 3, 4]
```

`copy()` 创建新的外层列表，结果可以接住。`original[:]` 和 `list(original)` 也能复制外层；`list` 在这里把已有元素依次装进一个新列表。

### 10.3 里面还有列表时，复制不一定完全独立

“列表里装列表”叫**嵌套列表**。例如 `rows = [[1, 2], [3, 4]]`，外层有两个元素，每个元素又是一行列表。`rows[0]` 取第一行，`rows[0][1]` 再取这一行的第二个元素。

```python
rows = [[1, 2], [3, 4]]
copied = rows.copy()

print(rows[0][1])
copied[0].append(9)
print(rows)
print(copied)

copied[1] = [8, 8]
print(rows)
print(copied)
```

输出：

```text
2
[[1, 2, 9], [3, 4]]
[[1, 2, 9], [3, 4]]
[[1, 2, 9], [3, 4]]
[[1, 2, 9], [8, 8]]
```

复制只创建了新的外层，里面的两行仍共享。给内部第一行 `append`，两边都会看到变化；替换 `copied[1]`，只换了新外层的一个位置，所以不影响 `rows[1]`。这种只复制外层的操作叫**浅复制**。

如果要连内部对象也独立复制，需要学习更深层的复制；现在先能判断改的是外层位置还是内部列表。

`+` 可以拼接列表，`*` 可以重复元素：

```python
print([1, 2] + [3])
print([0] * 3)
```

输出 `[1, 2, 3]` 和 `[0, 0, 0]`。但 `[[0]] * 3` 会重复引用同一个内部列表，不是创建三个独立内部列表，不要用这种写法制造需要分别修改的多行数据。

## 11. 推导式：先会写循环，再缩成一行

先用已经学过的语法，生成 1 到 4 的平方：

```python
squares = []
for n in range(1, 5):
    squares.append(n ** 2)
print(squares)
```

输出是 `[1, 4, 9, 16]`。**列表推导式**把这个“逐个计算并收集”的过程写在一行：

```python
squares = [n ** 2 for n in range(1, 5)]
print(squares)
```

输出相同。读法是：先看 `for n in range(1, 5)`，`n` 依次取 1、2、3、4；再看前面的 `n ** 2`，每轮把平方结果放进新列表。

需要筛选时，加尾部 `if`：

```python
scores = [55, 80, 45, 90]
passed = [score for score in scores if score >= 60]
doubled_evens = [n * 2 for n in range(1, 7) if n % 2 == 0]
print(passed)
print(doubled_evens)
```

输出：

```text
[80, 90]
[4, 8, 12]
```

三个部分的处理顺序是：**取一个值 → 判断是否保留 → 计算要放进结果的值**。第二行中，2、4、6 通过筛选，然后变成 4、8、12。

```python
doubled_evens = []
for n in range(1, 7):
    if n % 2 == 0:
        doubled_evens.append(n * 2)
print(doubled_evens)
```

这段展开写法对本例得到相同结果，但推导式还有自己的变量作用范围，不能把所有细节都当成和普通循环完全一致。现在用它生成和筛选列表即可，多步骤处理仍用普通循环更清楚。

最外层要用 `[]`。把类似表达式写进圆括号会得到另一种对象，并不是列表。

**小练习 5：**用推导式生成 1 到 10 的奇数，再从 `[58, 60, 89, 45]` 筛出及格分数。写完后，选一个推导式展开为普通循环。

<details>
<summary>参考写法</summary>

```python
odds = [n for n in range(1, 11) if n % 2 == 1]
passed = [score for score in [58, 60, 89, 45] if score >= 60]
print(odds)
print(passed)
```

输出 `[1, 3, 5, 7, 9]` 和 `[60, 89]`。

</details>

## 12. 去重：先用已学语法完成

去重就是每个相同的值只留一份。可以准备一个新列表，遇到尚未保存的值再加进去：

```python
grades = ["A", "B", "A", "C", "B"]
unique = []
for grade in grades:
    if grade not in unique:
        unique.append(grade)

print(unique)
print(len(unique))
print(grades)
```

输出：

```text
['A', 'B', 'C']
3
['A', 'B', 'A', 'C', 'B']
```

第一次遇到 A 时加入，第二次遇到 A 时发现已经存在，就跳过。这种写法保留第一次出现的顺序，原列表不变，能完成当前习题中的“有几种等级”“打印去重清单”。

题目提示或答案中的 `set` 是后面才学习的**集合**。集合去重的写法留到[字典与集合](04_字典与集合.md)再学；集合不保证保留输入顺序，也有元素类型限制。当前用上述循环完成去重即可，如果题目明确要求使用集合，再完成相应模块后作答。
