示例变量名可以换成你习惯的 `a`、`i` 等合法名字。重点是知道变量当前保存的类型、读写方式和处理结果；不要求与示例同名。

先想一个需求：如果 `student = ["小林", 80]`，你得记住第0项是姓名、第1项是分数。写成 `{"name": "小林", "score": 80}` 后，就可以按 `"score"` 找到分数。字典给每一项配一个用来查找的键；它不是给列表下标换个名字，而是另一种组织数据的方式。

## 1. 创建字典和集合，先分清大括号

| 写法 | 类型 | 含义 |
|---|---|---|
| `[]` | list | 空列表 |
| `{}` | dict | 空字典 |
| `{"name": "小林", "score": 80}` | dict | 每个键对应一个值 |
| `{"python", "sql"}` | set | 两个不同元素组成的集合 |
| `set()` | set | 空集合 |

**空集合要写 `set()`，不能写 `{}`。** 有内容时，`键: 值` 中的冒号表示字典的一项；集合元素之间只有逗号。

```python
a = {}
b = set()
c = {"name": "小林", "score": 80}
d = {"python", "sql"}

print(type(a))  # <class 'dict'>
print(type(b))  # <class 'set'>
print(type(c))  # <class 'dict'>
print(type(d))  # <class 'set'>
```

## 2. 字典的键和值分别是什么

```python
student = {"name": "小林", "score": 80}

print(student["name"])   # 小林
print(student["score"])  # 80
print(len(student))      # 2：字典有两项，不是把键和值各数一次
```

在 `"score": 80` 中：

- `"score"` 是**键**，用来定位这一项。
- `80` 是**值**，是这一项保存的数据。
- `student["score"]` 的意思是“读取键为 `"score"` 的值”。

字典中的键不能重复。对同一个键再次赋值，会替换它对应的旧值。值可以重复，也可以是字符串、数字、列表、集合等不同类型。

初学时常用字符串或整数作为键。字典要求键**可哈希**：对象需要支持Python用于查找键的哈希规则。当前记住字符串、整数和元素也都可哈希的元组可以作为键；列表、字典、普通集合不能。不能把“不可变”与“可哈希”完全画等号，例如 `(1, [2])` 外层是元组，内部有列表，仍不能作为键。

```python
locations = {(1, 2): "入口"}
print(locations[(1, 2)])  # 入口
# bad = {[1, 2]: "入口"}  # TypeError：列表不能作为键
# bad = {(1, [2]): "入口"}  # TypeError：元组里含列表
```

### 整数键也不是位置下标

```python
a = {2: "二号货架", 7: "七号货架"}

print(a[2])  # 二号货架：读取键2，不是读取第3项
print(a[7])  # 七号货架

# print(a[0])  # KeyError：字典中没有键0
```

字典支持整数键，但不能把 `a[0]` 理解成“字典的第一项”。即使字典保留插入顺序，也仍然是按键读取。需要按位置处理一排数据时，通常使用列表。

## 3. 字典的读取、修改、新增和删除

```python
student = {"name": "小林", "score": 80}

student["score"] = 85    # 已有键：替换它的值
student["city"] = "杭州"  # 新键：新增一项
del student["city"]      # 删除这一项

print(student)  # {'name': '小林', 'score': 85}
```

`字典[键] = 值` 同时适用于修改和新增；区别在于这个键是否已经存在。`del 字典[键]` 要求键存在，否则会产生 `KeyError`。

读取不存在的键同样会产生 `KeyError`。如果键可能缺失，可以先检查，或使用 `get()`。

```python
student = {"name": "小林", "score": 80}

print(student.get("score"))          # 80：键存在，返回实际值
print(student.get("city"))           # None：键不存在，没有指定默认值
print(student.get("city", "未知"))   # 未知：键不存在，返回指定的默认值
print(student)                      # 原字典没有被get添加city这一项

# print(student["city"])  # KeyError：直接读取缺失的键
```

`get("city", "未知")` 的默认值只在**键不存在时**使用。键存在但保存的是空字符串或 `None` 时，仍然返回这个实际值。

```python
student = {"city": ""}

print(repr(student.get("city", "未知")))  # ''：有city这个键，实际值为空字符串
print(student.get("name", "未命名"))     # 未命名：没有name这个键
```

另外几种常用修改方式：

```python
student = {"name": "小林", "score": 80}
student.update({"score": 90, "city": "杭州"})
city = student.pop("city")
missing = student.pop("age", "未填写")
backup = student.copy()
student["score"] = 95
print(city, missing)  # 杭州 未填写
print(student)        # {'name': '小林', 'score': 95}
print(backup)         # {'name': '小林', 'score': 90}
```

`update` 把另一个字典的项加入当前字典，同名键用新值覆盖，返回None；`pop(键)` 删除一项并返回其值，缺键时若没有默认值就报KeyError。`copy()` 创建一个新的外层字典，里面若有列表或集合，内层对象仍可能共享，和列表浅复制的道理一样。`clear()` 清空当前字典，也返回None。

**先试一下：** 建立 `{"name": "小周", "score": 60}`，把分数改为70，加上city，再删掉city。最后应该只剩姓名和70分。用 `get` 读取不存在的age，要求显示 `未填写`。

## 4. 字典的 in 检查的是键

```python
student = {"name": "小林", "score": 80}

print("score" in student)           # True：有这个键
print("小林" in student)            # False：小林是值，不是键
print("小林" in student.values())   # True：显式检查值

if "score" in student:
    print(student["score"])        # 80
```

`键 in 字典` 返回布尔值，可以用于 `if` 判断。它只做检查，不会修改字典。

## 5. 遍历字典：只拿键，或同时拿键和值

```python
scores = {"小林": 80, "小周": 95}

for name in scores:
    print(name, scores[name])

for name, score in scores.items():
    print(name, score)
```

完整代码输出四行，两段循环各输出相同的两行：

```text
小林 80
小周 95
小林 80
小周 95
```

第一种写法中，`for name in scores` 每轮取到的是**键**，再通过 `scores[name]` 读取值。

第二种写法中，`scores.items()` 每轮提供一个 `(键, 值)` 对；`name, score` 把这一对拆给两个变量。因此可以同时处理键和值。

`scores.keys()` 只提供键，`scores.values()` 只提供值，`scores.items()` 提供键值对。它们不是普通列表；如果需要一份列表结果，可以显式转换：

```python
scores = {"小林": 80, "小周": 95}
print(list(scores.keys()))    # ['小林', '小周']
print(list(scores.values()))  # [80, 95]
print(list(scores.items()))   # [('小林', 80), ('小周', 95)]
```

不要在遍历一个字典时给它新增或删除键，可能报 `RuntimeError`。确实需要删除时，可以先收集待删除的键，循环结束后再删除。

`items` 后面的括号不能漏：`scores.items()` 才是调用方法。不要把方法本身当作已经得到的数据。

Python 3.7 及以上的字典保证插入顺序；这与“字典没有位置下标”并不矛盾。按输入顺序遍历时可以直接遍历；要求按名字或分数排序时，要另外执行排序。

## 6. 按键累计：同一个名字的数字合在一起

例如有三笔销售，要求统计每个人的总件数：

```python
rows = [("小林", 3), ("小周", 2), ("小林", 5)]
totals = {}

for name, quantity in rows:
    totals[name] = totals.get(name, 0) + quantity

print(totals)  # {'小林': 8, '小周': 2}
```

核心这一行从右边开始理解：

```plaintext
totals.get(name, 0)  → 找到这个名字已有的累计值；第一次出现就从0开始
+ quantity          → 加上本轮数量
totals[name] = ...  → 把新累计值保存回这个名字对应的位置
```

执行过程：

| 本轮数据 | 之前的累计值 | 加上本轮数量 | 保存后 |
|---|---:|---:|---|
| 小林，3 | 没有这个键，取0 | 0 + 3 | 小林：3 |
| 小周，2 | 没有这个键，取0 | 0 + 2 | 小周：2 |
| 小林，5 | 3 | 3 + 5 | 小林：8 |

也可以先初始化，再使用 `+=`：

```python
rows = [("小林", 3), ("小周", 2), ("小林", 5)]
totals = {}

for name, quantity in rows:
    if name not in totals:
        totals[name] = 0
    totals[name] += quantity

print(totals)  # {'小林': 8, '小周': 2}
```

没有先建立键就直接写 `totals[name] += quantity`，会因读取缺失的旧值而产生 `KeyError`。

累计字典要在循环外创建；如果每轮都重新写 `totals = {}`，上一轮的结果就丢了。已有键的初始化只能在“第一次出现”时执行，不能每次都把累计值重置为0。

**累计数量**时加 `quantity`；**统计记录次数**时每轮加1。两者不是同一件事。

```python
rows = [("小林", 3), ("小周", 2), ("小林", 5)]
counts = {}

for name, quantity in rows:
    counts[name] = counts.get(name, 0) + 1

print(counts)  # {'小林': 2, '小周': 1}：各出现几笔记录
```

### 固定档位计数：四个键先各从0开始

成绩分档需要判断与字典配合。以下分数约定为0—100整数，先创建四个档位，再让每个人只进入其中一档：

```python
rows = [("a", 59), ("b", 60), ("c", 79), ("d", 80), ("e", 89), ("f", 90)]
a = {"优秀": 0, "良好": 0, "及格": 0, "待加强": 0}

for name, score in rows:
    if score >= 90:
        a["优秀"] += 1
    elif score >= 80:
        a["良好"] += 1
    elif score >= 60:
        a["及格"] += 1
    else:
        a["待加强"] += 1

for level, count in a.items():
    print(f"{level}：{count}人")
```

输出为优秀1人、良好2人、及格2人、待加强1人，各占一行。if/elif/else保证每条记录只给一个档位加1；79进入及格，89进入良好。a在循环前初始化，所以rows为空时四档仍各为0。这里加的是人数1，不是本人的分数。

判断分支的执行顺序见[核心语法第8节](00_核心语法.md#branches)。

**先试一下：** 对 `[("小林", 0), ("小周", 4), ("小林", 2)]` 同时建立数量合计和记录次数。结果应分别是 `{'小林': 2, '小周': 4}` 和 `{'小林': 2, '小周': 1}`。再把输入换成 `[]`，两份结果都应是空字典。

## 7. 集合：保存不重复的元素

```python
topics = {"python", "sql", "python"}

print(len(topics))          # 2：重复的python只保留一份
print("python" in topics)  # True
print("java" in topics)    # False
print(sorted(topics))      # ['python', 'sql']：排序后展示，结果是列表

# print(topics[0])  # TypeError：set不支持位置下标
```

集合用于成员检查和去重，不按位置读取。集合不保证插入顺序，也不保证打印顺序；不要把一次打印的位置当作固定顺序。

集合元素也必须可哈希。常见的字符串、整数可以直接放入集合；列表、字典、集合本身不能作为普通集合的元素。

创建集合时也可以传入列表或元组：`set(["sql", "sql", "python"])` 得到两个不同主题。`len` 数的是不同元素的数量；空集合在if中为假。集合可以for遍历，但遍历顺序不能当作业务顺序。

## 8. add：加入一个元素，返回 None

```python
topics = set()

result = topics.add("python")
topics.add("python")     # 再加同一个元素，仍只保留一份
topics.add("sql")

print(result)            # None：add修改原集合，没有另一个新集合交回
print(sorted(topics))    # ['python', 'sql']
```

`topics.add("python")` 已经修改了 `topics`，不需要用返回值重新赋给 `topics`。如果写成 `topics = topics.add("python")`，这个名字随后就指向 `None`，不能再当集合使用。

`add()` 把传入的整个对象当作**一个元素**。传入字符串 `"python"` 时，是加入一个完整主题，不是拆成六个字符。

```python
a = set()
a.add("python")
b = set("python")

print(sorted(a))  # ['python']：add加入整个字符串
print(sorted(b))  # ['h', 'n', 'o', 'p', 't', 'y']：set遍历字符串，按字符创建集合
```

所以要把一个主题保存成集合，可以写 `{topic}`，或先写 `set()` 再 `add(topic)`；`set(topic)` 会把字符串按字符拆开。

### 删除、批量添加与集合运算

```python
topics = {"python", "sql"}
topics.update(["sql", "excel"])
topics.discard("java")
topics.remove("sql")
print(sorted(topics))  # ['excel', 'python']
```

`update` 逐个加入传入容器里的元素；`discard` 删除指定元素，不存在也不报错；`remove` 删除指定元素，不存在会报KeyError。这些方法修改原集合，返回None。`set.pop()` 删除并返回一个任意元素，不能指定为“第一个”；空集合pop会报KeyError。

两个人选的主题可以这样比较：

```python
a = {"python", "sql"}
b = {"sql", "excel"}
print(sorted(a | b))  # ['excel', 'python', 'sql']：并集，两边全部不同元素
print(sorted(a & b))  # ['sql']：交集，两边都有
print(sorted(a - b))  # ['python']：差集，a有但b没有
print(sorted(a ^ b))  # ['excel', 'python']：只在一边出现
print({"sql"} <= a)   # True：左边是右边的子集
```

这几种运算生成新集合，没有修改a或b。差集有方向，`a - b` 与 `b - a` 通常不同。这里用sorted固定展示顺序，结果显示成列表，但运算的原始结果是集合。

## 9. 按姓名分组：每个人对应一个主题集合

目标是得到这样的关系：

```plaintext
小林 → python、sql
小周 → python
```

这里需要两层结构：**外层字典按姓名找人，内层集合保存这个人不重复的主题。**

```python
rows = [
    ("小林", " Python "),
    ("小周", "python"),
    ("小林", "sql"),
    ("小林", "python"),
    ("小周", "   "),
]
groups = {}

for name, topic in rows:
    topic = topic.strip().lower()
    if topic == "":
        continue

    if name not in groups:
        groups[name] = set()

    groups[name].add(topic)

for name, topics in groups.items():
    print(name, sorted(topics))
```

输出：

```text
小林 ['python', 'sql']
小周 ['python']
```

按顺序理解循环中的四步：

1. 去掉主题两端空白，并统一小写；用赋值接住字符串方法的结果。
2. 清洗后为空就跳过，不把空主题加入集合。
3. 第一次遇到这个姓名，给它建立一个空集合。
4. 找到这个姓名对应的集合，把本轮完整主题加入其中。

`groups[name]` 在这里取到的不是姓名，也不是数字，而是一个**集合**。因此可以继续调用 `.add(topic)`。

不要每一轮都执行 `groups[name] = set()`，否则同一个人的已有主题会被清空。这个初始化应当放在 `if name not in groups:` 内。

每个新姓名都执行一次 `set()`，就有自己独立的集合。不要把一个共同集合赋给所有姓名，那会使不同人的主题混在一起。

展示时使用 `sorted(topics)`，所以打印中看见的是列表格式；`groups` 中保存的值仍然是集合。**排序展示不会把原集合自动改成列表。**

## 10. 保留首次出现和原顺序：列表配合集合

`list(set(values))` 能去重，但不保证原顺序。如果要求保留第一次出现的顺序，可以用集合记录“见过什么”，用列表记录“最后保留什么”。

```python
values = ["sql", "python", "sql", "excel", "python"]
seen = set()
result = []

for value in values:
    if value in seen:
        continue
    seen.add(value)
    result.append(value)

print(result)  # ['sql', 'python', 'excel']
print(values)  # 原列表仍是 ['sql', 'python', 'sql', 'excel', 'python']
```

`seen` 只负责查重，顺序由 `result.append()` 保存。第一次见到就加入；后面重复出现就跳过。

### 按订单编号保留第一条订单

判断重复时要使用题目要求的字段。两条订单的金额不同，但订单编号相同，也可能要按同一订单处理。

```python
orders = [
    {"order_id": "A01", "amount": 20},
    {"order_id": "A02", "amount": 30},
    {"order_id": "A01", "amount": 99},
    {"order_id": "A03", "amount": 15},
]
seen_ids = set()
cleaned = []

for order in orders:
    order_id = order["order_id"]
    if order_id in seen_ids:
        continue
    seen_ids.add(order_id)
    cleaned.append(order)

for order in cleaned:
    print(order["order_id"], order["amount"])
print(len(orders))  # 4：没有删除或修改原订单
```

输出：

```text
A01 20
A02 30
A03 15
4
```

第二条 `A01` 的99没有覆盖第一条的20。`cleaned` 是新列表，顺序沿用首次出现的顺序。这里把原订单字典加入新列表，没有复制字典本身；后续如果修改某条订单字典，两边仍会看到同一个对象的变化。

本例保证每条订单都有有效的 `order_id`。实际清洗时，如果要先去空白、检查缺失或金额是否合法，应按工具规则先完成校验，再决定什么时候记录到 `seen_ids`。例如要求“保留第一条有效订单”，就应在校验通过后才记录编号。

## 11. sorted 返回列表：排序前后分清容器类型

```python
topics = {"sql", "python"}
scores = {"小林": 80, "小周": 95}

sorted_topics = sorted(topics)
sorted_names = sorted(scores)

print(sorted_topics)                # ['python', 'sql']
print(type(sorted_topics))           # <class 'list'>
print(sorted_names)                 # ['小周', '小林']：字典默认参与排序的是键
print(type(topics))                  # <class 'set'>：原集合还是集合
print(type(scores))                  # <class 'dict'>：原字典还是字典
```

字典默认参加排序的是键。若要求“按分数排名”，需要告诉sorted用分数作为排序依据，这要用到函数。本页先学按默认顺序展示；排名留到[函数进阶](06_函数进阶.md)和[容器综合](07_容器综合与拓展.md)，不会作为本页练习的前置。

如果题目要求最终返回字典或集合，不能直接把 `sorted(...)` 的列表当作那个容器交回。集合本身也不适合表达固定排序；“集合保存主题，列表展示有序主题”可以分别完成这两个需要。

## 12. 速查：现在手上是什么类型

| 你要做什么 | 写法 | 得到什么 |
|---|---|---|
| 建空字典 | `{}` | dict |
| 建空集合 | `set()` | set |
| 读取字典的一项 | `data[key]` | 对应的值；缺键产生 KeyError |
| 缺键时取默认值 | `data.get(key, default)` | 实际值或默认值 |
| 检查字典有无某个键 | `key in data` | bool |
| 同时遍历键和值 | `for key, value in data.items():` | 每轮拆出一对键和值 |
| 按键累计数字 | `data[key] = data.get(key, 0) + number` | 修改原字典 |
| 检查集合中有无元素 | `value in seen` | bool |
| 向集合加入一个元素 | `seen.add(value)` | 修改原集合，返回 None |
| 排序展示集合 | `sorted(seen)` | 新列表，原集合不变 |
| 保留首次出现的顺序 | 集合查重，列表 append | 按首次出现顺序排列的新列表 |
