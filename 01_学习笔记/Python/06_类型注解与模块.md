# 类型注解与模块：让代码更好读，也能分文件使用

对应P71～76。模块就是能被导入的Python文件；包用来组织一组模块。

## 类型注解是说明，不是自动检查

```python
def twice(value: int) -> int:
    return value * 2

print(twice(3))    # 6
print(twice("3"))  # 33；普通Python运行不会仅因注解而拒绝字符串
```

工具可能提示类型不符，但Python不会自动把"3"变成3。确实需要数字时，明确转换并处理转换失败。

## 自己的模块

两个文件放在同一个文件夹：

helpers.py：

```python
def clean_name(name):
    return name.strip().lower()
```

run_examples.py：

```python
from helpers import clean_name
print(clean_name(" Alice "))  # alice
```

运行run_examples.py。只在文字里写“文件名：”不会创建文件，要真的保存为对应.py文件。
常用写法：import helpers之后用helpers.clean_name；或from helpers import clean_name后直接用clean_name。

## 为什么导入时也会打印

导入模块会执行其顶层代码。把试运行代码放在入口保护里：

```python
def clean_name(name):
    return name.strip().lower()

if __name__ == "__main__":
    print(clean_name(" Alice "))
```

直接运行该文件会打印；从其他文件导入时不执行这段演示。函数定义仍能被导入。

## 包的最小结构

```text
项目/
  run.py
  tools/
    __init__.py
    cleaning.py
```

在这份入门示例中，__init__.py可以为空，tools按普通包组织。在run.py写from tools.cleaning import clean_name。
运行项目入口run.py，不要随意进入包内直接运行依赖相对位置的文件。

## 标准库与第三方库

json、csv、pathlib是Python自带模块，当前无需安装。第三方库才可能需要额外安装。
不要把自己的文件命名为json.py、csv.py、typing.py，以免遮蔽标准库。

## 模块与数据路径

导入路径和数据文件路径不是一回事。读取数据时可以从当前脚本位置确定文件夹：

```python
from pathlib import Path
BASE = Path(__file__).resolve().parent
data_file = BASE / "练习数据" / "示例.txt"
```

__file__在保存后运行的.py文件中可用；直接粘贴到交互终端时可能没有它，因此文件习题请运行保存好的.py文件。
