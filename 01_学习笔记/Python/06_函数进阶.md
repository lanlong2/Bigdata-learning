## 1. 作用域：一个名字在哪里能使用

**作用域**就是“这个名字在哪一片代码里有效”。先学习最常见的两种：

- **全局变量**：在这个文件最外层定义的变量。
- **局部变量**：在某次函数调用内部使用的参数和内部赋值的变量。

同样的名字可以在这两片范围中各有自己的含义：

```python
value = 10

def double(value):
    value = value * 2
    return value

print(double(3))
print(value)
```

输出：

```text
6
10
```

调用时，内部参数 value 得到 3；右边的 `value * 2` 得到 6，重新赋给内部 value，再返回 6。外部 value 仍然是 10。这里给局部名字重新赋值，不会把同名的全局变量也改成 6。

函数内部建立的其他名字，外面也不能直接使用：

```python
def add_one(number):
    result = number + 1
    return result

answer = add_one(4)
print(answer)
# print(result)  # NameError：result 是函数内部的局部名字
```

输出为 `5`。外面取得结果靠 return，不需要也不能靠“直接拿函数内部变量”。

### 函数可以读取全局名字

```python
prefix = "商品"

def make_label(name):
    return prefix + ":" + name

print(make_label("pen"))
prefix = "物品"
print(make_label("pen"))
```

```text
商品:pen
物品:pen
```

函数内没有给 prefix 赋值，所以这两次调用都读取外部当前的 prefix。这样的隐含依赖会让函数行为随外部状态变化。初学时，通常把会变化的数据写成参数，更容易检查一次调用究竟使用了什么。

### global：确实需要重新赋值全局变量时才使用

```python
count = 0

def record_call():
    global count
    count = count + 1
    return count

print(record_call())
print(record_call())
print(count)
```

```text
1
2
2
```

`global count` 告诉 Python：本函数里的 count 使用文件最外层那个名字，因此赋值会更新外面的 count。

如果函数内写 `count = count + 1` 却没有 global，Python 会把这个函数里的 count 认作局部名字；右侧又在局部 count 得到值之前读取它，会产生 `UnboundLocalError`。单纯读取全局变量无需 global。

G01—G08 都可以通过参数传入、return 传出完成，不要求使用 global。只有工具的需求确实包含“更新全局状态”时，才采用上面的写法。

```python
number = 5

def reduce(number):
    number = number - 2
    return number

print(reduce(number))
print(number)
```

<details>
<summary>核对答案</summary>

输出为 `3`、`5`。实参把外面 number 当前的值 5 交给内部参数；内部重新赋值后返回 3，外面的名字没有被重新赋值。

## 2. 列表参数：局部名字不等于自动复制一份数据

整数、字符串等对象不能原地修改；列表、字典、集合是**可变对象**，可以直接改变内容。传入可变对象时，函数内部的参数名与外面的名字可能指向同一个对象。

```python
def add_zero(values):
    values.append(0)
    return values

numbers = [1, 2]
result = add_zero(numbers)
print(result)
print(numbers)
```

```text
[1, 2, 0]
[1, 2, 0]
```

调用没有自动复制列表。内部 values 指向外面的 numbers 所指的列表，append 改了这个列表，所以两边都看见新增的 0。字典的赋值、集合的 add 也要考虑这一点。

### 修改对象与重新赋值不同

```python
def replace_inside(values):
    values = [9, 9]
    return values

numbers = [1, 2]
print(replace_inside(numbers))
print(numbers)
```

```text
[9, 9]
[1, 2]
```

这里创建了另一个列表，只让内部 values 指向新列表，没有修改原列表。外面 numbers 仍指向 `[1, 2]`。

要“返回新列表、不改输入”，可以创建一个新容器，把处理结果收集进去：

```python
def doubled_values(values):
    result = []
    for value in values:
        result.append(value * 2)
    return result

numbers = [1, 2, 3]
print(doubled_values(numbers))
print(numbers)
print(doubled_values([]))
```

```text
[2, 4, 6]
[1, 2, 3]
[]
```

result 在每次调用时重新创建，所以不同调用不会共用一个结果列表。空输入不进入循环，直接交回新建的空列表。

需要增删外层元素时，也可以先 `result = values.copy()` 再改 result。不过浅复制只复制外层；如果元素本身是列表或字典，修改元素内容仍可能影响原数据。这里的数字处理没有这个问题。

**就地练习 2：**定义 `increment_values(values)`，把每个数字加 1 后放进新列表。检查 `[0, 2]` 和 `[]`，并打印原列表确认没有修改。

<details>
<summary>参考与核对输出</summary>

```python
def increment_values(values):
    result = []
    for value in values:
        result.append(value + 1)
    return result

values = [0, 2]
print(increment_values(values))
print(values)
print(increment_values([]))
```

```text
[1, 3]
[0, 2]
[]
```

</details>

## 3. 位置、关键字和默认参数：明确哪个数据交给哪个名字

**位置传参**按前后顺序对应；**关键字传参**在调用处写 `参数名=值`，按名字对应。

```python
def format_record(name, score):
    return f"{name}:{score}"

print(format_record("小林", 86))
print(format_record(score=86, name="小林"))
print(format_record("小林", score=86))
```

输出是三行 `小林:86`。第二次虽然 score 写在前面，但关键字已经说明了对应关系。关键字必须使用定义中的形参名，不能把外部变量名当作关键字名称。

普通调用中，位置实参要放在关键字实参前面；同一个参数不能得到两份值：

```python
def format_record(name, score):
    return f"{name}:{score}"

print(format_record("小林", score=86))
# format_record(name="小林", 86)  # SyntaxError：位置参数放在关键字参数后
# format_record("小林", name="小周", score=86)  # TypeError：name 重复赋值
# format_record(student="小林", score=86)  # TypeError：没有 student 这个形参
```

正常代码输出为 `小林:86`。

### 默认参数让调用者可以省略某个值

```python
def is_pass(score, threshold=60):
    return score >= threshold

print(is_pass(59))
print(is_pass(60))
print(is_pass(79, 80))
print(is_pass(threshold=80, score=80))
```

```text
False
True
False
True
```

`threshold=60` 写在定义中，表示调用时没提供 threshold，就用 60；提供了就用实际传入值。内部判断必须写 `score >= threshold`，如果写死成 `score >= 60`，自定义门槛就失效了。

对于本节这种普通形参，必填参数放在有默认值的参数前；`def is_pass(threshold=60, score):` 是语法错误。调用函数时，默认参数照样可以按位置或关键字提供。

**就地练习 3：**写 `has_enough(quantity, minimum=1)`，返回数量是否达到门槛。依次检查数量 0、1，以及 `quantity=3, minimum=4`。

```python

    return quantity >= minimum

print(has_enough(0))
print(has_enough(1))
print(has_enough(minimum=4, quantity=3))
```

输出依次为 `False`、`True`、`False`。

## 4. 默认值在定义时产生：不要让多次调用共用一个意外的列表

默认值的表达式在执行 def 时计算，不是每次调用时再计算：

```python
minimum = 60

def is_pass(score, threshold=minimum):
    return score >= threshold

minimum = 80
print(is_pass(70))
print(is_pass(70, minimum))
```

```text
True
False
```

定义函数时，默认值取到 60。后来外面的 minimum 重新赋值为 80，不会把已经保存的默认值也改成 80。第二次调用明确提供了当前的 minimum，即 80，才使用新门槛。

这一规则在默认值是可变列表时尤其容易出问题：

```python
# 故意展示共享默认列表的问题，不建议照此设计函数。
def collect_bad(item, values=[]):
    values.append(item)
    return values

print(collect_bad("pen"))
print(collect_bad("book"))
```

```text
['pen']
['pen', 'book']
```

`[]` 在定义时创建一次，两次省略 values 的调用用的是同一个列表。第二次调用的结果含有上一次的数据。

想让每次没有提供列表的调用都得到自己的新列表，用 None 作为默认标记，在函数体内创建：

```python
def collect(item, values=None):
    if values is None:
        values = []
    values.append(item)
    return values

print(collect("pen"))
print(collect("book"))
existing = ["bag"]
print(collect("pen", existing))
print(existing)
```

```text
['pen']
['book']
['bag', 'pen']
['bag', 'pen']
```

这次两个省略参数的调用各建一个新列表。最后显式提供 existing，函数仍会修改那个输入列表，因为这里的需求是“加入给定列表”。如果需求是不改输入，应在非 None 时复制外层，再添加。

这里判断 `values is None`，不写 `if not values`：调用者明确传入的空列表也是一个有效列表，不能把它误当作“没有提供”。

**就地练习 4：**定义 `with_item(item, values=None)`。未提供 values 时返回只含 item 的新列表；提供列表时返回增加 item 后的新列表，原列表必须保持不变。连续调用两次，确认不共享上次数据。

<details>
<summary>参考与核对输出</summary>

```python
def with_item(item, values=None):
    if values is None:
        result = []
    else:
        result = values.copy()
    result.append(item)
    return result

print(with_item("pen"))
print(with_item("book"))
values = []
print(with_item("bag", values))
print(values)
```

```text
['pen']
['book']
['bag']
[]
```

</details>

## 5. *args：把任意数量的位置实参收集成元组

有些函数不能提前确定会收到几个数字。定义中的一个星号可以收集多余的位置实参：

```python
def total_numbers(*numbers):
    return sum(numbers)

def received_values(*numbers):
    return numbers

print(total_numbers(2, 3, 4))
print(total_numbers())
print(received_values(2, 3))
print(received_values())
```

```text
9
0
(2, 3)
()
```

调用 `total_numbers(2, 3, 4)` 时，内部 numbers 得到元组 `(2, 3, 4)`；没有数字时得到空元组 `()`。`sum(())` 为 0，所以空调用自然得到 0。

这种形参常写作 `*args`，但 args 不是固定关键字。`*numbers`、`*quantities` 都可以，关键是星号负责收集，名字供函数内部使用。

### 定义处的 * 收集，调用处的 * 拆开

如果已经有一个列表，不需要逐项手写：

```python
def total_numbers(*numbers):
    return sum(numbers)

batches = [2, 4, 1]
print(total_numbers(*batches))
print(total_numbers(*[]))
# total_numbers(batches)  # TypeError：传入的是一个列表实参，不能按这里的数字约定求和
```

```text
7
0
```

调用处 `*batches` 把列表拆开，相当于 `total_numbers(2, 4, 1)`。不带星号就只传入了一个列表，内部 numbers 会是 `([2, 4, 1],)`，这与“每个实参都是数字”的约定不同。

列表和元组都可以这样拆包。星号也可以用于固定参数的调用，但拆开后的数量仍必须匹配固定参数；它不会自动修复参数不足或过多。

**就地练习 5：**写 `multiply_all(*numbers)` 返回所有数字的乘积，约定没有数字时返回 1。检查 `(2, 3, 4)`、没有参数、列表 `[2, 5]` 拆包调用。

<details>
<summary>参考与核对输出</summary>

```python
def multiply_all(*numbers):
    result = 1
    for number in numbers:
        result *= number
    return result

print(multiply_all(2, 3, 4))
print(multiply_all())
values = [2, 5]
print(multiply_all(*values))
```

输出依次为 `24`、`1`、`10`。求和从 0 开始，乘积从 1 开始；初始值取决于实际需求。

</details>

## 6. **kwargs：把任意数量的关键字实参收集成字典

定义中的两个星号把关键字实参收集成字典：

```python
def received_fields(**fields):
    return fields

print(received_fields(name="小林", city="杭州"))
print(received_fields())
```

```text
{'name': '小林', 'city': '杭州'}
{}
```

`name="小林"` 在内部变为字典的一项 `"name": "小林"`。`**kwargs` 是常见名称，`**fields` 同样正确；函数内部按字典方式读取。

例如，缺少姓名时使用“未命名”，缺少城市时使用“未知”：

```python
def build_label(**fields):
    name = fields.get("name", "未命名")
    city = fields.get("city", "未知")
    return name + "@" + city

print(build_label(name="小林", city="杭州", note="加急"))
print(build_label(name="小周"))
print(build_label())
print(build_label(name="", city="杭州"))
```

```text
小林@杭州
小周@未知
未命名@未知
@杭州
```

这里约定字段值都是字符串。没有使用 note，就自然忽略它。get 的默认值只在键缺失时生效；姓名明确提供了空字符串时，仍使用空字符串，不擅自改成“未命名”。

### 调用处的 ** 把字典拆成关键字实参

```python
def build_label(**fields):
    return fields.get("name", "未命名") + "@" + fields.get("city", "未知")

info = {"name": "小林", "city": "杭州"}
print(build_label(**info))
print(build_label(**{}))
# build_label(info)  # TypeError：这里没有用来接收字典的位置形参
```

```text
小林@杭州
未命名@未知
```

`build_label(**info)` 相当于 `build_label(name="小林", city="杭州")`。字典的键必须是字符串；如果把它拆给固定形参函数，键还必须与形参对应。显式关键字与字典拆包不能重复提供同一名字，如 `build_label(name="小周", **info)` 会重复提供 name。

`*` 与 `**` 不要混淆：定义处前者收集位置实参为元组，后者收集关键字实参为字典；调用处则分别把数据拆回对应的实参。

**就地练习 6：**写 `contact_label(**fields)`，取 name 和 phone，缺少时分别为“未命名”和“未提供”，返回 `"姓名:电话"`。用字典拆包调用一次，再检查无参数和已提供空电话的情况。

<details>
<summary>参考与核对输出</summary>

```python

    return fields.get("name", "未命名") + ":" + fields.get("phone", "未提供")

print(contact_label())

```

```text

未命名:未提供
小周:
```

## 7. 函数也能当作数据：把处理规则交给另一段代码

函数本身也可以赋给变量或作为实参传入。先区分有没有调用括号：

```python
def twice(value):
    return value * 2

operation = twice
result = twice(4)
print(operation(3))
print(result)
```

```text
6
8
```

`twice` 表示函数本身，可以以后再调用；`twice(4)` 表示现在调用，得到数字 8。operation 指向那个函数，所以 `operation(3)` 就调用同一个处理规则。

把规则作为参数传入，就能使用同一套循环完成不同处理：

```python
def apply_to_values(values, operation):
    result = []
    for value in values:
        result.append(operation(value))
    return result

def twice(value):
    return value * 2

def add_one(value):
    return value + 1

values = [1, 2, 3]
print(apply_to_values(values, twice))
print(apply_to_values(values, add_one))
print(values)
print(apply_to_values([], twice))
```

```text
[2, 4, 6]
[2, 3, 4]
[1, 2, 3]
[]
```

第一次调用按如下步骤执行：

1. values 接到原列表，operation 接到 twice 函数本身。
2. 新建 result；循环第一项 value 为 1。
3. 调用 `operation(1)`，也就是 `twice(1)`，取得 2，再 append 到 result。
4. 下一项以相同方式取得 4，再下一项取得 6。
5. 循环结束后 return 新列表 `[2, 4, 6]`。

`apply_to_values(values, twice)` 是传入函数。`apply_to_values(values, twice(2))` 会先取得 4，再把数字 4 传给 operation，后续 `operation(value)` 就会因为数字不能被调用而报错。写 `twice()` 也不对，它缺少 value 实参。

这里约定 operation 接收一个元素、返回处理结果，并且不修改该元素。外层新列表并不自动复制复杂元素；如果规则内部修改传入的字典或列表，原数据仍可能受影响。

**就地练习 7：**使用本节的 apply_to_values，另外定义 `clean_name(raw)`，把 `[" Alice Smith ", " BOB "]` 转成 `["alice smith", "bob"]`。这里只清洗，不删除元素。

<details>
<summary>参考与核对输出</summary>

```python
def apply_to_values(values, operation):
    result = []
    for value in values:
        result.append(operation(value))
    return result

def clean_name(raw):
    return raw.strip().lower()

names = [" Alice Smith ", " BOB "]
print(apply_to_values(names, clean_name))
print(names)
```

```text
['alice smith', 'bob']
[' Alice Smith ', ' BOB ']
```

</details>

## 8. lambda 与 sorted 的 key：告诉排序工具“比较哪一项”

**lambda**可以写出一个只含一个表达式的小函数。语法是 `lambda 参数: 表达式`，表达式的结果自动作为返回值，不写 return。

```python
twice = lambda value: value * 2
print(twice(4))
```

输出为 `8`。它与定义 `def twice(value): return value * 2` 的计算作用相同。需要循环、多条语句或复杂分支时，使用 def 更容易读。

排序记录时，只按整条元组默认排序往往不符合需要。例如 `(姓名, 分数)` 的默认排序会先看姓名；要按分数排，需要给 sorted 提供 key。

**key 函数**接收一条记录，返回“这条记录用于比较的值”。返回的值叫排序键；最终结果仍保存原来的整条记录。

先用 def 理解：

```python
def score_key(row):
    return row[1]

rows = [("小林", 80), ("小周", 95), ("小陈", 80)]
ranked = sorted(rows, key=score_key, reverse=True)
print(ranked)
print(rows)
```

```text
[('小周', 95), ('小林', 80), ('小陈', 80)]
[('小林', 80), ('小周', 95), ('小陈', 80)]
```

内部比较依据可以这样列出：

| 原记录 | key 返回的值 |
|---|---:|
| `("小林", 80)` | 80 |
| `("小周", 95)` | 95 |
| `("小陈", 80)` | 80 |

`reverse=True` 把排序键按从大到小排列。key 传的是函数本身，让 sorted 负责给它每条记录；这里不能写成 `key=score_key()`。

把只取第二项的简单规则写成 lambda：

```python
def rank_scores(rows):
    return sorted(rows, key=lambda row: row[1], reverse=True)

rows = [("小林", 80), ("小周", 95), ("小陈", 80)]
print(rank_scores(rows))
print(rows)
print(rank_scores([]))
```

```text
[('小周', 95), ('小林', 80), ('小陈', 80)]
[('小林', 80), ('小周', 95), ('小陈', 80)]
[]
```

`row` 是 lambda 的参数，每次接收一条元组记录；`row[1]` 读取其中的分数。变量名可以换成你习惯的名字。

Python 排序是**稳定的**：排序键相同的记录，保留排序前的相对顺序。所以两个 80 分仍然是小林在小陈前面；降序也遵守这一规则。

### sorted 与 list.sort 不要用错

`sorted(rows, ...)` 返回新列表，不改 rows。`rows.sort(...)` 直接修改 rows，调用结果为 None。所以 `return rows.sort(...)` 同时不满足“返回新列表”和“不改原列表”两个要求。

空列表用 sorted 得到 `[]`，不用专门构造一个非空输入来避开它。实际要求不止看屏幕结果，还要分别检查返回值类型与原数据。

**就地练习 8：**输入 `(商品名, 数量)` 列表，按数量升序返回新列表，要求使用 lambda；同数量保留原顺序。检查 `[("pen", 2), ("bag", 1), ("book", 2)]` 和空列表。

<details>
<summary>参考与核对输出</summary>

```python
def rank_quantities(rows):
    return sorted(rows, key=lambda row: row[1])

rows = [("pen", 2), ("bag", 1), ("book", 2)]
print(rank_quantities(rows))
print(rows)
print(rank_quantities([]))
```

```text
[('bag', 1), ('pen', 2), ('book', 2)]
[('pen', 2), ('bag', 1), ('book', 2)]
[]
```

</details>

### max、min也能使用key：按指标找整条记录

列表模块学过max和min找最大、最小数字。数据是一条记录时，也可以用key告诉它“比较哪个指标”：

```python
points = [(1, 2), (4, 0), (-3, 5), (0, 0), (2, -7)]
farthest = max(points, key=lambda point: point[0] ** 2 + point[1] ** 2)
nearest = min(points, key=lambda point: point[0] ** 2 + point[1] ** 2)
print(farthest)  # (2, -7)
print(nearest)   # (0, 0)
print(max([], key=lambda point: point[0] ** 2 + point[1] ** 2, default=None))
```

最后一行输出None。坐标 `(x, y)` 到原点的距离平方是 `x ** 2 + y ** 2`，比较距离平方就能判断远近。本例最大指标是53，但max返回的是对应的整条坐标 `(2, -7)`，不是53。

同样可以先定义普通函数，再把函数本身传给key。最大指标相同的多条记录，max返回最先遇到的一条；如果题目要求所有并列最高，要另用循环收集。空输入直接max/min会报ValueError；这里的default指定“没有元素时返回None”，或者可以在调用前先判断非空。这补齐了后续坐标综合题的前置。

## 9. 多字段排序：总量降序，同总量按名字升序

“同分保持原顺序”与“同分按名字排序”是不同要求，要先读清规则。这一节用只含英文字母的商品名，方便观察名字升序。

元组会先比较第一项；第一项相同，再比较第二项。因此可以让 key 返回一个元组：

```python
rows = [("pen", 5), ("bag", 5), ("book", 2)]
ranked = sorted(rows, key=lambda row: (-row[1], row[0]))
print(ranked)
print(rows)
```

```text
[('bag', 5), ('pen', 5), ('book', 2)]
[('pen', 5), ('bag', 5), ('book', 2)]
```

三个键分别是 `(-5, "pen")`、`(-5, "bag")`、`(-2, "book")`。默认升序先把 -5 排在 -2 前，相当于数量大的先排；两个 -5 再比较名字，bag 在 pen 前。

这里的负号适用于数值。不要对整个 `(数量, 名字)` 使用 `reverse=True` 并期望数量降序、名字升序；整体反向会让两个字段的方向都反过来。

另一种办法是利用稳定排序，**先排次要字段，再排主要字段**：

```python
rows = [("pen", 5), ("bag", 5), ("book", 2)]
by_name = sorted(rows, key=lambda row: row[0])
ranked = sorted(by_name, key=lambda row: row[1], reverse=True)
print(by_name)
print(ranked)
```

```text
[('bag', 5), ('book', 2), ('pen', 5)]
[('bag', 5), ('pen', 5), ('book', 2)]
```

第一步把名字排好。第二步按数量降序，数量相同的 bag 与 pen 保持第一步产生的相对顺序，于是同数量仍是名字升序。这与一次返回复合排序键的结果相同。

若数据来自 `{商品名: 数量}` 字典，先使用 `totals.items()` 取得 `(商品名, 数量)` 对，再把同样的 key 交给 sorted；得到的结果是元组列表，原字典不变。

**就地练习 9：**把 `[("z", 2), ("a", 2), ("b", 5)]` 按数量降序、同数量名字升序排列。先用元组 key，再用两次稳定排序，核对结果相同。

<details>
<summary>参考与核对输出</summary>

```python
rows = [("z", 2), ("a", 2), ("b", 5)]
first = sorted(rows, key=lambda row: (-row[1], row[0]))
second = sorted(rows, key=lambda row: row[0])
second = sorted(second, key=lambda row: row[1], reverse=True)
print(first)
print(second)
```

两行都是 `[('b', 5), ('a', 2), ('z', 2)]`。

</details>

## 10. 组合参数、筛选和汇总：每次调用都重新处理实际输入

现在把已经学过的循环、默认参数和多返回值组合起来。输入约定：orders 是 `(商品名, 数量)` 元组列表；数量和门槛为非负整数。保留数量达到门槛的记录，返回 `(保留条数, 保留数量之和)`。

```python
def summarize_orders(orders, min_quantity=1):
    count = 0
    quantity_sum = 0
    for name, quantity in orders:
        if quantity >= min_quantity:
            count += 1
            quantity_sum += quantity
    return count, quantity_sum

orders = [("pen", 2), ("book", 0), ("bag", 3)]
print(summarize_orders(orders))
print(summarize_orders(orders, min_quantity=3))
print(summarize_orders(orders, min_quantity=0))
print(summarize_orders(orders, min_quantity=9))
print(summarize_orders([]))
print(orders)
```

```text
(2, 5)
(1, 3)
(3, 5)
(0, 0)
(0, 0)
[('pen', 2), ('book', 0), ('bag', 3)]
```

以默认门槛 1 为例：pen 的 2 达到门槛，count 从 0 变成 1，数量和从 0 变成 2；book 的 0 不符合，不累计；bag 的 3 符合，count 变成 2，数量和变成 5。循环结束再返回。

这里 count 每保留一条加 1，quantity_sum 加这一条的数量；记录条数与数量总和不是同一个统计。两个累计变量都在函数内、循环前初始化，所以多次调用互不沿用上次结果。门槛 0 时，0 数量记录也保留；没有符合项或输入为空时，初始的 `(0, 0)` 正好符合规则。

### 子函数也要接到实际门槛

需要先筛选，再按名字累计时，让数据按处理顺序传递：

```python
def select_records(records, minimum=1):
    selected = []
    for name, quantity in records:
        if quantity >= minimum:
            selected.append((name, quantity))
    return selected

def total_by_name(records):
    totals = {}
    for name, quantity in records:
        totals[name] = totals.get(name, 0) + quantity
    return totals

def summarize_by_name(records, minimum=1):
    selected = select_records(records, minimum=minimum)
    return total_by_name(selected)

records = [("pen", 1), ("pen", 2), ("book", 3)]
print(summarize_by_name(records))
print(summarize_by_name(records, minimum=2))
print(summarize_by_name(records, minimum=9))
print(summarize_by_name([]))
```

```text
{'pen': 3, 'book': 3}
{'pen': 2, 'book': 3}
{}
{}
```

`minimum=minimum` 左边是被调用函数的形参名，右边是当前函数收到的值。只写 `select_records(records)` 会一直使用子函数默认值 1，外面传入 2 也不会改变筛选规则。

筛选作用于单条记录，因此先筛选再累计。门槛 2 时，pen 的第一条 1 被排除，只累计第二条 2；若先把 pen 合为 3 再判断门槛，就实现了不同的需求。

**就地练习 10：**保留上面的三个函数，分别使用门槛 0、1、3、9 调用 `summarize_by_name([("pen", 0), ("pen", 2), ("book", 3)])`。核对每次结果，并确认原列表没有修改。

<details>
<summary>核对结果</summary>

- 门槛 0：`{'pen': 2, 'book': 3}`，其中 pen 的 0 与 2 都参与累计。
- 门槛 1：`{'pen': 2, 'book': 3}`，pen 的 0 被筛掉。
- 门槛 3：`{'book': 3}`。
- 门槛 9：`{}`。

前两次累计结果相同，但保留记录条数分别是 3 与 2。要统计记录条数，读取筛选后列表的 len；要统计不同商品数，读取累计字典的 len。原列表应仍为 `[('pen', 0), ('pen', 2), ('book', 3)]`。

</details>

## 11. 选学：递归是函数调用自己

这一节可以先跳过。递归适合处理一些“问题能缩小成同一种小问题”的任务；先掌握普通函数、循环和数据处理，就能完成本页的必做习题。

例如阶乘：3 的阶乘是 `3 × 2 × 1`，并且约定 0 的阶乘为 1。输入只接受非负整数：

```python
def factorial(number):
    if number == 0:
        return 1
    return number * factorial(number - 1)

print(factorial(3))
print(factorial(0))
```

```text
6
1
```

`factorial(3)` 的调用先展开，再逐层交回结果：

```text
factorial(3) 等待 3 × factorial(2)
    factorial(2) 等待 2 × factorial(1)
        factorial(1) 等待 1 × factorial(0)
            factorial(0) 返回 1
        factorial(1) 返回 1 × 1 = 1
    factorial(2) 返回 2 × 1 = 2
factorial(3) 返回 3 × 2 = 6
```

需要同时满足两个条件：有能结束调用的停止条件；每次调用都更接近停止条件。这里 number 每次减 1，从非负整数最终到 0。

不要把负数或小数传给这个例子：它们不符合输入约定，可能无法到达 0。Python 的递归深度有限，过深会出现 `RecursionError`，所以这也不是用来处理任意大输入的阶乘工具。看到递归时先画调用过程，再考虑是否普通循环更直接。
