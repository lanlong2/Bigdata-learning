# 函数基础：把一段处理过程起个名字

对应P57～62。先会参数、返回值、说明文档和嵌套调用，再进入函数进阶。

## 定义、调用、参数

```python
def add(a, b):
    """把两个数相加，并返回结果。"""
    return a + b

result = add(2, 3)
print(result)  # 5
```

def这一行是在定义，不会立即计算。a、b是参数名；调用时2、3传进去。冒号后换行，函数内部统一缩进4个空格。

## print 和 return

- print：给人看，会向终端输出文字。
- return：把结果交回调用函数的地方；执行后离开当前函数。
- 没写return，或者只写return而不带值，调用结果是None。

```python
def show_sum(a, b):
    print(a + b)

result = show_sum(2, 3)  # 这里先输出5
print(result)           # 然后输出None
```

如果下一步还要计算，通常让函数return结果，由外面决定是否print。不要把None当作0。

## 先说明输入与边界

```python
def average(scores):
    """scores是数字列表；空列表返回None，非空返回平均数。"""
    if not scores:
        return None
    return sum(scores) / len(scores)

print(average([60, 80]))  # 70.0
print(average([]))        # None
```

先判断空列表，避免除以0。函数说明写清“传什么、返回什么、特殊情况怎样处理”，不必写很多行。

## 嵌套调用

```python
def clean_name(name):
    return name.strip().lower()

def greeting(name):
    return "你好，" + clean_name(name)

print(greeting(" Alice "))  # 你好，alice
```

按调用顺序追踪：greeting收到文本 → clean_name返回干净文本 → 拼接 → 返回。不要仅按文件从上到下想象所有函数都会执行。

## 写代码时检查

函数是否被调用；参数数量是否匹配；return是否缩进在函数里；后续代码拿到的是预期类型还是None。
