## 1. 元组是什么，什么时候用它

**元组也是有顺序的容器，类型名是 `tuple`。**与列表相比，它的外层结构不能原地修改：不能替换某个位置，不能在原元组里增加或删除元素。

例如一个二维坐标固定有 x、y 两个位置，一条简单的成绩记录固定有姓名、总分、平均分三个位置。可以用元组表达这种固定结构：

```python
point = (3, 4)
record = ("小林", 240, 80.0)
empty = ()

print(point)
print(type(point))
print(len(record))
print(empty)
```

输出：

```text
(3, 4)
<class 'tuple'>
3
()
```

创建时通常用圆括号包住元素，逗号分隔。元组里的元素也可以是不同类型。

列表和元组如何选择，是根据用途作判断，不是 Python 强制规定。很多可以增减的分数常用列表保存；一个字段位置固定的记录常用元组保存。元组也可以保存同类数据，列表也可以保存记录。

## 2. 一个元素的元组，必须有逗号

括号也能表示运算分组，所以 `(7)` 只是整数 7。要创建只含 7 的元组，写成 `(7,)`。

```python
a = (7)
b = (7,)
c = ()
d = ("abc")
e = ("abc",)
f = 1, 2

print(type(a))
print(type(b), len(b))
print(type(c), len(c))
print(type(d), len(d))
print(type(e), len(e))
print(f)
```

输出：

```text
<class 'int'>
<class 'tuple'> 1
<class 'tuple'> 0
<class 'str'> 3
<class 'tuple'> 1
(1, 2)
```

`("abc")` 没有逗号，仍是长度为 3 的字符串；`("abc",)` 是长度为 1 的元组，唯一元素是字符串 `"abc"`。`f = 1, 2` 说明逗号可以构成元组，括号在这里能省略。初学时保留括号更容易读。

整数没有容器长度，`len(a)` 会报 `TypeError`。空元组直接写 `()`，不是写一个空字符串。

**小练习 1：**创建“只含文本 `"Python"`”的元组，打印它的长度，再取出唯一元素并打印这个元素的长度。

```python
items = ("Python",)
print(len(items))
print(len(items[0]))
```

输出 `1` 和 `6`。外层有一个元素，这个元素本身是六字符的字符串。

## 3. 读取、切片、计数与拼接

学过列表后，元组的读取规则不陌生：索引从 0 开始，`-1` 是末尾，切片包含起始、不包含结束。

```python
t = (10, 20, 20, 30)
print(t[0])
print(t[-1])
print(t[1:3])
print(len(t))
print(20 in t)
print(t.count(20))
print(t.index(20))
print(t + (40,))
print((0,) * 3)
print(t)
```

输出：

```text
10
30
(20, 20)
4
True
2
1
(10, 20, 20, 30, 40)
(0, 0, 0)
(10, 20, 20, 30)
```

`count` 统计某个值出现的次数，`index` 得到第一次匹配的索引。找不到时，`count` 是 0，`index` 会报 `ValueError`。

切片结果仍是元组。`t + (40,)` 是拼接得到一个新的结果，并没有给原来的 `t` 增加元素；要让 `t` 接住结果，需要另写赋值。`(0,) * 3` 是重复。

元组也能逐个遍历：

```python
t = (10, 20, 30)
for value in t:
    print(value)
```

输出三行，依次为 `10`、`20`、`30`。越界索引会报 `IndexError`，空元组也没有最后一个元素，和列表的边界相同。

## 4. 不可变的外层，不代表里面的列表不能变

```python
t = ("小林", [80, 90])
t[1].append(100)
print(t)

# t[0] = "小陈"  # TypeError：不能替换元组的位置
# t[1] = [60]    # TypeError：也不能换掉这个位置里的列表
# t.append(1)    # AttributeError：元组没有 append 方法
# t.sort()       # AttributeError：元组没有 sort 方法
```

输出：

```text
('小林', [80, 90, 100])
```

`t[1]` 取出来的是列表，调用的是**这个列表的** `append`。元组仍有两个位置，第二个位置仍指向同一份列表；变化发生在列表内部。`t[1] = [60]` 则试图让元组的位置改为另一份列表，元组不允许。

因此不能简单说“元组中所有内容永远不变”。准确说法是：**元组的外层元素不能原地增删或替换，元素本身如果是可变对象，它的内部仍可能变化。**

错误类型也要区分：索引赋值不支持，是 `TypeError`；根本没有某个方法，是 `AttributeError`。

## 5. 转换与排序：得到新容器

`list(元组)` 把元素装进列表，`tuple(列表)` 把元素装进元组。

```python
t = (3, 1, 2)
values = list(t)
values[0] = 9
new_tuple = tuple(values)

print(t)
print(values)
print(new_tuple)
print(sorted(t))
print(tuple(sorted(t)))
```

输出：

```text
(3, 1, 2)
[9, 1, 2]
(9, 1, 2)
[1, 2, 3]
(1, 2, 3)
```

`sorted(t)` 不改原元组，返回的是**列表**。如果需要排序后的元组，再用 `tuple` 转换。多个调用连在一起时，先计算里面的 `sorted(t)`，再把结果交给外面的 `tuple`。

转换字符串时，会按字符取元素：

```python
print(tuple("hi"))
print(list(("hello", "world")))
```

输出：

```text
('h', 'i')
['hello', 'world']
```

### 转成元组不是深度备份

```python
nums = [3, 1, 2]
snapshot = tuple(nums)
nums.sort()
print(nums)
print(snapshot)

inner = [1]
source = [inner]
nested_snapshot = tuple(source)
inner.append(2)
print(nested_snapshot)
```

输出：

```text
[1, 2, 3]
(3, 1, 2)
([1, 2],)
```

第一部分创建了新的外层元组，保留当时数字的排列。排序原列表不会重排元组。第二部分的内部列表仍共享，内部变化会在元组里被看到。`tuple` 不是把所有内部数据都复制一份。

## 6. 拆包：一次把元素分给多个变量

**拆包**是把容器中的元素按顺序分别交给几个变量。先看不用拆包的写法：

```python
point = (3, 4)
x = point[0]
y = point[1]
print(x, y)
```

输出是 `3 4`。用拆包可以写成：

```python
point = (3, 4)
x, y = point
print(x, y)
```

输出相同。左边的 `x, y` 是两个接收位置，右边的 `point` 有两个元素，第一个给 x，第二个给 y。

普通拆包要求变量数与元素数相等，少一个或多一个都报 `ValueError`：

```python
info = ("小林", 18, "计算机")
name, age, major = info
print(name, age, major)

# name, age = info  # ValueError：三个元素，只有两个接收位置
```

输出是 `小林 18 计算机`。拆包不只支持元组，也能用于列表、字符串等能依次取值的对象，但元素数量仍要符合接收规则。

### 一行交换两个变量

```python
x = 1
y = 2
x, y = y, x
print(x, y)
```

输出是 `2 1`。右边先取到原来的 y、x，也就是 2、1，再分别赋给左边的 x、y；不是先把 x 改掉再去计算右边的 x。

### 星号接住剩余部分

```python
info = ("小林", 18, "计算机", 3.8)
name, *rest = info
*head, gpa = info
first, *middle, last = info

print(name, rest)
print(head, gpa)
print(first, middle, last)
print(type(rest))
```

输出：

```text
小林 [18, '计算机', 3.8]
['小林', 18, '计算机'] 3.8
小林 [18, '计算机'] 3.8
<class 'list'>
```

左边带 `*` 的变量把剩余元素接成**列表**，即使原容器是元组。每一层拆包最多只能有一个这样接收剩余元素的变量。剩余部分也可以为空，例如 `first, *rest = (10,)` 中 `rest` 是 `[]`。

这里是赋值左边的星号。函数调用中还会有另一种星号用法，在函数进阶学习，不要提前混为一谈。

## 7. enumerate：在逐个取值时附上编号

`enumerate(容器)` 把每个元素配上编号。默认编号从 0 开始，每次取到的都是一个二元素元组，形式是 `(编号, 元素)`。

```python
names = ["小林", "小陈", "小王"]
numbered = list(enumerate(names))
print(numbered)
```

输出：

```text
[(0, '小林'), (1, '小陈'), (2, '小王')]
```

`enumerate` 本身不是列表，它会在被读取时依次提供这些配对；这里用 `list` 把全部配对收集成列表，方便观察。

循环每次拆开一个配对：

```python
names = ["小林", "小陈", "小王"]
for i, name in enumerate(names):
    print(i, name)
```

输出：

```text
0 小林
1 小陈
2 小王
```

`i, name` 就是在拆包。需要人类习惯的第 1、第 2名时，第二个参数指定起始编号：

```python
names = ["小林", "小陈"]
for number, name in enumerate(names, 1):
    print(f"第{number}位：{name}")
```

输出：

```text
第1位：小林
第2位：小陈
```

起始编号改为 1，并没有改变列表自己的索引，`names[0]` 仍是小林。编号用来显示，索引用来访问，不要把它们直接混用。

## 8. 在循环中拆记录，理解嵌套拆包

把多条元组记录放进列表，就是“列表装多行，元组装每一行的字段”。

```python
rows = [("小林", 88), ("小陈", 95)]
total = 0
for name, score in rows:
    print(f"{name}：{score}")
    total = total + score
print(f"平均分：{total / len(rows):.1f}")
```

输出：

```text
小林：88
小陈：95
平均分：91.5
```

每一轮取一个元组，把姓名给 `name`，分数给 `score`。字段数量必须和接收变量数量匹配。

再加编号时，先把两个步骤展开：

```python
rows = [("小林", 88), ("小陈", 95)]
for number, row in enumerate(rows, 1):
    name, score = row
    print(number, name, score)
```

输出：

```text
1 小林 88
2 小陈 95
```

同样的步骤可以写成 `for number, (name, score) in enumerate(rows, 1)`。外层配对是 `(编号, 一条记录)`，内层记录又是 `(姓名, 分数)`。这叫**嵌套拆包**，按两层结构对应接收。

```python
rows = [("小林", 88), ("小陈", 95)]
for number, (name, score) in enumerate(rows, 1):
    print(number, name, score)
```

输出和上例相同。读不顺时，先展开为上一段写法，不必强求写在一行。

推导式里的 `for` 同样能拆包：

```python
points = [(1, 2), (4, 0), (-3, 5)]
swapped = [(y, x) for x, y in points]
first_quadrant = [(x, y) for x, y in points if x > 0 and y > 0]
xs = [x for x, y in points]
ys = [y for x, y in points]

print(swapped)
print(first_quadrant)
print(xs)
print(ys)
```

输出：

```text
[(2, 1), (0, 4), (5, -3)]
[(1, 2)]
[1, 4, -3]
[2, 0, 5]
```

每轮先拆坐标，再按条件筛选，最后把表达式放进新列表。`swapped` 的外层是列表，内部元素仍是元组。

## 9. zip：把几列按位置配在一起

`zip` 把几个对象的第一个元素配一起，再把第二个配一起，依次继续。每组结果是元组。

```python
names = ["小林", "小陈"]
scores = [88, 95]
rows = list(zip(names, scores))
print(rows)

for name, score in zip(names, scores):
    print(f"{name}：{score}")
```

输出：

```text
[('小林', 88), ('小陈', 95)]
小林：88
小陈：95
```

`zip` 本身也不是列表，它按需提供配对；要保存全部结果，用 `list(zip(...))`。如果直接循环使用，就不用先转成列表。

### 长度不一致时，默认在最短一列结束

```python
names = ["小林", "小陈"]
scores = [88]
print(list(zip(names, scores)))
```

输出是 `[('小林', 88)]`。小陈不会得到分数，也不会因为多了一个姓名而默认报错。做“每人必须有一份分数”的任务时，要先检查列长度相等，不能让缺数据静悄悄地被忽略。

### 配对对象读过以后不会自动从头再来

```python
pairs = zip([1, 2], [10, 20])
print(list(pairs))
print(list(pairs))
```

输出：

```text
[(1, 10), (2, 20)]
[]
```

第一遍已读取完。像这样逐个提供值、记录读到哪里且不会自动重来的对象叫**迭代器**。`enumerate` 创建的对象也有这个特性。要重复使用结果，先保存成列表；要重新配对，就重新调用 `zip`。

### 从两列还原坐标点

```python
points = [(1, 2), (4, 0), (-3, 5)]
xs = [x for x, y in points]
ys = [y for x, y in points]
restored = list(zip(xs, ys))
labels = [f"P{i}" for i in range(len(points))]

print(restored)
print(restored == points)
print(list(zip(labels, points)))
```

输出：

```text
[(1, 2), (4, 0), (-3, 5)]
True
[('P0', (1, 2)), ('P1', (4, 0)), ('P2', (-3, 5))]
```

`restored == points` 比较内容是否相同，不代表两个变量指向同一个列表。最后一行的外层列表装了三条记录，每条记录里的第二个字段又是坐标元组。

习题中的 `zip(*points)` 还有**调用时展开参数**这一步，和左边的星号拆包不同。先学[函数进阶](06_函数进阶.md)的参数展开，再到[容器综合](07_容器综合与拓展.md)理解行列互换；现在不要求提前掌握这个简写。

## 10. 修改列表里的某条元组记录

列表里的元素是元组时，要分别判断改哪一层：外层列表可以替换元素，内层元组不能替换自己的元素。

```python
points = [(1, 2), (-3, 5)]
old_point = points[1]

# points[1][0] = 30  # TypeError：想改的是内层元组

temporary = list(old_point)
temporary[0] = 30
points[1] = tuple(temporary)

print(old_point)
print(points)
```

输出：

```text
(-3, 5)
[(1, 2), (30, 5)]
```

先把旧点的值装进新列表，修改列表，再转成新元组，最后替换外层列表里的整条记录。旧元组没有被修改。已经知道新字段时，也可以直接 `points[1] = (30, old_point[1])`。

**小练习 4：**用 `[("小林", 80), ("小陈", 90)]`，创建小林分数为 85 的新元组并替换第一条记录，保留变量 `old_record` 用来打印原记录。

<details>
<summary>参考写法</summary>

```python

old_record = records[0]
records[0] = (old_record[0], 85)
print(old_record)
print(records)
```

输出 `('小林', 80)` 和 `[('小林', 85), ('小陈', 90)]`。

</details>
