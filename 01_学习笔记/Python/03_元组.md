# 元组：固定外层结构，不代表内部一切都不能变

练习入口：[字符串与元组习题册](../../02_习题册/Python/02_字符串与元组/README.md)。
先分清 `(7)`、`(7,)`、`()`，再学拆包和嵌套。

## 9. 元组是什么

元组是**用小括号 `()` 包起来的、装好就不能再改的一组数据**。

形象理解：普通收纳箱（列表）随便加随便删；元组是**焊死的收纳箱**——东西一旦装好，箱子就焊上了，只能看不能动。

```python
point = (3, 4)                   # 一个坐标
rgb = (255, 128, 0)              # 一个颜色
person = ("张三", 18, "男")       # 一条记录
empty = ()                       # 空元组
```

**元组的两个关键特性**：

| 特性 | 含义 |
|------|------|
| **有序** | 元素有固定先后顺序，每个位置有编号（和字符串、列表一样） |
| **不可变** | 创建之后**不能增、不能删、不能改** |

## 10. 创建元组的三个坑 ⚠️

**坑1：单元素元组必须带逗号**

```python
x = (7)        # ⚠️ 这是【整数 7】，括号被当成数学括号了
y = (7,)       # ✓ 这才是元组，逗号才是元组的灵魂
type(x)        # <class 'int'>
type(y)        # <class 'tuple'>
len(y)         # 1
```

> 🔑 **单元素元组要带逗号；空元组是例外，直接写 ()。**

**坑2：括号可以省略**

```python
t = 1, 2, 3           # ✓ 这就是元组 (1, 2, 3)
a, b = 1, 2           # 这一行的本质就是元组拆包
def f():
    return 1, 2       # 函数"返回多个值"，其实是返回了一个元组
```

**坑3：元组不可变，但里面装的可变对象还能变**（很爱考）

```python
t = (1, 2, [3, 4])
t[0] = 99          # ✗ TypeError: 'tuple' object does not support item assignment
t[2].append(5)     # ✓ 居然成功！t 变成 (1, 2, [3, 4, 5])
```

**为什么？** 焊死的是**格子**——每个格子里放的东西不能被换成别的东西。但如果某个格子里放的是一个**袋子（列表）**，你换不掉这个袋子，却可以往袋子里塞东西。

## 11. 元组的读操作：会读列表就会读元组

```python
t = (10, 20, 30, 40, 50)

t[0]           # 10
t[-1]          # 50
t[1:3]         # (20, 30)     切片结果还是【元组】
len(t)         # 5
20 in t        # True
t + (60,)      # (10,20,30,40,50,60)  拼接会生成【新元组】，原来的没变
(0,) * 3       # (0, 0, 0)            重复

for x in t:            # 遍历，和列表写法完全相同
    print(x)
```

## 12. 元组的方法：只有两个！

```python
t = (1, 2, 2, 3)
t.count(2)      # 2    某个值出现几次
t.index(2)      # 1    第一次出现的位置
```

凡是"修改"类的操作，元组一律没有：

```python
t.append(4)     # ✗ AttributeError: 'tuple' object has no attribute 'append'
t.sort()        # ✗ 同样没有
sorted(t)       # ✓ sorted() 可以用！它不改原件，返回一个【新列表】
```

## 13. 拆包（unpacking）⭐ 元组最香的用法

把元组里的值**一次性拆给多个变量**：

```python
point = (3, 4)
x, y = point            # x=3, y=4   ← 变量个数必须和元素个数【严格相等】，多一个少一个都报错

a, b = 1, 2
a, b = b, a             # ⭐ 交换两个变量，不需要临时变量
```

**星号拆包**（吃掉剩下的，剩下的会装进**列表**）：

```python
first, *rest = (10, 20, 30, 40)
print(first, rest)      # 10 [20, 30, 40]

*head, last = (10, 20, 30)
print(head, last)       # [10, 20] 30
```

**函数返回多个值 = 返回一个元组**：

```python
def min_max(nums):
    return min(nums), max(nums)     # 返回的是元组 (2, 9)

lo, hi = min_max([4, 9, 2])         # 直接拆包接住
print(lo, hi)                       # 2 9
```

**其实你早就在用元组了**：

```python
for i, name in enumerate(["张三", "李四"]):
    ...      # enumerate 每轮吐出的 (0, "张三") 就是元组，i, name 就是在拆包

for k, v in {"x": 1, "y": 2}.items():
    ...      # items() 吐出的也是元组
```

## 14. 为什么要用元组？（新手最大的疑问）

| 理由 | 说明 |
|------|------|
| **固定外层结构** | 不能替换、增加、删除元组元素；如果元素本身是列表，列表内部仍能变化 |
| **元素都可哈希时能当字典的 key** | 列表不行：`{[0,0]: "原点"}` 直接报 `unhashable type: 'list'`；`{(0,0): "原点"}` 完全没问题 |
| **元素都可哈希时能放进集合** | `{(1,2), (1,2), (3,4)}` → `{(1,2), (3,4)}` |
| **性能取决于实现与用法** | 不记固定字节数或速度倍数，先根据数据含义选择容器 |
| **表达"结构"而不是"集合"** | 列表装"同类的很多个"，元组装"一件事的几个字段" |

> 💡 判断标准：`[88, 92, 79]` 用列表（都是分数，同类并列）；`("张三", 18, "男")` 用元组（姓名/年龄/性别，各是各的字段）。

## 字典键的条件

字典键必须可哈希。字符串、整数通常可以；列表不可以；元组要检查所有元素是否也可哈希。

```python
locations = {(0, 0): "原点"}  # 可以
# bad = {(0, [1]): "示例"}   # TypeError：里面有列表
```

## tuple() 不是深度备份

```python
inner = [1]
snapshot = tuple([inner])
inner.append(2)
print(snapshot)  # ([1, 2],)，内部列表仍共享
```

由纯数字构成的列表转成元组后，重新排序原列表不会影响这个元组；不要把这个特例理解为任意数据都得到不会变化的备份。
