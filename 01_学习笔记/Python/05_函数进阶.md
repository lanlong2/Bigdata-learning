# 函数进阶：参数怎样传，变量在哪里生效

对应P63～70。递归可先选学，不作为文件处理的门槛。

## 局部变量和参数

```python
count = 10
def add_one(count):
    count = count + 1
    return count

print(add_one(3))  # 4
print(count)       # 10
```

函数参数count是函数内部的名字，给它重新赋值不等于修改外面的count。初学时优先用参数传入、return传出，少依赖global。
传入列表时，若在函数里append或修改元素，会影响同一个列表；“局部变量”不代表传入对象自动复制。

## 位置参数、关键字参数与默认值

```python
def is_pass(score, threshold=60):
    return score >= threshold

print(is_pass(60))                  # True
print(is_pass(threshold=80, score=75))  # False
```

位置参数按位置对应；关键字参数按名字对应。普通调用中位置参数放在关键字参数前，不能给同一个参数重复赋值。
默认参数先用数字、字符串或None；避免把可变列表直接写成默认值，以免多次调用共享同一个列表。

## 任意数量的位置参数

```python
def total(*numbers):
    return sum(numbers)

print(total(2, 3, 4))  # 9
print(total())        # 0
```

numbers在函数内是元组。调用时分别传值；已有列表可以用total(*values)拆开。

## 任意数量的关键字参数

```python
def make_label(**fields):
    return fields.get("name", "未命名") + "@" + fields.get("city", "未知")

print(make_label(name="小林", city="杭州"))  # 小林@杭州
```

fields是字典。*接位置参数为元组，**接关键字参数为字典。

## 函数也可以作为参数

```python
def twice(x):
    return x * 2

def apply_one(value, operation):
    return operation(value)

print(apply_one(4, twice))  # 8
```

传twice是传函数本身，传twice(4)是先调用再传结果，要分清括号。

## lambda 和排序

```python
rows = [("小林", 80), ("小周", 95)]
ranked = sorted(rows, key=lambda row: row[1], reverse=True)
print(ranked)  # [('小周', 95), ('小林', 80)]
```

lambda这里只提供一个简单的“取分数”函数。逻辑复杂时用def更清楚。
sorted返回新列表；相同排序键会保持原先的相对顺序。

## 递归先掌握两个条件

递归是函数调用自己。必须有停止条件，并且每次调用要更接近停止条件。深度有限，不能把无限递归当循环替代。
