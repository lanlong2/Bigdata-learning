## 1. 先按需求选择容器

容器是保存一组数据的类型。区别不只是括号长得不同，更在于怎样查找、是否允许重复和是否要保留顺序。

| 类型 | 适合保存什么 | 怎样读取 | 能否改自身 | 重复与顺序 |
|---|---|---|---|---|
| str字符串 | 一段文本 | 下标、切片 | 不能改某个字符，方法通常返回新字符串 | 字符可以重复，位置有顺序 |
| list列表 | 一排要逐条处理的记录 | 下标、切片、遍历 | 可以增删改 | 保留重复和顺序 |
| tuple元组 | 一条字段位置固定的记录 | 下标、切片、拆包 | 不能替换外层元素 | 保留重复和顺序 |
| dict字典 | 姓名→合计、字段名→值 | 按键读取 | 可以增删改键值项 | 键唯一，保留插入顺序 |
| set集合 | 不同主题、已见过的编号 | 成员检查和遍历，不支持下标 | 可以加入和删除元素 | 自动去重，不保证插入顺序 |

一份名单不一定要用set：如果重复出现也要计为多条记录，就先放list。主题要求不重复时才用set。字典保证插入顺序，不意味着它可以用0、1、2作为位置下标。

**先试一下：** “5笔原始订单”“每笔订单的编号和数量”“各商品销量”“不同商品种类”分别可以用列表、元组或字典记录、字典、集合保存。先说明需求，再选类型。

## 2. 看清嵌套结构，再决定下一步操作

```python
records = [("ada", "python", 20), ("bob", "sql", 10)]
totals = {"ada": 20, "bob": 10}
topics = {"ada": {"python"}, "bob": {"sql"}}
print(records[0])          # ('ada', 'python', 20)：一条元组
print(records[0][2])       # 20：元组里的整数
print(totals["ada"])      # 20：字典里的整数
print(sorted(topics["ada"]))  # ['python']：先取集合，再排序展示
```

`topics["ada"]` 是集合，所以可以调用add；它不是姓名字符串。`records[0]` 是元组，所以可拆给三个变量。每多一层方括号，先问上一层到底取出了什么。

`in` 在不同类型上检查的对象不同：

```python
print("ell" in "hello")                     # True：连续子串
print("ell" in ["hello", "world"])          # False：完整元素
print((1, 2) in (1, 2, 3))                  # False：没有这个二元素元组
print((1, 2) in ((1, 2), (3, 4)))           # True
print("ada" in {"ada": 20})                 # True：检查键
print(20 in {"ada": 20})                    # False：不是检查值
```

### 内容相等与对象共享

```python
a = [1, 2]
b = a
c = a.copy()
print(a == c)  # True：内容相等
print(a is c)  # False：两个不同列表
print(a is b)  # True：两个名字指向同一个列表
b.append(3)
print(a)       # [1, 2, 3]
print(c)       # [1, 2]
```

`==` 比内容，`is` 比是否同一个对象。判断None使用 `is None`；普通数字和文本的内容比较使用 `==`，不要根据一次运行的对象复用情况决定写is。浅复制只复制外层，嵌套的可变对象仍可能共享。

## 4. 从文本得到干净记录

```python
def parse_records(text):
    records = []
    for part in text.split(";"):
        part = part.strip()
        if not part:
            continue
        name, topic, minutes_text = part.split(",")
        name = name.strip().lower()
        topic = topic.strip().lower()
        if not name or not topic:
            continue
        minutes = int(minutes_text.strip())
        records.append((name, topic, minutes))
    return records

raw = " Ada , Python ,20 ; Bob,sql,0 ; Ada,python,10 ; Ada,sql,30 ; ; Bob,Python,5"
records = parse_records(raw)
print(records)
print(parse_records("   ; ; "))
```

输出：

```text
[('ada', 'python', 20), ('bob', 'sql', 0), ('ada', 'python', 10), ('ada', 'sql', 30), ('bob', 'python', 5)]
[]
```

顺序是：按分号拆片段→去片段两端空白→空片段跳过→拆字段→清洗姓名与主题→转整数→把元组加入列表。纯空白片段在拆字段和转数字**之前**跳过。分钟0是一条有效记录，不能用 `if not minutes` 把它删除。

重复的ada/python仍保留为两条记录，这是本任务要求。输入text是字符串，所有清洗结果都接到新变量中。

**先试一下：** 把输入换为 `" Lee, SQL,0 ; Lee,Python,15"`，应得到两条元组，姓名都是lee，分钟为0和15。

## 5. 一次遍历建立合计与主题集合

```python
def summarize(records):
    totals = {}
    topics = {}
    for name, topic, minutes in records:
        totals[name] = totals.get(name, 0) + minutes
        if name not in topics:
            topics[name] = set()
        topics[name].add(topic)
    return totals, topics

records = [("ada", "python", 20), ("bob", "sql", 0),
           ("ada", "python", 10), ("ada", "sql", 30), ("bob", "python", 5)]
totals, topics = summarize(records)
print(totals)
for name, values in topics.items():
    print(name, sorted(values))
```

输出：

```text
{'ada': 60, 'bob': 5}
ada ['python', 'sql']
bob ['python', 'sql']
```

两个字典做不同工作：totals[name]保存整数，topics[name]保存集合。`return totals, topics` 返回二元素元组，调用处用两个变量拆包。加分钟使用minutes，增加记录条数则应加1；本例不用记录次数做排名。

传入空列表时，函数返回两份空字典。没有记录和有一条0分钟记录不同：后一种仍有姓名和主题。

**先试一下：** 用 `[("lee", "sql", 0), ("lee", "sql", 15)]`，合计应为 `{'lee': 15}`，主题集合仍只有sql。用 `[]` 检查两份结果都是空字典。

## 6. 用明确的排序规则得到排名

```python
totals = {"bob": 30, "ada": 30, "lee": 5}
ranked = sorted(totals.items(), key=lambda item: (-item[1], item[0]))
print(ranked)       # [('ada', 30), ('bob', 30), ('lee', 5)]
print(type(ranked)) # <class 'list'>
print(totals)       # {'bob': 30, 'ada': 30, 'lee': 5}
```

items提供 `(姓名, 总分钟)`。key给每项生成 `(-总分钟, 姓名)` 这个排序依据；sorted默认从小到大排，负数让总分钟从大到小，同分时再按姓名升序。只写reverse=True会把多个排序字段整体反转，不能自动表达“分钟降序、姓名升序”。

排名结果是列表，原totals仍为字典。若要求的是主题集合，也不能用sorted的列表冒充集合返回。显示层可以排序，保存层保持题目要求的类型。

## 7. 完整组合：返回一段可保存的报告

下面是完整脚本，定义和调用都在同一个代码块，可以独立运行。它重新列出前面的函数，方便核对组合过程。

```python
def parse_records(text):
    records = []
    for part in text.split(";"):
        part = part.strip()
        if not part:
            continue
        name, topic, minutes_text = part.split(",")
        name = name.strip().lower()
        topic = topic.strip().lower()
        if not name or not topic:
            continue
        records.append((name, topic, int(minutes_text.strip())))
    return records

def summarize(records):
    totals = {}
    topics = {}
    for name, topic, minutes in records:
        totals[name] = totals.get(name, 0) + minutes
        if name not in topics:
            topics[name] = set()
        topics[name].add(topic)
    return totals, topics

def build_report(text):
    records = parse_records(text)
    totals, topics = summarize(records)
    total_minutes = sum(totals.values())
    if records:
        average_text = f"{total_minutes / len(records):.1f}"
    else:
        average_text = "无"
    lines = [f"有效记录：{len(records)}条",
             f"总分钟：{total_minutes}", f"平均分钟：{average_text}"]
    ranked = sorted(totals.items(), key=lambda item: (-item[1], item[0]))
    for number, (name, minutes) in enumerate(ranked, start=1):
        topic_text = "/".join(sorted(topics[name]))
        lines.append(f"{number}. {name}：{minutes}分钟；主题：{topic_text}")
    return "\n".join(lines)

raw = " Ada , Python ,20 ; Bob,sql,0 ; Ada,python,10 ; Ada,sql,30 ; ; Bob,Python,5"
report = build_report(raw)
print(report)
```

输出：

```text
有效记录：5条
总分钟：65
平均分钟：13.0
1. ada：60分钟；主题：python/sql
2. bob：5分钟；主题：python/sql
```

调用过程是build_report→parse_records→summarize→排序和连接→返回str→外层print。sum可对字典values提供的数字求和。平均数的分母是记录条数5，不能误用姓名数2。`enumerate(..., start=1)` 提供编号和排名项，排名项又拆成姓名、分钟。join使用换行符把各行连接成一段文字。

报告函数返回字符串，调用处决定是否打印，后续文件模块再把它写到文件。这样测试时可以直接检查返回内容。

**先试一下：** 用空文本运行，结果必须是三行：有效记录0条、总分钟0、平均分钟无。再用 `"Lee,SQL,0"`，平均分钟是0.0，并有lee的排名行。不要把这两种情况合并。

## 8. 补充：zip与星号为什么能把坐标拆成两列

元组模块已经学过zip把两列并排配对；函数进阶学过 `*` 把一个容器展开成多个位置参数。把它们结合起来：

```python
points = [(1, 2), (3, 4), (5, 6)]
if points:
    xs, ys = zip(*points)
else:
    xs, ys = (), ()
print(xs)  # (1, 3, 5)
print(ys)  # (2, 4, 6)
```

`zip(*points)` 相当于 `zip((1, 2), (3, 4), (5, 6))`，先拿各元组的第一项得到 `(1, 3, 5)`，再拿第二项得到 `(2, 4, 6)`。这里每条记录约定都是二元素元组；空points不能直接拆给xs、ys，所以先判断。

普通循环也能得到两列列表；如果题目指定zip或结果类型为tuple，就需要满足指定要求。此技巧不是写清洗工具的必要条件。
