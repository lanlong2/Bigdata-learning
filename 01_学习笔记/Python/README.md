## 每次怎样学一小节

1. 先读概念和示例解释，遇到陌生词回到它第一次出现的位置。
2. 遮住输出，预测结果；把一个完整代码块复制到自己的练习文件并运行。
3. 改一组数据再运行，解释哪一行让结果变化。标为报错的行单独验证。
4. 自己完成对应题，再看解析；合法的自选变量名可保留。
5. 对照模块完成检查，能独立写出并通过普通和边界输入后再继续。

代码写在 `.py`，说明和输出写在注释或自己的记录中。输入题在终端输入；涉及 `__file__` 或多文件导入的示例先保存，再运行完整文件。题目答案与学习示例分开，看到示例不算独立作答。
