# Java后端 · 主就业路线

本路线在[大模型应用路线](../大模型应用/README.md)完成后开始，按整条路线串行学习。Java是就业优先方向，预算**450小时**；与另列的75小时技术返修预算配合，目标是常规Java后端实习核心能力准备较充分，不能保证覆盖所有岗位或所有技术追问。

Java从零开始，已有Python经验可以帮助理解变量、函数和流程，但不把Java语法、面向对象和编译运行当作已学。教材、习题与项目建设不表示用户已开始或完成Java。

## 技术选型边界

- 以**JDK 21 LTS**作为教学建议起点；先认识编译与运行，再使用IDE。实际安装渠道及维护版本在开始时核对。
- 使用Spring Boot、Maven、MyBatis与MySQL 8.4；框架的具体受支持版本和兼容矩阵在J04开学前查官方资料，不预写2027/2028年的“最新版本”。
- 先写可靠的单体后端。微服务全家桶、分布式事务、大规模消息系统、Kubernetes和深入JVM调优不列必修。
- Redis为有明确需求的缓存，不为了技术列表添加。鉴权与安全先选一个成熟方案并理解验证流程，不自创密码算法。

## 怎样判断准备程度

能够从空工程实现主要业务、独立修改需求，解释请求处理与事务过程；能用测试验证正常、异常、权限和重复请求；能用日志、断点、SQL执行计划等定位问题；能说明索引、并发控制、缓存等设计的适用条件与局限。

算法与计算机基础属于学习内容，不能全部推给不计入预算的“面试准备”。简历、投递、正式面试另计，技术解释与代表题练习已经计入本表。最终状态根据实际学习、用户明确完成陈述及具体检查分别更新，不按时间自动宣告达标。
