# SQL 零基础教程

当前阶段：SQL 学习阶段。Python 学习阶段已结束；本目录是新建的 SQL 教材，所有模块均为**待学习**，练习均为**待练习**。教材生成、数据库脚本验证不代表本人已经学习或作答。

SQL 用来向关系数据库描述“我要哪些数据、怎样统计、怎样修改”。Python 可以逐步写处理流程，SQL 常先描述想要的结果，再由数据库决定如何执行。两者可以配合使用；本阶段从 SQL 本身开始。

## 从哪里开始

1. 阅读 [00_环境与关系表](00_环境与关系表.md)，已有可用PostgreSQL时直接连接，未安装时先安装；创建或连接专用学习数据库。
2. 在该库执行 [00_重建练习库.sql](练习数据/00_重建练习库.sql)。**每次执行都会清空并重建 `sql_learning` schema；其中应只存本课程练习数据。**
3. 每次新开查询窗口先执行 `SET search_path TO sql_learning;`，再按下表顺序学习。
4. 做模块中的就地练习，再打开对应题目；先写 [我的作答.sql](../../02_习题册/SQL/00_基础查询/我的作答.sql)，需要时再看独立的答案文件。

默认方言为 PostgreSQL，官方资料核对日期为 2026-10-10，链接固定到 PostgreSQL 18 文档；本教程基础语法也适用于 PostgreSQL 17。MySQL、SQLite、SQL Server 在安装、日期、限制行数等方面会有差异，先不要混用教程命令。

## 贯穿全教程的数据

| 表名 | 含义 | 每行代表什么 | 初始行数 |
| --- | --- | --- | --- |
| `customers` | 客户 | 一位客户 | 5 |
| `products` | 商品 | 一种商品 | 4 |
| `orders` | 订单明细 | 一笔只包含一种商品的订单记录 | 8 |

`orders` 故意包含一笔取消订单和一笔缺少客户编号的订单；客户表包含一位城市缺失的客户和一位无订单客户，商品表包含一种没有订单的商品。它们用来练习边界情况，不要自行删掉。

口径约定：`paid` 表示已支付，`cancelled` 表示已取消；销售分析默认只算 `paid`，题目另有说明时按题意。`quantity` 是数量，单价在商品表 `unit_price`，订单金额需要在模块 04 关联商品后计算，不能把数量当金额。初始已支付订单共 7 笔、数量合计 14、金额合计 40.00。
