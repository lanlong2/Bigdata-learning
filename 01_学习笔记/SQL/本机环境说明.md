# 本机 MySQL 学习环境

配置日期：2026-10-11。本文记录这台电脑的实际环境；换电脑时按 [00_环境与关系表](00_环境与关系表.md)重新安装和配置，不复制本机账号文件。

## 每次从这里开始

1. 双击桌面 **MySQL 数据学习** 快捷方式。它直接启动 DBeaver，并打开项目中的 [01_验证学习环境.sql](练习数据/01_验证学习环境.sql)。首次打开通常需要约 10–15 秒；本机 MySQL 在登录 Windows 时自动启动。
2. 确认编辑器的数据源是 **MySQL 数据学习**，数据库为 `sql_learning`。选中一条查询，按 **Ctrl+Enter** 执行。
3. 按教材顺序学习，在对应 [基础查询作答](../../02_习题册/SQL/00_基础查询/我的作答.sql)、[进阶作答](../../02_习题册/SQL/01_关联与进阶/我的作答.sql)或[项目查询](../../05_项目实践/SQL/00_订单查询报告/我的查询.sql)中写自己的 SQL。
4. **Ctrl+S** 保存项目文件；需要同步到 GitHub 时再提交、推送。操作说明见 [DBeaver 与 GitHub 同步](../Git/DBeaver与GitHub同步.md)。

新快捷方式使用 MySQL 专用工作区；早先 SQLite 连接不再作为当前课程入口。

## 实际连接参数

| 项目 | 本机值 | 简单解释 |
|---|---|---|
| 数据库服务 | MySQL Community Server 8.4.11 LTS | 保存数据并执行 SQL |
| 客户端 | DBeaver Community，简体中文 | 写 SQL、执行、查看结果 |
| JDBC 驱动 | MySQL Connector/J 26.7.0 | 让 DBeaver 与 MySQL 通信；已校验官方仓库 SHA-256 |
| 主机 | `127.0.0.1` | 数据库在本机，只监听本机地址 |
| 端口 | `3306` | 客户端找到服务的入口 |
| 数据库 | `sql_learning` | 本课程的专用学习空间 |
| 日常账号 | `sql_learner` | 仅有本学习库的权限，不使用管理员账号做日常练习 |
| 字符集 | `utf8mb4` | 支持中文及完整 Unicode 字符 |
| 排序规则 | `utf8mb4_0900_as_cs` | 本课程明确区分大小写与重音，匹配教材示例 |
| 表引擎 | `InnoDB` | 支持课程需要的事务和外键 |
| 服务时区 | `+08:00` | 中国标准时间 |
| SQL 模式 | 严格模式，含 `ONLY_FULL_GROUP_BY` | 拒绝部分非法写入和含糊的分组查询 |

DBeaver 已保存学习账号密码；需要手动重新配置时，双击桌面 **MySQL 连接信息**。该信息仅保存在本机用户目录，不写进 SQL 文件、不上传 GitHub。管理员密码另存于本机私有配置中。
