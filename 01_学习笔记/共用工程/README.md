# 共用工程 · 两条路线复用的能力

这是一份复用导航，不是第三条并行路线。先在Python大模型应用中学一次，再在Java中迁移语言与工具；相应时间已经包含在A/J模块内，不重复加课时。

| 能力 | 首次学习位置 | Java阶段怎样复用 | 当前材料 |
|---|---|---|---|
| 版本管理 | 现有[Git说明](../Git/README.md)，随A01/A05使用 | 保存可解释的提交，检查差异，排查配置和敏感信息 | 既有说明与历史保留；新路线不重设旧书面测验为门槛 |
| 数据库 | [SQL00—07](../SQL/README.md)，A00共35小时 | J03学习JDBC、参数化查询、索引和事务实用边界 | SQL教材现成；J03新增内容待展开 |
| 环境、依赖与配置 | [A01工程补齐](../大模型应用/00_路线导读与工程补齐.md) | J00区分JDK/运行环境；J04使用Maven和配置文件 | A01基础教材可学 |
| HTTP与API | A02：请求、响应、JSON、校验与状态码 | J02/J04：网络基础与Spring接口 | 官方阅读入口已备；完整中文教程待按进度展开 |
| 测试与排障 | A01断言检查，A02接口测试，A05日志与异常 | J01异常/JVM基础，J04/J06测试与日志 | A01完整示例可学；深入材料待展开 |
| Linux与部署 | A05：目录/权限/进程/端口/环境配置的最小使用 | J05/J06迁移Java应用运行与日志检查 | 随项目展开，不另启Linux运维路线 |
| 数据处理与评测 | A04/A05：清洗、去重、分组统计和固定问题集 | J06：测试数据、查询口径和结果比较 | 复用已学Python容器与SQL，不必先学全套Pandas |
| 安全与成本 | A03/A05：密钥不入库、超时、有限重试与调用预算 | J05/J06：权限边界、输入校验与配置隔离 | 跟功能同时学习，不只在结尾补文档 |

每次90分钟：先回顾上次卡点约10分钟，围绕一个明确产出实现或练习约65分钟，最后约15分钟验证并写清下一步。比例可随调试任务调整；不要到点把尚未验证的功能记为完成。

排障记录只需说明现象、复现输入、观察、原因、修改与回归结果，保存在对应项目；不自动加入`04_错题与疑问`。75小时技术返修用于复习薄弱处、项目返工、维护和重新部署，不是休假或停学预算。
