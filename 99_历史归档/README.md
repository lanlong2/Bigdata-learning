# 历史归档 · 查旧资料用

这里保存整理前的原件，不是新的每日学习入口。

- [整理前文件夹](2026-09-17_整理前/)：保留原来的内容和作答，未做文字修改。
- [迁移对照](迁移对照.md)：按原文件名寻找新的位置。
- [原件校验清单](原件校验清单.json)：记录10份原文件的大小与校验值，供核对完整性。

## 使用规则

想继续学习，请回到[总导航](../README.md)。只有查历史时才打开这里。

旧计划中的“今天”“明天”、旧进度和旧截止日期，均以原文保留，不作为现在的任务。当前计划从2026-09-17开始。旧笔记可能含已经订正的表述，应以“01_学习笔记”和新习题解析为准。

不要在原件上继续作答。日常答案写入“02_习题册”，阶段测验写入“03_阶段试卷”；这样不会出现两份进度互相矛盾。

如果想恢复某一份原件，先复制到别处核对，再决定是否替换当前文件。此目录没有包含Git内部历史；原仓库的Git记录仍在原位置。
