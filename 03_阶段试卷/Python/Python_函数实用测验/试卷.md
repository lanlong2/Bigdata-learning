### B01 · 库存提醒文本（10分）

目标：返回`"pen:3"`，供后续显示或保存；商品名为字符串，数量为非负整数。当前程序出错或拿不到可复用的结果。

```python
    print(text)

```

### B02 · 销量排序（10分）

目标：返回按数量降序排列的新列表，原列表保持不变；同数量保持原顺序，空列表返回`[]`。必须用lambda作为排序key。

```python
def rank_items(rows):
    return rows.sort(key=lambda row: row[1], reverse=True)
rows = [("pen", 2), ("book", 5), ("bag", 2)]
ranked = rank_items(rows)
```

修复后返回`[("book", 5), ("pen", 2), ("bag", 2)]`，`rows`仍为原列表。

## D · 订单汇总流程（30分）

把已有订单处理写成可重复调用的函数。下面四问可以衔接，函数均不在内部打印。即使前一问未完成，也可用题目给出的中间数据继续后面的题。

```python
raw = " Pen ,2;book,0;;PEN,3; bag ,5;book,2; \n"
```

规则：`;`分记录，`,`分商品名与数量；忽略空白片段。非空记录保证恰有一个逗号，商品名非空、只含英文字母及两端空白，数量能转为非负整数。商品名去两端空白并转小写；数量转int。允许重复商品、0数量、空字符串或全空片段；不考坏数字或文件读取。

### D01 · 解析订单（6分）

`" ; \n;;"`返回`[]`。

### D02 · 按单条数量筛选（6分）

定义`select_orders(records, min_quantity=1)`，返回数量大于等于门槛的记录组成的新列表，不修改原列表。门槛为非负整数，必须使用实际传入值。保持原顺序。

对D01样例，默认返回`[('pen', 2), ('pen', 3), ('bag', 5), ('book', 2)]`；`min_quantity=3`返回`[('pen', 3), ('bag', 5)]`；门槛0保留全部；空输入返回`[]`。

### D03 · 按商品累计（8分）

对D02默认筛选后的列表，得到`{'pen': 5, 'bag': 5, 'book': 2}`。字典显示顺序不评分。

### D04 · 组合成可复用报告（10分）

定义`build_report(raw, min_quantity=1)`，必须依次调用D01、D02、D03三个函数，返回字典，包含以下四个键：

- `record_count`：筛选后的记录条数，重复商品分条计数。
- `quantity_sum`：筛选后的数量总和。
- `product_count`：筛选后的不同商品数。
- `ranked`：累计结果转为`(商品名, 累计数量)`元组列表，按累计数量降序；同销量按商品名字母升序。使用lambda作为销量排序key，可分两次稳定排序。

**门槛作用于单条记录，先筛选，再按商品累计。** 对本例：

```python
# build_report(raw)
{'record_count': 4, 'quantity_sum': 12, 'product_count': 3,
 'ranked': [('bag', 5), ('pen', 5), ('book', 2)]}

# build_report(raw, min_quantity=3)
{'record_count': 2, 'quantity_sum': 8, 'product_count': 2,
 'ranked': [('bag', 5), ('pen', 3)]}

# build_report('')，或者门槛高于所有数量
{'record_count': 0, 'quantity_sum': 0, 'product_count': 0, 'ranked': []}
```

检查连续使用不同门槛时，结果是否各自正确。字典键的显示顺序不评分；`ranked`的列表顺序和元组类型要符合要求。
