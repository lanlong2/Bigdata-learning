## 使用顺序

1. 先看试卷README，确认范围、满分、时限和允许的工具。
2. 同时打开试卷与答卷，记录开始时间。
3. 独立完成整卷；不会的先标记，时间到就记录实际完成情况。
4. 完成后再看参考答案与评分；保留原答卷，错题另外订正。
5. 重测时另存一份带日期的新答卷，不覆盖旧结果。

看过答案后立即重做只算订正；以后重测注明“复测”与已看过解析。如果使用帮助，记录涉及的题号和帮助内容。
