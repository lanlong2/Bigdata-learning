### 本卷最需要分清的三种情况

| 写法 | 原对象怎样了 | 返回了什么 |
|---|---|---|
| `text.upper()` | 原字符串不变 | 大写字符串 |
| `sorted(numbers)` | 原容器不变 | 排好序的新列表 |
| `numbers.sort()` | 原列表被排序 | `None` |

“返回值”就是这次操作交回来的结果。可以用 `=` 保存，也可以直接 `print(...)`、用于判断或传给下一步。**不能简单记成“所有方法都要重新赋值”。** 例如 `numbers = numbers.sort()` 反而会让 `numbers` 变成 `None`。

## 五、大题二：成绩记录处理（D2，15 分）

### 完整参考代码

下面整段可以独立运行，不依赖 D1。

```python
rows = [("林晓", 72), ("周宁", 59), ("陈雨", 91), ("苏禾", 88), ("许安", 60)]

# D2.1 · 逐条打印
for name, score in rows:
    print(f"{name}：{score}分")

# D2.2 · 总分与平均分
total_score = 0
for name, score in rows:
    total_score += score
average_score = total_score / len(rows)
print(f"总分：{total_score}")
print(f"平均分：{average_score:.1f}")

passed_names = []
for name, score in rows:

else:
    print("及格名单：无")

# D2.4 · 最高分
best_name, best_score = rows[0]
for name, score in rows:
    if score > best_score:
        best_name = name
        best_score = score
print(f"最高分：{best_name} {best_score}分")

# D2.5 · 分数分档
excellent_count = 0
good_count = 0
pass_count = 0
needs_practice_count = 0
for name, score in rows:
    if score >= 90:
        excellent_count += 1
    elif score >= 80:
        good_count += 1
    elif score >= 60:
        pass_count += 1
    else:
        needs_practice_count += 1
print(f"优秀：{excellent_count}人")
print(f"良好：{good_count}人")
print(f"及格：{pass_count}人")
print(f"待加强：{needs_practice_count}人")
```

### 为什么这样写

- `for name, score in rows` 每次拿到一条元组记录，再拆成两个变量。
- 总分从 `0` 开始累加。平均分要用 `/`，用 `//` 会丢掉小数部分。

- 最高分从第一条记录开始比较，同时更新姓名和分数，避免“最高分找对了，姓名还是另一个人”。
- 分档从高往低判断。同一组 `if/elif/else` 中，一名学生只会进入一个分支。

**常见错误：** 直接写 `max(rows)` 会先比较元组的姓名，而不是自动按分数比较。本题使用普通循环就能准确完成，不需要提前学习 `lambda`。

## 六、大题三：订单数量汇总（D3，20 分）

### 完整参考代码

下面整段可以独立运行，不依赖前面的题目。

```python
raw_orders = " Pen , 2 ; notebook,3;; PEN,4; eraser , 1; notebook ,3;   ;\n"

# D3.1 · 拆分记录并去掉空项
clean_rows = []
for raw_row in raw_orders.split(";"):
    clean_row = raw_row.strip()
    if clean_row:
        clean_rows.append(clean_row)
print(f"有效记录：{len(clean_rows)}条")

# D3.2 · 整理成元组记录
records = []
for clean_row in clean_rows:
    product, quantity_text = clean_row.split(",")
    product = product.strip().lower()
    quantity = int(quantity_text.strip())
    records.append((product, quantity))
print(records)

# D3.3 · 按商品累计数量
totals = {}
for product, quantity in records:
    if product in totals:
        totals[product] += quantity
    else:
        totals[product] = quantity
for product in sorted(totals):
    print(f"{product}：{totals[product]}件")

# D3.4 · 商品去重与种类统计
product_names = set()
for product, quantity in records:
    product_names.add(product)
print(f"商品种类：{len(product_names)}种")
print("商品清单：" + "、".join(sorted(product_names)))

# D3.5 · 找出全部最高销量商品
highest_quantity = 0
for quantity in totals.values():
    if quantity > highest_quantity:
        highest_quantity = quantity

best_products = []
for product, quantity in totals.items():
    if quantity == highest_quantity:
        best_products.append(product)
best_products = sorted(best_products)
print(f"最高销量：{highest_quantity}件")
print("最高销量商品：" + "、".join(best_products))
```

### 完整输出

```text
有效记录：5条
[('pen', 2), ('notebook', 3), ('pen', 4), ('eraser', 1), ('notebook', 3)]
eraser：1件
notebook：6件
pen：6件
商品种类：3种
商品清单：eraser、notebook、pen
最高销量：6件
最高销量商品：notebook、pen
```

### 分步评分

| 题号 | 得分点 | 分值 |
|---|---|---:|
| D3.1 | 按分号拆分记录 | 1 |
| D3.1 | 去掉每条记录两端的空白 | 1 |
| D3.1 | 忽略空字符串与仅含空白的记录 | 1 |
| D3.1 | 用 `clean_rows` 按原顺序保存有效记录并正确打印条数 | 1 |
| D3.2 | 按逗号拆出两个字段 | 1 |
| D3.2 | 商品名去掉两端空白并统一小写 | 1 |
| D3.2 | 数量转换为整数 | 1 |
| D3.2 | 用元组保存每条记录，组成有序的 `records` 列表并打印 | 1 |
| D3.3 | 使用 `totals` 字典，键为商品名，值为数量 | 1 |
| D3.3 | 新商品能初始化，同名商品能累加（各 1 分） | 2 |
| D3.3 | 按商品名字母升序输出累计数量 | 1 |
| D3.4 | 用集合 `product_names` 正确保存不重复的商品名 | 1 |
| D3.4 | 商品种类数正确 | 1 |
| D3.4 | 商品清单按字母升序排列 | 1 |
| D3.4 | 按指定格式打印种类与清单两行 | 1 |
| D3.5 | 从累计数量中找出最高销量 | 1 |
| D3.5 | 正确保留全部并列最高商品，单个最高商品时也适用 | 2 |
| D3.5 | 按字母升序输出商品，数值与两行格式正确 | 1 |

### 为什么这样写

1. **先去空项，再拆字段。** 空字符串里没有逗号，直接拆成两个变量会失败。必须先清洗，再判断是不是空项，才能处理只含空格的片段。
2. **先统一商品名，再累计。** `Pen` 和 `PEN` 在 Python 看来是两个不同字符串；转小写后才会汇总到同一个键。
3. **数量先转整数。** 字符串 `"2" + "4"` 是 `"24"`；整数 `2 + 4` 才是数量 `6`。
4. **字典累计与集合去重各有用途。** 字典保存“商品对应多少件”，集合保存“出现了哪些不同商品”。
5. **先找最大数量，再找全部相等的商品。** 只保存一个商品名会遗漏并列者。

补充：D3.3 也可以使用 `totals[product] = totals.get(product, 0) + quantity`；D3.4 可以用 `product_names = set(totals)`；D3.5 可以用 `max(totals.values())`。这些是等价写法，不是额外必学要求。
