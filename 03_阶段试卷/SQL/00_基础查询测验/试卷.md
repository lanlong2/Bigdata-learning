# SQL基础查询测验

满分100分，建议60分钟。使用课程schema `sql_learning` 中的customers、products和orders。初始化方法见[使用说明](README.md)。查询窗口先执行：

```sql
SET search_path TO sql_learning;
```

本卷只查询，不修改样例。已付款订单指 `status = 'paid'`，商品数量指quantity；订单数与商品数量分别统计。答案写入[我的答卷.sql](我的答卷.sql)。

## A · 选列与去重（20分）

**A01（10分）** 查询products的product_name、unit_price两列，按product_id升序排列。

**A02（10分）** 查询orders出现过的不同status，每个状态只保留一行，按status升序排列。

## B · 条件与空值（35分）

**B01（15分）** 查询已付款且quantity不小于2的订单，返回order_id、quantity两列，按order_id升序排列。

**B02（10分）** 查询没有登记客户编号的订单，返回order_id、customer_id两列，按order_id升序排列。

**B03（10分）** 查询unit_price在3到5之间（包括3和5）的商品，返回product_name、unit_price，按单价降序，再按product_id升序排列。

## C · 汇总与分组（45分）

**C01（15分）** 用一条查询统计全部已付款订单的订单笔数和商品总数量，返回两列。别名可自选。

**C02（15分）** 只统计已付款订单，按product_id分组，返回product_id、商品总数量、订单笔数三列。先按商品总数量降序，再按product_id升序排列。

**C03（15分）** 只统计已付款订单，按customer_id分组，保留已付款订单笔数至少2笔的客户，返回customer_id、订单笔数、商品总数量三列，按customer_id升序排列。

完成后记录实际用时与帮助情况，再打开[参考答案与评分](参考答案与评分.md)。
