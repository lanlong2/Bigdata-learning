## B01 · 15分

```sql
SELECT order_id, quantity
FROM orders
WHERE status = 'paid' AND quantity >= 2
ORDER BY order_id;
```

结果：(1001,2)、(1003,3)、(1005,4)、(1008,2)。列和表3分，paid筛选4分，数量含等号条件5分，两个条件同时满足及排序3分。

## B02 · 10分

```sql
SELECT order_id, customer_id
FROM orders
WHERE customer_id IS NULL
ORDER BY order_id;
```

结果：(1007,NULL)。正确表和列3分，IS NULL条件5分，排序2分。`= NULL`无法按要求找出该行，空值条件不得分。

## B03 · 10分

```sql
SELECT product_name, unit_price
FROM products
WHERE unit_price BETWEEN 3 AND 5
ORDER BY unit_price DESC, product_id ASC;
```

结果：notebook/5.00、pen/3.00。表与列2分，区间及两端包含5分，完整排序3分。用 `unit_price >= 3 AND unit_price <= 5` 等价。

## C01 · 15分

```sql
SELECT COUNT(*) AS order_count, SUM(quantity) AS total_quantity
FROM orders
WHERE status = 'paid';
```

结果一行：(7,14)。paid筛选4分，订单笔数COUNT(*)4分，商品数量SUM(quantity)5分，单行两列结构2分。COUNT(quantity)在本表非空约束下等价，但需能说明它数非空值，不是把数量相加。

## C02 · 15分

```sql
SELECT product_id, SUM(quantity) AS total_quantity, COUNT(*) AS order_count
FROM orders
WHERE status = 'paid'
GROUP BY product_id
ORDER BY total_quantity DESC, product_id ASC;
```

| product_id | total_quantity | order_count |
|---:|---:|---:|
| 1 | 6 | 3 |
| 3 | 6 | 2 |
| 2 | 2 | 2 |

paid筛选3分，正确分组3分，两个统计各3分，完整两级排序3分。

## C03 · 15分

```sql
SELECT customer_id, COUNT(*) AS order_count, SUM(quantity) AS total_quantity
FROM orders
WHERE status = 'paid'
GROUP BY customer_id
HAVING COUNT(*) >= 2
ORDER BY customer_id;
```

| customer_id | order_count | total_quantity |
|---:|---:|---:|
| 1 | 3 | 5 |
| 2 | 2 | 7 |

paid筛选3分，按客户分组3分，订单数和数量各2分，HAVING及至少2笔条件4分，排序1分。WHERE筛选原始行，HAVING筛选分组后的统计结果。
