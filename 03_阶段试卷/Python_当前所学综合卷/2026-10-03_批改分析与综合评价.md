## E02 · 0.5/5

按姓名创建字典0.5/1（正确初始化字典，未成功建立姓名键）；值为集合0/1；同人去重、不同人分开0/2；返回结果、空输入、原记录不变0/1。

```python
# group_topic对应题目group_topics
def group_topic(records):
    a = {}
    for i in records:
        if i[0] not in a:
            a[i[0]] = set()
        a[i[0]].add(i[1])
    return a
```
