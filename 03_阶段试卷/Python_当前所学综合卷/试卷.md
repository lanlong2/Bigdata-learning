### B03 · 过滤无效库存（5分）

目标：`keep_valid([4, -1, -2, 0, 3])`返回`[4, 0, 3]`，保留非负整数、重复值及原顺序，返回新列表且不改原列表。空输入返回`[]`。

```python
def keep_valid(values):
    for value in values:
        if value < 0:
            values.remove(value)
    return values
```
