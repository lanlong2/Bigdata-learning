## A02 · 预览与返回

题目要求：预测三行输出，并解释为什么后两行没有得到函数里算出的数值。首测输出正确，缺少的是局部变量解释。

### 我的原答案

```python
# A02（5分）三行输出与说明：
#7
#None
#10
#说明：函数没有返回值
```

### 正确答案

三行输出：

```text
7
None
10
```

完整说明：函数没有return，调用结果是None；函数内重新赋值的是局部参数value，没有改变外部value，因此外部仍为10。

交卷后可用原题代码核对，不需要改变题目中的函数：

```python
value = 10

def preview(value, bonus=2):
    value = value + bonus
    print(value)

result = preview(bonus=3, value=4)
print(result)
print(value)
```

### 涉及知识点与详解

**1. 关键字参数按名字对应。** `preview(bonus=3, value=4)`把4交给函数参数value、把3交给bonus，实际bonus覆盖默认2。因此函数内计算4+3，打印7。

**2. print不等于return。** 函数打印7，是向终端展示；它没有把7交回调用处。函数执行到末尾仍没有return时，调用表达式的结果是None，所以result为None。

**3. 局部重新赋值与外部变量。** 函数参数value是函数内的局部名字，虽然与外部value同名，但本题的重新赋值只把局部value改为7。函数之外的value仍保存10。这里讨论的是整数的重新赋值，不能泛化成“函数内所有操作都不会影响传入对象”；修改传入列表是另一种情况。

| 名字的位置 | 初始值 | 执行后 |
|---|---:|---|
| 函数外的value | 10 | 10 |
| 函数内的参数value | 4 | 7 |
| 调用处的result | 等待返回 | None |

详见[函数基础](../../01_学习笔记/Python/05_函数基础.md)与[函数进阶的局部变量](../../01_学习笔记/Python/06_函数进阶.md)。

## C01 · 按指令接收到货

题目要求：while按顺序读指令；stop用break停止，<=0用continue跳过；正数加入初始库存，不修改commands；按实际箱容量输出三行，并处理空列表、首条stop及无stop。

### 我的原答案

```python
# C01（10分）到货指令：
commands = ["3", "0", "-2", "5", "stop", "100"]
initial_stock = 2
box_size = 4
a=[]
sum1=0
for i in commands:
    while i < len(commands):
        if i=="stop":
            break
        else:
            if int(i)>0:
                a.append(int(i))
            else:
                pass
for i in a:
    sum1=sum1+i
print(f"""
总库存：{sum1}件
装箱：{sum1//box_size}
剩余：{sum1%box_size}
""")
```

### 正确答案

保留sum1、i、a：i专门表示位置下标，a表示当前指令，sum1表示库存。当前指令可以直接累计，无须先收集到列表。

```python
commands = ["3", "0", "-2", "5", "stop", "100"]
initial_stock = 2
box_size = 4

sum1 = initial_stock
i = 0

while i < len(commands):
    a = commands[i]
    i = i + 1

    if a == "stop":
        break

    a = int(a)
    if a <= 0:
        continue

    sum1 = sum1 + a

print(f"总库存：{sum1}件")
print(f"整箱：{sum1 // box_size}箱")
print(f"剩余：{sum1 % box_size}件")
```

输出：

```text
总库存：10件
整箱：2箱
剩余：2件
```

### 涉及知识点与详解

**1. 当前i是值，不是下标。** 现存原答案用`for i in commands`，第一轮i是字符串`"3"`；len(commands)是整数6。`while i < len(commands)`立即尝试字符串与整数比大小，产生TypeError。只把原来的`while i`换成这句，尚未把i变成下标。

正确写法先让i=0，表示位置，再用commands[i]取得该位置的值。`i < len(commands)`表示还有可读取的位置，不是比较指令的大小。

**2. 每轮先取值，再推进。** 先`a = commands[i]`，再`i = i + 1`，第一条不会漏读。推进放在continue之前，才能保证跳过0或负数后读取下一条；while不会替你自动推进。

**3. stop必须在转换前识别。** int能转换`"3"`，不能转换`"stop"`。先判断stop并break，再对其余字符串转int。

**4. break与continue控制不同。** break退出所在的一层循环；原结构的break只退出内层while，外层for仍继续。正确示例只有一个while，stop能结束整个读取。continue跳过当前这轮的累计，回到条件判断；pass只是空操作，不能替代continue。

| 读到的指令 | 操作 | 库存 |
|---|---|---:|
| "3" | 初始2，再加3 | 5 |
| "0" | continue | 5 |
| "-2" | continue | 5 |
| "5" | 加5 | 10 |
| "stop" | break | 10 |
| "100" | 不读取 | — |

**5. 初始库存和最终装箱。** sum1从initial_stock开始；`//`得到完整箱数，`%`得到剩余件数。三次print在while外，只输出最终结果。“整箱”、箱/件单位及三行格式也属于题目要求。

**6. 边界与输入不变。** commands只被读取，没有删除、排序或改写。保持初始2、每箱4时，空列表及首条stop均得到2件/0箱/剩2件；无stop的`["3", "0", "-2", "5"]`得到10件/2箱/剩2件，最后由下标条件正常结束。

题目要求：循环拆包、求总分和一位小数平均；及格姓名放列表，按原顺序用顿号连接；字典统计四个互斥档位；按指定七行输出；空输入和无人及格显示无。

### 我的原答案

```python
# C02（15分）成绩日报：
rows = [("小周", 58), ("小林", 90), ("小白", 60), ("小陈", 80), ("小许", 100)]
sum1=0
for i in rows:
    sum1=sum1+i[1]
#sum1
avg=round(sum1/len(rows),1)
#avg
names=[]
for i in rows:
    if i[1]>=60:
        names.append(i[0])
    else:
        pass
names1=",".join(names)
#names
w=0
j=0
l=0
y=0
for i in rows:
    if i[1]<60:
        w=w+1
    elif i[1]>=60 and i[1]<79:
        j=j+1
    elif i[1]>=80 and i[1]<89:
        l=l+1
    elif i[1]>=90 and i[1]<=100:
        y=y+1
print(f"""
总分:{sum1}
平均分：{avg}
及格名单：{names1}
优秀：{y}人
良好：{l}人

待加强：{w}人

```

### 正确答案

当前原答案已统一sum1，普通数据的累计这一处已修正。下面保留sum1、i、avg、names、names1，新增a字典保存四档统计。外层封装函数只是为了方便换数据验证，C题也允许写成脚本。

```python
def score_report(rows):
    sum1 = 0
    names = []
    a = {"优秀": 0, "良好": 0, "及格": 0, "待加强": 0}

    for i in rows:
        name, score = i
        sum1 = sum1 + score
        if score >= 60:
            names.append(name)

        if score >= 90:
            a["优秀"] += 1
        elif score >= 80:
            a["良好"] += 1
        elif score >= 60:
            a["及格"] += 1
        else:
            a["待加强"] += 1

    names1 = "、".join(names) if names else "无"
    print(f"总分：{sum1}")
    if rows:
        avg = sum1 / len(rows)
        print(f"平均分：{avg:.1f}")
    else:
        print("平均分：无")
    print(f"及格名单：{names1}")
    for level in ["优秀", "良好", "及格", "待加强"]:
        print(f"{level}：{a[level]}人")

rows = [("小周", 58), ("小林", 90), ("小白", 60), ("小陈", 80), ("小许", 100)]
score_report(rows)
```

输出：

```text
总分：388
平均分：77.6
及格名单：小林、小白、小陈、小许
优秀：2人
良好：1人
及格：1人
待加强：1人
```

### 涉及知识点与详解

**1. 累计变量一致与记录拆包。** 当前代码的`sum1 = sum1 + i[1]`已经使用同一个累计器，不再是首测时的sum/sum1混用。正确示例继续保留i，并把它拆为name、score；这能明确一条元组里两项的含义，也满足题目要求的循环拆包。

**2. 平均数先判空。** 非空时用总分除人数，`.1f`控制显示一位小数；空rows的len为0，必须在除法之前分支处理。空输入要显示无，而不是随意写成平均0。

**3. 名单是列表，显示才转字符串。** names保存符合>=60的人名，append保持原顺序。names1是最终显示文字；`"、".join(names)`用顿号连接，无人符合时显示无。这里的条件表达式`X if 条件 else Y`表示条件成立取X，否则取Y，也可写成普通if/else。

**4. 四档用字典保存。** w/j/l/y四个独立数字不能代替题目指定的字典。a先给四个键各存0，分档时更新对应值；空rows时循环0次，四档自然仍为0。这不是因变量名不同扣分，而是容器要求不同。

**5. if/elif保证互斥，边界必须包含。** 原代码的`<79`漏掉79，`<89`漏掉89。按90→80→60→其余判断，前一档不成立才进入下一档，既不重叠也不遗漏：

| 分数 | 正确档位 |
|---:|---|
| 59 | 待加强 |
| 60、79 | 及格 |
| 80、89 | 良好 |
| 90 | 优秀 |

**6. 七行格式独立核对。** 总分用中文冒号，名单用顿号，四档顺序固定，人数后有“人”。分开print避免三引号带来多余空行。只有0分时：总分0、平均0.0、名单无、待加强1人；空rows时总分0、平均无、名单无、四档均0。可调用`score_report([])`、`score_report([("零", 0)])`与边界数据分别检查，原rows不修改。

## D01 · 合计多段学习时间

题目要求：不定长位置参数接收非负整数，返回总分钟；无参数0；已有parts列表通过*拆包传入。失分处是调用，函数本体正确。

### 我的原答案

```python
# D01（6分）sum_minutes及列表拆包调用：
parts = [15, 30, 10]
def sum_minutes(*minutes):
    sum1=0
    if minutes:
        for i in minutes:
            sum1=sum1+i
        return sum1
    else:
        return 0
print(sum_minutes(20,0,40))
print(sum_minutes(parts))
```

### 正确答案

沿用你的函数体，只把列表调用改为`sum_minutes(*parts)`并补空调用：

```python
def sum_minutes(*minutes):
    sum1 = 0
    if minutes:
        for i in minutes:
            sum1 = sum1 + i
        return sum1
    else:
        return 0

parts = [15, 30, 10]
print(sum_minutes(20, 0, 40))  # 60
print(sum_minutes(*parts))    # 55
print(sum_minutes())          # 0
```

### 涉及知识点与详解

**1. 定义中的*收集参数。** minutes是一个元组，保存调用时传入的各个位置参数。名称可以自定，*决定收集行为。

| 调用 | 函数内的minutes |
|---|---|
| `sum_minutes(20, 0, 40)` | `(20, 0, 40)` |
| `sum_minutes()` | `()` |
| `sum_minutes(parts)` | `([15, 30, 10],)` |
| `sum_minutes(*parts)` | `(15, 30, 10)` |

**2. 调用中的*展开列表。** 原调用把整个parts当成一个参数，循环第一次拿到的i就是列表，整数0加列表会产生TypeError。*parts把15、30、10展开为三个参数，逐个累加得到55。

**3. 空调用与每次重新累计。** sum1位于函数内部，每次调用都重新从0开始；空minutes进入else返回0。这个函数不需要为列表另写内层循环，本题练的是调用处的拆包。

## D03 · 批量套用处理函数

题目要求：operation每次接收一个值，apply_rule按原顺序收集为新列表；用clean_topic和len分别演示，空输入返回[]，不修改values。

### 我的原答案

```python
# D03（6分）apply_rule、clean_topic与两种规则调用：
def clean_topic(text):
    return text.lower().strip()
def apply_rule(values,operation):
    a=[]
    if values:
        for i in values:
            a.append=len(operation(i))
        return a
    else:
        return []

```

### 正确答案

```python
def clean_topic(text):
    return text.lower().strip()

def apply_rule(values, operation):
    a = []
    for i in values:
        a.append(operation(i))
    return a

values = [" PYTHON ", " Sql "]
print(apply_rule(values, clean_topic))  # ['python', 'sql']
print(apply_rule(["python", "sql"], len))  # [6, 3]
print(apply_rule([], clean_topic))  # []
print(values)  # [' PYTHON ', ' Sql ']，原输入不变
```

### 涉及知识点与详解

**1. append用括号调用。** `a.append(...)`才是追加元素；`a.append = ...`是给方法属性赋值，列表不允许这样替换append，会产生AttributeError。clean_topic清洗正确，可沿用。

**2. operation的结果直接收集。** operation(i)已经完成当前规则：清洗规则返回字符串，len规则返回整数。原代码固定再套len，对清洗结果会变成长度；对len返回的整数再求len，则产生TypeError。apply_rule只负责调用与收集，不替调用者改规则。

| 传入的operation | i | operation(i) | 追加到a的值 |
|---|---|---|---|
| clean_topic | ' PYTHON ' | 'python' | 'python' |
| len | 'python' | 6 | 6 |

**3. 函数本身与调用结果。** `apply_rule(values, clean_topic)`传函数本身；在apply_rule里面调用operation(i)。若传`clean_topic(" PYTHON ")`，会先得到字符串python，再把字符串当规则传入，无法继续调用。

**4. 单个值与一张列表。** for负责取出每项；operation只处理本次的i。a每次调用都新建，按序append，values只被读取。空输入没有元素，循环0次，自然返回[]。

详见[核心语法：调用与括号](../../01_学习笔记/Python/00_核心语法.md#calls)及[函数进阶](../../01_学习笔记/Python/06_函数进阶.md)。

## D04 · 筛选有效学习时段

题目要求：按实际min_minutes筛选，默认30、含等号；重复主题按多条记录计数；调用D01并*拆包；返回条数、总分钟、平均三元组，无符合项返回(0, 0, None)。

### 我的原答案

```python
# D04（8分）session_summary与调用：

def session_summary(sessions,min_minutes=30):
    a=[]
    h=0
    sum=0
    if min_minutes==100 or sessions==False:
        for i in sessions:
            if i[1]>=min_minutes:
                a.append(i)
                h=h+1
                sum=sum+i[1]

            else:
                pass
    avg=sum/len(a)

```

### 正确答案

为了本段可单独运行，先带上D01正确求和函数。session_summary沿用a、h、sum、avg；这里sum是局部数值，不再调用同名内置函数。

```python
def sum_minutes(*minutes):
    sum1 = 0
    for i in minutes:
        sum1 = sum1 + i
    return sum1

def session_summary(sessions, min_minutes=30):
    a = []
    for i in sessions:
        if i[1] >= min_minutes:
            a.append(i[1])

    h = len(a)
    sum = sum_minutes(*a)
    if h == 0:
        return (0, 0, None)

    avg = sum / h
    return (h, sum, avg)

sessions = [('python', 20), ('sql', 40), ('python', 30), ('git', 0)]
print(session_summary(sessions))       # (2, 70, 35.0)
print(session_summary(sessions, 20))   # (3, 90, 30.0)
print(session_summary(sessions, 0))    # (4, 90, 22.5)
print(session_summary(sessions, 100))  # (0, 0, None)
print(session_summary([]))            # (0, 0, None)
print(session_summary([('git', 0)], 0)) # (1, 0, 0.0)
```

### 涉及知识点与详解

**1. 门槛是筛选条件，不是决定是否执行筛选的开关。** 原外层条件`min_minutes == 100 or sessions == False`使默认30、20、0不进入循环，a一直为空。100只是例子里“全部被过滤”的一种输入，不能写成只有100才处理。正确函数对每条记录都比较实际min_minutes。

**2. 空列表不是False这个对象。** `[] == False`是False。判断列表为空可用`if not sessions`；本题直接遍历即可，空列表循环0次，最后由h==0统一处理。

**3. >=保留边界，不按主题去重。** 门槛30时保留40和30；门槛0时连0分钟记录也保留。两个python时段是两条记录，符合的各算一条；这与E题按主题集合去重的统计不同。

**4. a保存分钟数，交给D01。** 原a.append(i)保存整条元组，不能直接作为数字求和参数。正确写a.append(i[1])，得到默认情况下的[40, 30]。`sum_minutes(*a)`把它展开为两个数，满足题目要求的子函数调用与拆包。

| 中间量 | 默认门槛下的值 | 类型 |
|---|---|---|
| a | [40, 30] | list，元素int |
| h | 2 | int |
| sum | 70 | int |
| avg | 35.0 | float |
| 返回值 | (2, 70, 35.0) | tuple |

**5. 分母为0前先返回。** 原代码默认或无符合项时仍计算sum/len(a)，会除以0。正确代码先检查h==0，return之后本次函数立即结束，下面除法不会执行。

**6. 没有数据与平均0不同。** a为空意味着没有有效时段，返回None平均；a=[0]意味着有一条合法记录，平均0/1为0.0。因此要看条数h，不要用`if sum`把总数0当作没有数据。

### 正确答案

```python
def parse_signins(raw):
    a = raw.split(";")
    f = []
    for i in a:
        i = i.strip()
        if not i:
            continue
        h = i.split(",")
        h0 = h[0].strip().lower()
        h1 = h[1].strip().lower()
        f.append((h0, h1))
    return f

raw = " Ada ,Python;bo,SQL;ADA,python;;cy,Python; Bo ,Linux;ada,sql; \n"
print(parse_signins(raw))
# [('ada', 'python'), ('bo', 'sql'), ('ada', 'python'),
#  ('cy', 'python'), ('bo', 'linux'), ('ada', 'sql')]
print(parse_signins(""))       # []
print(parse_signins(" ; \n;;")) # []
print(parse_signins("Ada,Python;ADA,python"))
# [('ada', 'python'), ('ada', 'python')]
```

### 涉及知识点与详解

**1. 空白不等于空字符串。** 原`if i`能跳过''，但空格、换行组成的字符串仍为真；末尾片段去逗号拆分后只有一项，h[1]越界。先strip，纯空白变成''，再跳过。

| 原片段i | 去空白后 | 是否拆逗号 |
|---|---|---|
| '' | '' | 不拆 |
| ' \n' | '' | 不拆 |
| ' Ada ,Python' | 'Ada ,Python' | 拆成两个字段 |

**2. 片段清理与字段清理分别负责不同位置。** 整条i.strip只去片段两端；姓名末尾或主题开头还可能有空格，所以拆分后h[0]、h[1]也要分别strip。

**3. 规范大小写再保存。** Ada和ADA都变成ada，Python和python都变成python，后续E02才能把同人同主题合在一起。字符串方法返回新结果，需要用h0、h1接住。

**4. 一条记录是元组，多条记录是列表。** f.append((h0, h1))把两字段作为一整条记录保存。for与append保持顺序；此题不做去重，所以ada的python签到两次仍保留两条。

**5. 空输入的自然结果。** 空字符串split后有空片段，但被跳过，f仍为[]；不需要为了空输入另外创建不一致的返回类型。本题保证非空片段有合法字段，无须额外写异常处理。

详见[核心语法：真假值](../../01_学习笔记/Python/00_核心语法.md#conditions)和[字符串清洗与拆分](../../01_学习笔记/Python/02_字符串.md)。

## E02 · 每人学过哪些主题

题目要求：返回“姓名→不同主题集合”的字典；同人同主题去重，不同人分开；空输入{}，原records不变。

### 我的原答案

```python
# E02（5分）group_topics：
def group_topic(records):
    a={}
    if records:
        for i in records:
            if i[0] not in a :
                a[i[0]]=set(a[i[1]])
            else:
                a[i[0]]= a[i[1]].add(i[1])
        return a
    else:
        return []

```

### 正确答案

保留group_topic名字；它对应题目group_topics。组合报告也使用group_topic调用。

```python
def group_topic(records):
    a = {}
    for i in records:
        if i[0] not in a:
            a[i[0]] = set()
        a[i[0]].add(i[1])
    return a

records = [('ada', 'python'), ('bo', 'sql'), ('ada', 'python'),
           ('cy', 'python'), ('bo', 'linux'), ('ada', 'sql')]
a = group_topic(records)
for name, topics in a.items():
    print(name, sorted(topics))
# ada ['python', 'sql']
# bo ['linux', 'sql']
# cy ['python']
print(group_topic([]))  # {}
```

### 涉及知识点与详解

**1. 姓名是键，主题是集合元素。** i[0]是姓名，i[1]是主题。要访问姓名对应的集合，应写a[i[0]]；原a[i[1]]把主题当字典键，第一条会读取不存在的a['python']，产生KeyError。

**2. 第一次创建集合，随后只添加。** a先是{}。第一次遇到ada，先建a['ada']=set()；再add('python')。以后同名只add，不重置集合，否则已有主题会丢失。

| 处理记录 | 此人的主题集合内容 |
|---|---|
| ('ada', 'python') | python |
| ('ada', 'python')再次出现 | 仍只有python |
| ('ada', 'sql') | python、sql |

**3. add修改集合，返回None。** `a[i[0]].add(i[1])`已经把主题加入集合，不要把这个调用结果重新赋给a[i[0]]。原代码的赋值会把None保存到字典里。

**4. set()与set(字符串)不同。** set()创建空集合；set('python')把字符串按字符拆成集合。保存完整主题应使用add('python')，或{'python'}，不是把主题拆成字母。

**5. 各姓名有独立集合。** 每个新姓名都单独执行一次set()，不同人的主题不会互相混入。空records不进入循环，return a返回{}，不能返回[]。

**6. 显示顺序与实际类型分开。** 集合不保证顺序。示例sorted(topics)仅把集合临时排序为列表显示，a里对应的值仍是集合；只读取records，没有增删其元素。

详见[字典与集合：姓名分组、add与缺键](../../01_学习笔记/Python/04_字典与集合.md)。

题目要求：保留不同主题数>=min_topics的人，默认门槛1；返回姓名与主题数的元组列表；使用lambda按数量降序，同数量姓名升序；空/无符合项[]，不修改字典及集合。

### 我的原答案

未作答，仅保留题号和疲劳说明：

```python
# E03（5分）rank_learners：
#太累了，下次补上吧
```

### 正确答案

```python
def rank_learners(grouped, min_topics=1):
    a = []
    for i in sorted(grouped):
        h = len(grouped[i])
        if h >= min_topics:
            a.append((i, h))
    return sorted(a, key=lambda i: i[1], reverse=True)

grouped = {'cy': {'python'}, 'bo': {'sql', 'linux'}, 'ada': {'python', 'sql'}}
print(rank_learners(grouped))
# [('ada', 2), ('bo', 2), ('cy', 1)]
print(rank_learners(grouped, 2))  # [('ada', 2), ('bo', 2)]
print(rank_learners(grouped, 3))  # []
print(rank_learners({}))         # []
print(rank_learners({'z': {'sql'}, 'a': {'git'}}))
# [('a', 1), ('z', 1)]
```

### 涉及知识点与详解

**1. 集合长度就是不同主题数。** grouped['ada']是{'python', 'sql'}，len为2。重复签到已经由E02集合去重，不能用原记录条数替代主题数。

**2. 遍历字典取得键。** sorted(grouped)产生姓名键的升序列表；此时for里的i是姓名字符串，grouped[i]取得其集合，h取得不同主题数。

**3. 门槛含等号。** h>=min_topics保留刚好达到要求的人。门槛3时原例无人符合；a自然为空，sorted([])仍返回[]。

**4. 姓名顺序先确定，再稳定按数量排序。** for先按姓名升序添加元组，随后按主题数降序排序。Python排序是稳定的，同数量的人保留排序前的相对顺序，所以ada仍在bo前面。

| 步骤 | 元组列表 |
|---|---|
| 姓名升序收集 | [('ada', 2), ('bo', 2), ('cy', 1)] |
| 数量降序，保持同数相对顺序 | [('ada', 2), ('bo', 2), ('cy', 1)] |

样例刻意把输入字典按cy、bo、ada插入，正确结果仍应为ada、bo、cy，说明不是偶然依赖输入顺序。

**5. lambda接收一条排名元组。** lambda中的i是('ada', 2)这样的元组，i[1]取主题数；它是lambda自己的参数，与for中作为姓名字符串的i各有作用。reverse=True只控制这次主题数降序，姓名升序已经由前一步建立。

**6. 返回新列表，输入只读。** sorted和append创建新的排名列表，没有改变grouped的键和值，也没有向里面的集合add或remove。

详见[函数进阶：lambda与稳定排序](../../01_学习笔记/Python/06_函数进阶.md)、[字典与集合](../../01_学习笔记/Python/04_字典与集合.md)。

## E04 · 组合成报告

题目要求：依次调用解析、分组、排名函数，把实际min_topics传下去；记录数按筛选前算，人数/主题按筛选后算；返回四键字典；空输入及连续调用正确。

### 正确答案

先加载本页E01、E02、E03的正确函数定义，再运行本段。这里group_topic与前面的自定义函数名保持一致。

```python
def learning_report(raw, min_topics=1):
    records = parse_signins(raw)
    grouped = group_topic(records)
    ranked = rank_learners(grouped, min_topics=min_topics)

    a = set()
    for name, count in ranked:
        for i in grouped[name]:
            a.add(i)

    return {
        "record_count": len(records),
        "learner_count": len(ranked),
        "topic_names": sorted(a),
        "ranked": ranked,
    }

raw = " Ada ,Python;bo,SQL;ADA,python;;cy,Python; Bo ,Linux;ada,sql; \n"
print(learning_report(raw))
# {'record_count': 6, 'learner_count': 3,
#  'topic_names': ['linux', 'python', 'sql'],
#  'ranked': [('ada', 2), ('bo', 2), ('cy', 1)]}
print(learning_report(raw, 2))
# {'record_count': 6, 'learner_count': 2,
#  'topic_names': ['linux', 'python', 'sql'],
#  'ranked': [('ada', 2), ('bo', 2)]}
print(learning_report(raw, 3))
# {'record_count': 6, 'learner_count': 0, 'topic_names': [], 'ranked': []}
print(learning_report(""))
# {'record_count': 0, 'learner_count': 0, 'topic_names': [], 'ranked': []}
print(learning_report("z,unique;a,python;a,sql", 2))
# {'record_count': 3, 'learner_count': 1,
#  'topic_names': ['python', 'sql'], 'ranked': [('a', 2)]}
print(learning_report(raw)["learner_count"])  # 再用默认门槛，仍为3
```

### 涉及知识点与详解

**1. 返回值逐步接力。** 三个子函数各负责一步，上一函数的返回值成为下一函数的输入：

| 步骤 | 输入 | 接收返回值 | 返回类型 |
|---|---|---|---|
| parse_signins | 原始字符串 | records | 元组记录列表 |
| group_topic | records | grouped | 姓名→集合的字典 |
| rank_learners | grouped及实际门槛 | ranked | 姓名/主题数元组列表 |
| learning_report | 组合以上结果 | 外部调用者 | 四键字典 |

**2. 门槛必须转交。** `min_topics=min_topics`左边是排名函数参数名，右边是报告函数实际收到的值。若只调用rank_learners(grouped)，外层传2或3时下游仍用默认1。

**3. 四个键使用不同统计口径。** 本卷record_count是筛选前有效签到条数，不是通过主题数门槛的记录数；即使门槛3无人符合，原例record_count仍为6。

| 字段 | 从哪里计算 | 原例默认值 |
|---|---|---|
| record_count | len(records)，有效记录，保留重复 | 6 |
| learner_count | len(ranked)，通过门槛的人数 | 3 |
| topic_names | ranked中这些人的主题总集合，去重后升序列表 | linux、python、sql |
| ranked | E03原样返回的排名列表 | ada2、bo2、cy1 |

**4. 只收集筛选后人员的主题。** 从ranked取姓名，再读取grouped[name]，把这些主题加入a。不能直接遍历所有grouped；否则被筛掉的z独有主题unique仍会进入报告。示例门槛2只保留a，主题应只有python、sql。

**5. 主题去重与排序分两步。** 集合a去除不同人之间的重复主题；sorted(a)生成字母升序列表。报告要求topic_names为列表，所以这里转为列表正确；grouped里各人的主题仍保存为集合。

**6. 空输入及连续调用。** 空raw→records为空→grouped为空→ranked为空→a为空，四项自然为0、0、[]、[]。各容器在本次函数调用中产生，没有沿用上次门槛的结果，因此连续调用3、空输入、再默认门槛不会相互污染。函数内部只返回报告，演示打印放在外部。
