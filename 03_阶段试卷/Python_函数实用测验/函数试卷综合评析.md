| 原评分项 | 得分 | 依据 |

| 第二种规则调用 | 0/1 | 未写乘2规则及调用 |
| 空列表 | 1/1 | 空输入返回[] |

你的两层函数共同生成了样例`[1,3,6]`，因此已有部分结果分。但是原题约定operation接收一个元素，当前实现没有遵守该约定：

- `add_one(2)`报TypeError，因为整数不能迭代。
- 换成`lambda x: x + 1`，map_values报列表与整数相加的TypeError。
- 换成`lambda x: x * 2`，得到`[0,2,5,0,2,5]`；传入的是列表，乘2变成列表重复。
- 记录operation的调用参数时，实际只收到一次`[0,2,5]`，而正确应依次收到0、2、5。

```python
def add_one(value):
    return value + 1

def map_values(values, operation):
    a = []
    for i in values:
        a.append(operation(i))
    return a
```

理解分工：add_one处理一个值；map_values负责遍历列表并收集每次返回值。旧进阶G06已使用这种结构，可先比较两份自己的代码，再合上旧代码重写。
