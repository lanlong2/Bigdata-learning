## B02 · 销量排序

题目要求：按数量降序返回新列表，原列表不变；同数量保持原顺序，空列表返回`[]`，使用lambda作为key。本题失分在问题说明，修复代码已符合要求。

### 我的原答案

```python
# B02（10分）问题说明、rank_items修复与调用：
#说明：sort只会出值但是不返回，应用sorted，同时没有考虑传入空值
def rank_items(rows):
    if rows:
        a= sorted(rows,key=lambda rows :rows[1],reverse=True)
        return a
    else:
        return []
rows=[("pen",2),("book",5),("bag",2)]
ranked=rank_items(rows)
print(rows)
print(ranked)
```

### 正确答案

问题说明：`rows.sort(...)`会直接修改原列表，返回值是`None`；直接返回它，调用者得到的是`None`。本题需要保留原列表并返回排序结果，因此使用`sorted(...)`。

下面保留你的代码结构，补上空输入调用：

```python
def rank_items(rows):
    if rows:
        a = sorted(rows, key=lambda rows: rows[1], reverse=True)
        return a
    else:
        return []

rows = [("pen", 2), ("book", 5), ("bag", 2)]
ranked = rank_items(rows)
print(rows)               # [('pen', 2), ('book', 5), ('bag', 2)]
print(ranked)             # [('book', 5), ('pen', 2), ('bag', 2)]
print(rank_items([]))     # []
```

### 涉及知识点与详解

**1. 原地修改与返回结果。** “原地修改”指列表对象本身被改变。`sort()`改变原列表，但调用表达式的值是`None`；所以`a = rows.sort()`中的a并不是排序列表。`sorted(rows)`创建新的排序列表，把它交给调用者，原rows的排列保持不变。

| 写法 | 是否改变原列表 | 调用表达式得到什么 |
|---|---|---|
| `rows.sort(...)` | 是 | `None` |
| `sorted(rows, ...)` | 否 | 新的排序列表 |

**2. lambda与key。** `key`指定“拿每个元素的哪个值来比较”。这里每个元素是一条元组，例如`('pen', 2)`；`rows[1]`取得数量2。lambda中的rows是它自己的形参，运行时接收一条元组；外层rows接收整个列表。同名可以运行，理解时要看它们各自接收什么值。

**3. 降序与稳定排序。** `reverse=True`让数量从大到小排列。同数量的元素仍保持输入时的相对顺序，所以pen与bag都是2时，pen仍在bag前面。稳定排序不会自动按名称排列；D04另有“同销量按名称升序”的要求，需要增加名称排序步骤。

**4. 空列表。** `sorted([])`本来就返回`[]`。你的if/else也能正确返回空列表。原题错误函数对空列表调用sort不会因空列表报错，只是仍返回`None`；因此“没有考虑空值”不能完整说明根因。

## C01 · 清洗收货人名单

题目要求：去两端空白、转小写、丢弃清洗后为空的名字；保留内部空格、重复项和原顺序，返回新列表。

### 我的原答案

```python
# C01（10分）clean_names与调用：
names = [" Alice Smith ", " \t", "BOB", " alice smith\n"]
def clean_names(names):
    c=[]
    for i in names:
        a=i.lower().strip()
        if i:
            c.append(a)
        else:
            pass
    return c
print(clean_names(names))
```

### 正确答案

关键修改是把`if i`改为`if a`：先清洗，再检查清洗结果。

```python
def clean_names(names):
    c = []
    for i in names:
        a = i.lower().strip()
        if a:
            c.append(a)
    return c

names = [" Alice Smith ", " \t", "BOB", " alice smith\n"]
print(clean_names(names))   # ['alice smith', 'bob', 'alice smith']
print(clean_names([]))      # []
print(clean_names(["  "]))  # []
print(clean_names(["", "\t", " A B "]))  # ['a b']
print(names)               # 原输入列表保持不变
```

### 涉及知识点与详解

**1. 空字符串与空白字符串不同。** Python在if中判断字符串时，空字符串`''`为假；只要含有字符就为真，即使那些字符是空格、制表符或换行。

| i的值 | `bool(i)` | `i.strip()` | `bool(i.strip())` |
|---|---|---|---|
| `''` | False | `''` | False |
| `'  '` | True | `''` | False |
| `'\t'` | True | `''` | False |
| `' Alice Smith '` | True | `'Alice Smith'` | True |

你判断的是原始i，所以`' \t'`通过了if；随后添加的是已经变成`''`的a。原答案实际输出`['alice smith', '', 'bob', 'alice smith']`。正确做法判断a，使“过滤条件”和“准备保存的值”一致。

**2. strip与lower的作用。** `strip()`去除字符串两端的空白，包括本题中的空格、制表符和换行；中间空格保留。`lower()`把字母转成小写。两者返回新的字符串，不会原地改动i，因此必须使用返回值，例如赋给a。这里先lower再strip符合题目要求。

**3. append、新列表与顺序。** 每次合格就`c.append(a)`，按遍历顺序添加到新列表。这样输入列表不变，重复的alice smith也保留。若改用集合去重，会改变本题要求；若使用`replace(' ', '')`，会删掉名字内部空格，同样不符合要求。

**4. 空列表的自然结果。** names为空时，for循环执行0次，c仍为`[]`，return直接返回它；无需为了空列表另写特殊分支。

## C02 · 合并多批到货数量

题目要求：函数使用不定长位置参数；除直接传整数外，还要将列表通过`*batches`拆包传入。

### 我的原答案

```python
# C02（10分）received_total与调用，含列表拆包：
def recived_total(*quantity):
    if quantity:
        sum=0
        for i in quantity:
            if type(i)==list:
                for a in i:
                    sum=sum+a
            else:
                sum=sum+i

    else:
        return 0
batches=[2,4,1]
print(recived_total(3,0,5))
print(recived_total(batches))
```

### 正确答案

你的整数累计与空调用逻辑已正确，缺少的是调用处的`*`。下面保留函数名与主要变量名，按原题“数量均为整数”的约定简化函数体；订正时也可保留原函数，只补正确的拆包调用。

```python
def recived_total(*quantity):
    sum = 0
    for i in quantity:
        sum = sum + i
    return sum

batches = [2, 4, 1]
print(recived_total(3, 0, 5))   # 8
print(recived_total(*batches)) # 7
print(recived_total())         # 0
print(recived_total(0))        # 0
```

### 涉及知识点与详解

**1. 定义处的*：收集位置参数。** `def recived_total(*quantity)`允许调用者传不同数量的位置参数。函数把它们收集为一个元组，交给quantity；quantity的名称可以自定。

| 调用 | 函数内部quantity |
|---|---|
| `recived_total(3, 0, 5)` | `(3, 0, 5)` |
| `recived_total()` | `()` |
| `recived_total(batches)` | `([2, 4, 1],)` |
| `recived_total(*batches)` | `(2, 4, 1)` |

**2. 调用处的*：展开可迭代对象。** `*batches`把列表中的2、4、1展开为三个位置参数。定义处的*把多个参数收起来；调用处的*把一个容器的元素展开出去。符号相同，作用取决于它出现的位置。

**3. 原答案为什么也得到7。** 你直接传batches后，quantity中只有一个元素，这个元素是列表。函数里额外判断list并进入第二层循环，所以最终算出7。这是另外实现的“接受列表”功能；本题指定练习的拆包调用仍没有写出。

**4. 从0开始累计。** sum放在函数内部，每次调用都重新初始化。空调用时没有元素，循环执行0次，返回0；传入0时加0，结果也正确。无需先判断quantity是否为空。这里sum是你自己的局部变量，沿用即可；它在该函数作用域中暂时遮住同名内置函数，当前实现没有调用内置sum，因此不影响结果。

## C03 · 生成订单摘要标签

题目要求：用不定长关键字参数接收字段；缺product时用“未命名”，缺city时用“未知”，返回“商品@城市”；保留已传入的空字符串，忽略其他字段。

### 我的原答案

只有下面这行注释，尚无函数实现：

```python
# C03（10分）order_label与调用：
# def order_label(**field:product="未命名"):
```

### 正确答案

保留你尝试使用的field名称：

```python
def order_label(**field):
    product = field.get("product", "未命名")
    city = field.get("city", "未知")
    return product + "@" + city

print(order_label(product="pen", city="杭州", note="加急")) # pen@杭州
print(order_label(product="book"))                         # book@未知
print(order_label())                                       # 未命名@未知
print(order_label(city="杭州"))                            # 未命名@杭州
print(order_label(product="", city="杭州"))                # @杭州
```

### 涉及知识点与详解

**1. 定义处的双星号：收集关键字参数。** `**field`把调用时传入的关键字参数收集为字典。例如`order_label(product='pen', city='杭州')`使field成为`{'product': 'pen', 'city': '杭州'}`。field这个名字可以自定；双星号才决定其收集关键字参数的作用。

**2. 收集参数与字段默认值分开处理。** 函数头先写`def order_label(**field):`，再在函数体中读取字典的键。你注释里的`**field:product="未命名"`不是本题的字段默认值写法，去掉注释后也不是有效的函数定义语法。本题两个字段的缺失默认值可分别交给get处理。

**3. dict.get的默认值。** `field.get('product', '未命名')`先找product这个键：键存在就返回对应的值，键不存在才返回“未命名”。直接写`field['product']`时，缺键会报KeyError；get能在本题中处理字段缺失。

| field | `field.get('product', '未命名')` |
|---|---|
| `{}` | `'未命名'` |
| `{'product': 'book'}` | `'book'` |
| `{'product': ''}` | `''` |

**4. 键缺失与空字符串不同。** product已经传入`''`时，键存在，所以应保留空字符串；结果是`'@杭州'`。如果使用`field.get('product') or '未命名'`，空字符串也会触发默认值，不符合本题约定。

**5. 忽略额外字段与返回结果。** 函数只读取product、city，因此note等其他键不影响结果。return把拼好的字符串交给调用处；函数内部不打印，外部print用于演示。

## C04 · 批量应用处理规则

题目要求：operation接收一个元素，返回该元素的处理结果；map_values逐元素调用它，并收集为新列表。

### 我的原答案

```python
# C04（10分）map_values、两个处理函数与调用：
def add_one(value):
    a=[]
    for i in value:
        i=i+1
        a.append(i)
    return a
def map_values(values,operation):
    if values:
        return operation(values)
    else:
        return []
print(map_values([0,2,5],add_one))
```

### 正确答案

```python
def add_one(value):
    return value + 1

def double_value(value):
    return value * 2

def map_values(values, operation):
    a = []
    for i in values:
        a.append(operation(i))
    return a

values = [0, 2, 5]
print(map_values(values, add_one))      # [1, 3, 6]
print(map_values(values, double_value)) # [0, 4, 10]
print(map_values([], add_one))          # []
print(add_one(2))                       # 3
print(values)                          # [0, 2, 5]，输入未改变
```

### 涉及知识点与详解

**1. 一个值与一组值。** 本题的add_one接收一个数字，如2，返回3。map_values接收列表，负责遍历。把“单个值的处理规则”与“整张列表的遍历”放在各自的函数中，外层就能重复使用不同规则。

| 函数 | 接收什么 | 负责什么 | 返回什么 |
|---|---|---|---|
| `add_one` | 一个数字 | 加1 | 一个数字 |
| `double_value` | 一个数字 | 乘2 | 一个数字 |
| `map_values` | 列表、规则函数 | 遍历并逐元素调用规则 | 新列表 |

**2. 传入函数对象与调用函数。** `map_values(values, add_one)`把add_one函数本身传进去；map_values内部的operation就可以调用这个函数。`operation(i)`才真正执行规则，并把这次的结果交给append。若写`add_one(2)`作为第二个参数，会先计算出3，再把数字3传入；后面无法把这个数字当成规则函数调用。

**3. 原答案的样例为什么正确。** 你的add_one接收整张列表并自己遍历，map_values只是把列表整张交给它。两者配合能得到样例，但其他合法单元素规则接到列表后会出错：`lambda x: x + 1`会尝试列表加整数；`lambda x: x * 2`会把列表重复两遍。

**4. operation应该收到哪些值。** 对`[0,2,5]`，正确代码依次执行`operation(0)`、`operation(2)`、`operation(5)`；原代码只执行一次`operation([0,2,5])`。理解这个调用过程，比只检查最终样例更能发现问题。

**5. 新列表与空输入。** a在每次调用中重新创建，append按遍历顺序收集返回值。原列表没有被赋值或增删。空列表时for执行0次，a自然为空，直接返回`[]`。

## D01 · 解析订单

题目要求：按分号拆记录，跳过空白片段；商品名去两端空白并转小写，数量转整数；返回按原顺序排列的元组记录列表，保留0数量。

### 我的原答案

未作答，答卷保留了卡点说明：

```python
# D01（6分）parse_orders：
#不会处理空白数据，本大题基本搁置
```

### 正确答案

```python
def parse_orders(raw):
    records = []
    for i in raw.split(";"):
        a = i.strip()
        if not a:
            continue
        name, quantity = a.split(",")
        records.append((name.strip().lower(), int(quantity.strip())))
    return records

raw = " Pen ,2;book,0;;PEN,3; bag ,5;book,2; \n"
print(parse_orders(raw))
# [('pen', 2), ('book', 0), ('pen', 3), ('bag', 5), ('book', 2)]
print(parse_orders(" ; \n;;")) # []
print(parse_orders(""))       # []
print(parse_orders("book,0")) # [('book', 0)]
```

### 涉及知识点与详解

**1. split返回列表。** `raw.split(';')`把一个大字符串拆成多个字符串，结果是列表。连续分号会产生空字符串；末尾空白也可能形成独立片段。先遍历这个列表，再对每个字符串元素使用strip。

**2. 清洗后判空与continue。** a是去除片段两端空白后的字符串。a为空就continue，跳过当前这一次循环，继续检查下一条；此时不会执行下面的逗号拆分。若用break，会直接结束整个循环，后面的有效订单也丢失。

**3. 先跳过空项，再拆包。** `name, quantity = a.split(',')`把两个字段分别赋给两个变量。原题保证非空记录恰好有一个逗号；空字符串没有两个字段，所以必须在这行之前过滤。拆包需要右边的元素数量与左边变量数量匹配。

**4. 记录两端清理与字段两端清理。** 对片段`' Pen ,2'`做strip后仍是`'Pen ,2'`，name中仍可能带尾部空格。因此每个字段还需分别strip。商品名lower使Pen与PEN都成为pen，后续累计才能合到同一个键。

**5. 字符串转整数。** split拆出的数量仍是字符串，例如`'0'`。`int(quantity.strip())`把它转换成整数0。D01负责解析，所以0要保留；是否过滤它由D02的门槛决定。不要用`if int(quantity)`过滤0。

**6. 元组与列表各自保存什么。** `(name, quantity)`是一条记录，用元组保存商品与数量；records是多条记录组成的列表。`records.append((...))`把一整条元组加入列表，保留原输入顺序。

| 处理到哪一步 | 类型 | 例子 |
|---|---|---|
| raw | str | `' Pen ,2;book,0;;'` |
| `raw.split(';')` | list，元素为str | `[' Pen ,2', 'book,0', '', '']` |
| a | str | `'Pen ,2'` |
| `a.split(',')` | list，元素为str | `['Pen ', '2']` |
| 一条规范记录 | tuple，其中数量为int | `('pen', 2)` |
| records | list，元素为tuple | `[('pen', 2), ('book', 0)]` |

## D02 · 按单条数量筛选

题目要求：门槛默认1，实际传入其他门槛时使用该值；数量大于等于门槛的记录保留，返回新列表并保持顺序。

### 我的原答案

未作答，对应区域只有题号：

```python
# D02（6分）select_orders：
```

### 正确答案

```python
def select_orders(records, min_quantity=1):
    a = []
    for name, quantity in records:
        if quantity >= min_quantity:
            a.append((name, quantity))
    return a

records = [('pen', 2), ('book', 0), ('pen', 3), ('bag', 5), ('book', 2)]
print(select_orders(records))
# [('pen', 2), ('pen', 3), ('bag', 5), ('book', 2)]
print(select_orders(records, min_quantity=3))
# [('pen', 3), ('bag', 5)]
print(select_orders(records, 0))  # 五条记录全部保留
print(select_orders(records, 100)) # []
print(select_orders([]))          # []
```

### 涉及知识点与详解

**1. 默认参数与实际传参。** `min_quantity=1`表示调用时省略门槛就使用1。调用`select_orders(records, 3)`或`select_orders(records, min_quantity=3)`时，函数内部min_quantity都变成3，比较条件必须使用这个变量，不能写死1。

**2. 包含边界的比较。** 大于等于写`>=`。门槛3时，数量刚好3也应保留；只写`>`会漏掉边界。门槛0时，0数量满足条件，不应再被其他判断剔除。

**3. 循环拆包与新列表。** `for name, quantity in records`每次取一条两元素元组，把商品、数量分别赋给两个变量。合格时把元组加到a，原records不删不改；按原顺序遍历并append，结果也保持原顺序。

**4. 没有匹配项与空列表。** 两种情况下都不会append，a最终为`[]`。把空列表初始化与return放在循环外，所有输入都能得到列表返回值。

**5. 单条筛选。** 同名商品可以重复出现，条件分别检查每一条记录。例如两个`('pen', 2)`遇到门槛3时，都不符合；不能先合计成4再保留。这一顺序会直接影响D04的结果。

## D03 · 按商品累计

题目要求：返回“商品名→累计数量”的字典；同名相加，0数量也保留商品键，空输入返回空字典。

### 我的原答案

未作答，对应区域只有题号：

```python
# D03（8分）sum_by_product：
```

### 正确答案

```python
def sum_by_product(records):
    total = {}
    for name, quantity in records:
        if name in total:
            total[name] = total[name] + quantity
        else:
            total[name] = quantity
    return total

records = [('pen', 2), ('pen', 3), ('bag', 5), ('book', 2)]
print(sum_by_product(records))  # {'pen': 5, 'bag': 5, 'book': 2}
print(sum_by_product([('book', 0)])) # {'book': 0}
print(sum_by_product([]))           # {}
```

### 涉及知识点与详解

**1. 用商品名作为字典键。** 同一种商品对应同一个键，数量作为值。列表里可以有多条pen记录；累计字典里只有一个pen键，值保存这些记录的数量总和。

**2. 第一次建立键，后续累加。** `name in total`检查字典是否已有这个商品键。第一次遇到就把quantity放进去；再次遇到就用“已有数量+当前数量”更新。若每次都直接`total[name] = quantity`，后面的值会覆盖前面，pen最终只剩3。

| 当前输入记录 | 处理后的total |
|---|---|
| `('pen', 2)` | `{'pen': 2}` |
| `('pen', 3)` | `{'pen': 5}` |
| `('bag', 5)` | `{'pen': 5, 'bag': 5}` |
| `('book', 2)` | `{'pen': 5, 'bag': 5, 'book': 2}` |

**3. get也可以实现累计。** 相同逻辑可以写成`total[name] = total.get(name, 0) + quantity`。键不存在时，把已有数量视为0；键存在时取实际累计值。先理解if/else写法，再读这一行即可，不要求强行缩短代码。

**4. 0数量与不存在的键不同。** 输入`('book', 0)`说明确实有book记录，只是数量为0。它应产生`{'book': 0}`。这里没有门槛筛选，也不能因为quantity为假就略过这条记录。

**5. 字典为空与输入不变。** total在函数内新建。空输入时循环0次，返回`{}`；非空时修改的也是total，原records不变。字典显示顺序不评分，销量与名称的排列在D04再处理。

## D04 · 组合成可复用报告

题目要求：依次调用D01、D02、D03，把筛选后的记录数、数量总和、商品种类数与排序结果放入字典；销量降序，同销量名称升序，空输入和不同门槛都正确。

### 我的原答案

未作答，对应区域只有题号：

```python
# D04（10分）build_report：
```

### 正确答案

先运行前面D01—D03的三个函数定义，再运行下面代码：

```python
def build_report(raw, min_quantity=1):
    records = parse_orders(raw)
    selected = select_orders(records, min_quantity=min_quantity)
    total = sum_by_product(selected)

    sum1 = 0
    for p in total.values():
        sum1 = sum1 + p

    ranked = sorted(total.items())
    ranked = sorted(ranked, key=lambda row: row[1], reverse=True)

    return {
        "record_count": len(selected),
        "quantity_sum": sum1,
        "product_count": len(total),
        "ranked": ranked,
    }

raw = " Pen ,2;book,0;;PEN,3; bag ,5;book,2; \n"
print(build_report(raw))
# {'record_count': 4, 'quantity_sum': 12, 'product_count': 3,
#  'ranked': [('bag', 5), ('pen', 5), ('book', 2)]}
print(build_report(raw, min_quantity=3))
# {'record_count': 2, 'quantity_sum': 8, 'product_count': 2,
#  'ranked': [('bag', 5), ('pen', 3)]}
print(build_report(raw, 0))
# {'record_count': 5, 'quantity_sum': 12, 'product_count': 3,
#  'ranked': [('bag', 5), ('pen', 5), ('book', 2)]}
print(build_report(""))
# {'record_count': 0, 'quantity_sum': 0, 'product_count': 0, 'ranked': []}
print(build_report(raw, 100))
# {'record_count': 0, 'quantity_sum': 0, 'product_count': 0, 'ranked': []}
```

### 涉及知识点与详解

**1. 子函数的返回值衔接。** 一个函数的返回值成为下一步的输入。按原题顺序：

| 调用 | 输入 | 返回值由谁接收 |
|---|---|---|
| `parse_orders(raw)` | 原字符串 | records：元组记录列表 |
| `select_orders(records, min_quantity=...)` | 记录列表与实际门槛 | selected：筛选后的列表 |
| `sum_by_product(selected)` | 筛选列表 | total：累计字典 |
| `build_report(...)` | 串起上述步骤 | 调用者得到四键报告字典 |

函数内部不打印，返回值能继续用于下一步。最后在调用处print，才显示完整报告。若子函数只print而不return，下一步就拿不到需要的数据。

**2. 门槛要继续传给下游。** build_report接收的min_quantity，要通过`select_orders(records, min_quantity=min_quantity)`传进去。等号左边是下游参数名，右边是当前函数收到的实际值。只写`select_orders(records)`会一直使用下游默认1，使外层传入的3或0失效。

**3. 先筛单条，再累计。** 对`'pen,2;pen,2'`和门槛3，两条记录都应被剔除，结果为空。若先合计得到pen=4再筛选，会错误地保留pen。本题筛选对象是每条订单，不是累计字典中的总销量。

**4. 三个统计数字不能混淆。** 默认门槛下，selected有4条记录，其中pen出现两条；total只有pen、bag、book三个键。

| 报告字段 | 怎么算 | 样例值 | 含义 |
|---|---|---:|---|
| record_count | `len(selected)` | 4 | 筛选后的订单记录条数 |
| quantity_sum | 累加total的值 | 12 | 商品数量总和 |
| product_count | `len(total)` | 3 | 不同商品种类数 |

total已经按商品累计，所以累加它的值仍等于筛选记录的数量总和。统计0数量记录时，数量总和可能不变，但记录条数可能增加；因此门槛0时本例record_count变5，quantity_sum仍为12。

**5. items与values。** `total.items()`提供每个“键、值”组成的元组，如`('pen', 5)`；sorted把这些元素整理为列表，因此ranked是元组列表。`total.values()`提供数量值，本题循环累加这些数量。直接遍历字典得到的是键，不是数量。

**6. 两次稳定排序。** `sorted(total.items())`先按元组的第一个元素，即商品名升序排列；本题每个商品名唯一，初始顺序为bag、book、pen。再按`row[1]`的销量降序稳定排序，bag与pen同为5时仍保持第一次排序得到的bag在pen前。因此最终为bag、pen、book。先处理次要条件“名称”，再稳定排序处理主要条件“销量”，就能同时满足两项要求。

若只按销量排序，结果相同的商品会保留进入排序前的顺序，可能是输入时的pen在bag前；这符合B02的同数量原顺序要求，却不符合D04的名称升序要求。

**7. 空输入与每次调用重新计算。** 空字符串解析成`[]`，筛选仍为`[]`，累计成为`{}`，数量循环0次、sum1为0，排序结果为`[]`。所有步骤都能处理空容器，报告自然全为0。records、selected、total、sum1都在本次调用中产生，未借用上次结果；连续调用不同门槛时也能各自正确。
