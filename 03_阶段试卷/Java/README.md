# Java后端 · 能力检查与出卷规划

**本目录现有内容是检查规划，JV01—JV03正式试卷／检查任务均待生成。** 不代表已学习Java、已备完整卷或已经测验。Java在大模型应用路线结束后开始。

| 节点 | 前置 | 应覆盖的能力 | 建议形式 | 状态 |
|---|---|---|---|---|
| JV01 语言与程序组织 | J00、J01及对应练习 | 类型、控制流程、数组方法、面向对象、集合、异常、文件与必要的并发/JVM基础 | 小程序实现＋解释与修错；约90分钟 | 待按实际已学范围出卷，答案分离 |
| JV02 后端整合 | J02—J05 | 代表算法、请求过程、SQL/JDBC、索引事务、接口校验、异常测试、缓存与权限边界 | 给定小业务的接口实现、查询分析和排错；可分两次90分钟 | 待生成完整题目、数据库脚本及评分标准 |
| JV03 独立业务交付 | J06项目核心完成 | 业务正确、权限、事务、重复与并发、测试、部署、性能证据、本人解释和修改 | 独立运行项目＋小需求变更＋问题定位 | 以[工单管理后端任务书](../../05_项目实践/Java/00_工单管理后端/任务书.md)展开，正式任务待生成 |

出卷时只默认使用已教过的知识，明确输入、预期输出、业务约束、运行方式、时间和分项给分依据。技术解释与算法训练已经属于学习预算，简历、投递和正式面试另计。

检查关注代码类型、逻辑、结果与边界，保留合法自选变量名。基础学习不用AI写代码；复杂项目部分使用AI时，要求理解、修改和验证相应代码，检查时可围绕它提出变更与排错任务。

批改报告新建在对应试卷目录，保留原答卷和历史分数；订正、复测单独保存。用户明确完成事实直接记录，不把重新测验设为状态更新的前置，不自动加入错题目录。
