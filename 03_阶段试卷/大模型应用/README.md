## 出卷前必须写清

1. 允许使用的已学语法、框架与文档；不引入尚未教过的技术作为隐含前置。
2. 独立练习时不用AI生成代码；复杂项目可以部分使用AI，但要能解释、修改、测试相应代码。
3. 精确的输入、正常和错误输出、固定数据及评测口径；调用外部模型时区分确定性工程检查和可能波动的生成结果。
4. 分项分值与评分依据。建议单次卷总分100，但正式出卷前不凭空生成“已有评分标准”或成绩。
5. 原答卷保存方式、批改报告路径、订正与复测分别怎样保存。

完成标准是能运行、解释、维护并识别局限，不是只演示一次成功回答。正式批改仍按原评分细项给分；用户后续明确说明已完成、已订正或复测通过，按其所指范围直接记录，不要求重新提供证明。检查与学习事实分开维护，不自动收录错题。
