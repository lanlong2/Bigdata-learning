## E001 · 列表连续变化

每行接着上一行的结果推，不回到初始列表。`[1,2,3]`先`pop(1)`再`append(4)`，得到`[1,3,4]`。

## E002 · 索引与切片

列表`a[1]`取元素，`a[1:2]`取新列表；区别包括类型，不只是外观。

<a id="e003"></a>

## E003 · 切片符号与范围

`a[3,5]`不是列表切片；用`a[3:6]`取下标3、4、5。切片含起点、不含终点，按下标取而不是按元素值取。

## E004 · 循环覆盖容器变量

`for i, scores in enumerate(scores)`会把scores重新绑定成元素。换用另一个变量即可，如`for i, p in enumerate(scores)`；不要求统一命名风格。

### 本轮卡点：i的类型取决于遍历什么

```python
grouped = {'cy': {'python'}, 'bo': {'sql', 'linux'}}
for i in grouped:
    # i是姓名字符串，例如'cy'
    print(i, grouped[i], len(grouped[i]))
# cy {'python'} 1
# bo的主题集合含sql、linux，主题数为2；集合显示顺序不限
```

`grouped`才是字典；`i`是键；`grouped[i]`是这个人的主题集合。`i.get`会因字符串没有`get`方法报错。这里`len(grouped.get(i))`也能取到主题数，因为i来自该字典，键一定存在；`get()`要对字典调用并传入键。

E04里的`c`只有姓名和数字，具体主题保存在`b`里：

```python
i = ('ada', 2)             # 从c中取出的排名元组
# i[0]是'ada'
# b[i[0]]等于b['ada']，取出{'python', 'sql'}
```

`c`决定收集哪些人的主题，`b`提供这些人学过的主题。

### 完整正确做法

保留你的a、b、c、d、f、h、i、p、y等变量名。E01按题目接口写为`parse_signins`；你当前代码使用`parise_signins`，复用时让定义与调用的名字一致即可。

```python
def parse_signins(raw):
    a = []
    b = raw.split(';')
    for i in b:
        if i.strip():
            c = i.split(',')
            d = c[0].strip().lower()
            f = c[1].strip().lower()
            a.append((d, f))
    return a


def group_topics(records):
    a = {}
    for i in records:
        if i[0] not in a:
            a[i[0]] = set()
        a[i[0]].add(i[1])
    return a


def rank_learners(grouped, min_topics=1):
    a = []
    for i in grouped:
        if len(grouped[i]) >= min_topics:
            a.append((i, len(grouped[i])))
    a = sorted(a, key=lambda x: x[0])
    c = sorted(a, key=lambda x: x[1], reverse=True)
    return c


def learning_report(raw, min_topics=1):
    h = {}
    a = parse_signins(raw)
    h['record_count'] = len(a)
    b = group_topics(a)
    c = rank_learners(b, min_topics)
    h['learner_count'] = len(c)
    p = set()
    for i in c:
        p.update(b[i[0]])
    y = sorted(p)
    h['topic_names'] = y
    h['ranked'] = c
    return h
```

- E02：`set()`是空集合，`{}`是空字典；`set('python')`会拆成字母。`add('python')`添加一个完整主题，原地修改集合，返回`None`，不再赋回a。
- E03：先排序姓名时不写`reverse=True`；第二次排序必须接着使用第一次的结果。本例先把姓名排序结果保存回a，再按主题数排序。同数量的人保留上一步的姓名顺序。如果两次都从未更新的原a排序，第一次结果就没有参与最终排名。
- E04：`p.update(b[i[0]])`把该人的每个主题加入总集合，自动去重；`sorted(p)`把主题集合变成字母升序列表。列表用`append`，集合用`add/update`，字典用键赋值。
- 参数名为`min_topics`，调用时转交实际门槛；返回键为`record_count`，不是`records_count`。不同个人变量名可以保留，参数接口与返回键要按题意核对。

### 为什么不用另外判断空字典和无匹配

`>= min_topics`已经完成门槛判断。空字典不进入循环，或所有人都不达门槛时，a仍为`[]`；排序空列表得到`[]`，lambda不会执行。排序放在循环外，c一定会得到赋值；原来放在循环内时，空字典会使c未定义。

报告中c为空时，收集主题的循环也不执行，p仍为空集合，`sorted(p)`得到`[]`。题目保证门槛为正整数，因此这里按题目前提处理。

### 关键结果与边界

```python
raw = ' Ada ,Python;bo,SQL;ADA,python;;cy,Python; Bo ,Linux;ada,sql; \n'
print(learning_report(raw))
# {'record_count': 6, 'learner_count': 3,
#  'topic_names': ['linux', 'python', 'sql'],
#  'ranked': [('ada', 2), ('bo', 2), ('cy', 1)]}
```

| 输入／门槛 | record_count | learner_count | topic_names | ranked |
|---|---:|---:|---|---|
| 原例，1 | 6 | 3 | `['linux', 'python', 'sql']` | `[('ada', 2), ('bo', 2), ('cy', 1)]` |
| 原例，2 | 6 | 2 | `['linux', 'python', 'sql']` | `[('ada', 2), ('bo', 2)]` |
| 原例，3 | 6 | 0 | `[]` | `[]` |
| 空字符串，1 | 0 | 0 | `[]` | `[]` |
| `'z,git;a,python;a,sql'`，2 | 3 | 1 | `['python', 'sql']` | `[('a', 2)]` |

最后一行用于看清：z被筛掉后，git也不能进入主题列表。重复签到仍计入record_count，但同一人的主题集合只保留一个相同主题；每次调用都新建结果容器，连续调用门槛1→2→3→1时结果互不影响。
