## E001 · 列表：忘记列表是"累积变化"的 🔴 最严重

来源：原列表笔记错题部分；历史发生日期未记载；状态：待独立复测。整理日期2026-09-17。

下次复习日期：待安排。复测日期与结果：待填写。

**你的错误**：

```python
nums = [1, 2, 3, 4, 5]
x = nums.pop(2)        # 你答对了：nums = [1, 2, 4, 5]
nums.append(99)        # 你答 [1,2,3,4,5,99]  ✗ 3 又跑回来了！
nums[0] = "换成我了"    # 你答 [换成我了,2,3,4,5]  ✗ 又从头算了
```

**错在哪**：你每一步都回到**最初的** `[1,2,3,4,5]` 去算，但列表在 `pop` 之后**已经永久变了**。

**正确的思考方式**——画一条时间线，每步更新一次：

```
初始:              [1, 2, 3, 4, 5]
pop(2) 后:         [1, 2, 4, 5]              ← 3 被删掉了，回不来了
append(99) 后:     [1, 2, 4, 5, 99]          ← 接着上一行推
nums[0]="..." 后:  ["换成我了", 2, 4, 5, 99]  ← 接着上一行推
[::-1] 结果:       [99, 5, 4, 2, "换成我了"]
```

📌 **记住**：列表是"活的"。凡是 `append`、`insert`、`remove`、`pop`、`sort`、`reverse`、`lst[i]=值` 这些操作，**做完列表就永久变了**，后面的每一行看到的都是变化后的它。

✅ **纠错习惯**：做连续操作的题时，**每行代码后面用注释写一遍当前列表长什么样**，强迫自己一步步推。

## E002 · 列表：索引和切片分不清 🔴

来源：原列表笔记错题部分；历史发生日期未记载；状态：待独立复测。整理日期2026-09-17。

下次复习日期：待安排。复测日期与结果：待填写。

**你的错误**：

```python
fruits[1:2]      # 题目要"取出香蕉"，你写了切片
```

**错在哪**：

| 写法 | 得到什么 | 类型 |
|------|---------|------|
| `fruits[1]` | `"香蕉"` | 一个**元素**（字符串） |
| `fruits[1:2]` | `["香蕉"]` | 一个**新列表**（外面有方括号！） |

看着差不多，但一个是"从格子里把东西拿出来"，一个是"切下一段格子"。后面如果对它做字符串操作（比如 `.upper()`），列表版本直接报错。

📌 **记忆法**：**有冒号 = 切片 = 得到列表；没冒号 = 索引 = 得到元素**。

## E003 · 列表：切片写成逗号 🔴

来源：原列表笔记错题部分；历史发生日期未记载；状态：待独立复测。整理日期2026-09-17。

下次复习日期：待安排。复测日期与结果：待填写。

**你的错误**：

```python
nums[3,5]      # ✗ TypeError: list indices must be integers or slices
nums[7,9]      # ✗ 同上
```

**错在哪**：切片的灵魂是**冒号 `:`**。逗号 `,` 在 Python 里是"分隔多个东西"的意思，`nums[3, 5]` 会被理解成"用 `(3,5)` 这个元组当索引"，列表不认，直接报错。

✅ 正确：`nums[3:6]`、`nums[7:]`

**还有一个连带问题**：你想取 `[3,4,5]` 时写了 `nums[3,5]`——就算改成冒号 `nums[3:5]` 也只能得到 `[3,4]`，因为**结束不包含**。想要到 5，必须写 **6**。

📌 **口诀**：**冒号不是逗号，结束位置要多写 1**。

## E004 · 列表：循环变量和列表同名 🟡

来源：原列表笔记错题部分；历史发生日期未记载；状态：待独立复测。整理日期2026-09-17。

下次复习日期：待安排。复测日期与结果：待填写。

**你的错误**：

```python
scores = [88, 62, 95, 70, 100, 45]
for i, scores in enumerate(scores):    # ← 循环变量也叫 scores！
    print(i, scores)
print(scores)                          # 45 ← 列表没了，变成最后一个元素
```

**错在哪**：输出看着是对的，但循环每转一圈，`scores` 这个名字就被重新绑定成当前元素。循环结束后，`scores` 不再是列表，而是最后一个元素 `45`。后面再想用这个列表就完蛋了。

✅ 正确：**用单数命名循环变量**

```python
for i, score in enumerate(scores):     # 列表叫 scores，元素叫 score
    print(i, score)
```

📌 **习惯**：列表用复数（`scores`、`names`、`items`），循环变量用单数（`score`、`name`、`item`）。

## E005 · 列表：方法的参数写错 🟡

来源：原列表笔记错题部分；历史发生日期未记载；状态：待独立复测。整理日期2026-09-17。

下次复习日期：待安排。复测日期与结果：待填写。

**你的错误**：

```python
cart.insert("1,水果")     # ✗ 两个错
items.count()             # ✗ 缺参数
```

**错在哪**：

1. `insert` 需要**两个参数**：`insert(位置, 值)`，你只给了一个
2. `"1,水果"` 是**一个字符串**——逗号写在引号**里面**就变成普通文字了，起不到分隔参数的作用
3. `count()` **必须给一个值**告诉它数谁

✅ 正确：

```python
cart.insert(1, "水果")         # 逗号在引号【外面】才是分隔符
items.count("苹果")            # 告诉它数哪个
```

📌 **检查习惯**：写完方法调用，问自己两个问题——**"括号里要几个东西？"** **"逗号在引号外面吗？"**

```python
h = for i in range()    # ✗ SyntaxError
```

**错在哪**：推导式**最外层必须有 `[]`**，没有方括号 Python 不知道你想生成一个列表。

## E009 · 字符串清洗A4

> 来源：字符串与元组习题A4 · 清洗一行脏数据
> 日期：2026-09-03　　历史状态：已订正通过；独立复测状态：待填写

---

### 一、题目

```python
raw = "   Zhang San ,  18  \n"
```

把它清洗成 `"zhangsan|18"`。

**难点**：两端有空格和换行、逗号两边有空格、姓名中间有空格、还要转小写、最后要用 `|` 拼起来。

---

### 二、我的版本（最终通过）

```python
raw = "   Zhang San ,  18  \n"
s = raw.strip()
print(s)
s1 = s.split(',')
s11 = s1[0].strip()
s12 = s1[1].strip()
s2 = [s11, s12]
print(s2)
s31 = s2[0].replace(' ', '')
s32 = s2[1].replace(" ", "")
s311 = s31.lower()
s321 = s32.lower()
s3 = [s311, s321]
print(s3)
s4 = "|".join(s3)
print(s4)
```

**输出**

```
Zhang San ,  18
['Zhang San', '18']
['zhangsan', '18']
zhangsan|18
```

✅ 结果正确。优点：每一步都 `print` 出来检查，调试思路清晰。

---

### 三、易错点（我实际踩过的坑）

### 坑1 · 方法忘了写括号 🔴 犯了三次

```python
raw.strip        # ✗ 只是"指了指"这个方法，没有执行
raw.strip()      # ✓ 加括号才是"按下启动键"
```

验证：

```python
print(raw.strip)     # <built-in method strip of str object at 0x...>
print(raw.strip())   # 'Zhang San ,  18'
```

**比喻**：`raw.strip` 是"洗衣机"三个字，`raw.strip()` 才是按下启动键。

---

### 坑2 · 没有用 `=` 接住返回值 🔴

```python
raw.replace(' ', '')        # ✗ 加了括号也白搭，结果被扔了
raw = raw.replace(' ', '')  # ✓ 必须接住
```

**根源**：字符串**不可变**。所有字符串方法都是"重新印一张新字条"，老字条一个字都不会变。
👉 口诀：**字符串方法不原地修改字符串；要使用返回结果，可以赋值、打印或传给下一步。返回类型要分别判断。**

---

### 坑3 · 下标从 0 开始，不是 1 🔴 导致程序崩溃

```python
s1 = s.split(',')     # ['Zhang San ', '  18']   ← 只有 2 段
```

| 写法 | 结果 |
|------|------|
| `s1[0]` | `'Zhang San '` ← **姓名在这里** |
| `s1[1]` | `'  18'` ← **年龄在这里** |
| `s1[2]` | 💥 `IndexError: list index out of range` |

我第一版写的是 `s1[1]` 和 `s1[2]`，等于跳过姓名、又去够一个不存在的第三段，程序直接崩在这行。

👉 死记：**n 个元素，门牌号是 `0` 到 `n-1`。**

---

### 坑4 · 列表没有字符串方法 🔴

```python
s2 = [s11, s12]             # s2 是【列表】
s2.replace(' ', '')         # 💥 AttributeError: 'list' object has no attribute 'replace'
```

`replace` / `lower` / `strip` / `split` 全是**字符串**的方法，**列表用不了**。

**类型追踪表**（卡住时先问自己"手里这个是什么类型"）：

| 变量 | 怎么来的 | 类型 | 能用什么 |
|------|---------|------|---------|
| `raw` | 原始数据 | **str** | strip / split / replace / lower |
| `s` | `raw.strip()` | **str** | 同上 |
| `s1` | `s.split(',')` | **list** ⚠️ | 索引 / len / append，**没有 replace** |
| `s1[0]` | 列表取一个元素 | **str** | 又能用字符串方法了 |
| `s4` | `"|".join(...)` | **str** | ✓ |

**自查神器**：`print(type(x), repr(x))`
`repr` 会把空格和 `\n` 原样显示出来，一眼看出到底洗干净没有。

---

### 坑5 · 变量命名 ⚠️ 唯一没改掉的问题

```python
s11  s12  s2  s31  s32  s311  s321  s3  s4      # ✗ 三个月后自己都看不懂
name  age  parts  result                         # ✓ 一眼知道装的是什么
```

👉 口诀：**变量名要回答"里面装的是什么"，而不是"它是第几个变量"。**

---

### 四、简便版本

### 版本 B · 拆包 + 好名字（推荐现在就用）

```python
raw = "   Zhang San ,  18  \n"

name, age = raw.strip().split(",")     # ⭐ 拆包：split 出 2 段，左边就写 2 个变量
name = name.replace(" ", "").lower()
age = age.strip()
print("|".join([name, age]))           # zhangsan|18
```

**关键**：`name, age = ...` 是序列拆包（知识点 13），一步顶掉 `s1[0]`、`s1[1]` 两行，还顺手把变量名起好了。

---

### 版本 C · 推导式（练熟推导式后再用）

```python
raw = "   Zhang San ,  18  \n"

parts = [p.replace(" ", "").lower() for p in raw.strip().split(",")]
print("|".join(parts))                 # zhangsan|18
```

**好处**：不管拆出 2 段还是 20 段，代码一个字都不用改。

---

### 五、两条额外发现

**① `strip()` 那一步其实是多余的**

```python
"Zhang San ".replace(" ", "")   # 'ZhangSan'    没 strip 也一样
"  18".replace(" ", "")         # '18'
```

因为 `strip()` 默认删除两端空白字符，而 `replace(" ", "")` 是**删掉所有空格**，后者本来就包含前者的活。

⚠️ **但要看目标**：这题目标是 `zhangsan`（姓名连在一起）才能这么干。
如果目标是 `zhang san`（**保留中间空格**），就**必须用 `strip()`，绝不能用 `replace`** —— 会把中间那个空格也吃掉。

**② 开头的 `raw.strip()` 不能省**
它要干掉结尾的 `\n`，而 `\n` **不是空格**，`replace(" ", "")` 治不了它。

---

### 六、一句话总结

> **`.方法` 忘括号 → 没启动；启动了忘 `=` → 白干；`split` 完忘了下标从 0 数 → 直接崩。**
> 方法调用、返回值、下标范围是三类不同规则，要分别检查。
