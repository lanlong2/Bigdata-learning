## 第一次怎么打开、怎么填写

- VS Code：选择“文件 → 打开文件夹”，选中 `bigdata-learning` 整个文件夹。
- 阅读 `.md`：打开文件后按 **Ctrl+Shift+V** 看预览；在预览里单击蓝色链接跳转。
- 填写 `.md`：回到文字编辑界面填写空白；`[ ]` 表示未完成，真正完成后改成 `[x]`。填写后按 **Ctrl+S** 保存。
- 写 Python：在 `.py` 中作答。普通回答写在以 `#` 开头的注释后，代码写在空白代码区。
- 运行 Python：确认右下角选择 Python 3.12，再用编辑器右上角的“运行 Python 文件”按钮。只想运行一道题，可选中该题代码后使用“在 Python 终端中运行选定内容”；每题需包含自己的数据，不依赖其他题的变量。
- 文件读写习题和项目包含 `__file__`，请先保存，再运行整个文件；不要用选中片段的方式运行这类代码。只检查一题时，可先把其他题的代码注释掉。
- 空白答题模板运行后没有输出是正常的。不要把 Markdown 的三反引号复制到 Python 文件里。
- 需要输入时，在终端看到提示后再打字并回车；不要把命令写进 `.py` 文件。

## 文件之间的规则

**笔记、习题、试卷、答案分别放。** 笔记中的示例用来理解；习题先自己尝试后逐题核对；试卷完成整卷后再统一对答案和评分。

你不需要一次做完所有旧题。当前阶段只做近期计划指定的题和诊断发现的薄弱题。
