打开 `src/main.py` 后使用“运行 Python 文件”按钮。路径基于脚本位置计算，不要求切换到某个固定终端目录。
使用Python自带库即可。模板当前没有打印和文件写入，运行没有输出属正常情况。

输出由你的程序生成到项目内 `results` 文件夹；需要时在代码中创建它。
