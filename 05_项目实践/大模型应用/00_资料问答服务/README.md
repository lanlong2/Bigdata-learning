# 项目00｜资料问答服务

状态：任务材料已建立，尚未记录用户开始或完成。对应A05，预算45小时，包含实现、测试、排错、评测、部署与技术说明；已包含在大模型应用路线175小时内。

为一组自己有权使用的小型资料建立问答接口：导入资料、检索相关段落、生成带来源的回答；资料没有依据时说明无法回答。它是独立Python服务，不依赖将来的Java项目。

1. 阅读[任务书](任务书.md)，先确定资料、使用场景与边界。
2. 按A00—A04完成SQL、Python工程、HTTP与FastAPI、模型接口和RAG评测知识。
3. 先实现最短可运行流程，再补齐引用、拒答、异常、评测和复现步骤。

最终应能从一次提问讲清：请求怎样进入、资料怎样检索、模型获得什么输入、回答引用什么依据，以及失败时怎样定位原因。新建目录不等于已经完成上述活动；实现代码、实际评测结果和部署记录在学习过程中由用户形成，不预先填充。
