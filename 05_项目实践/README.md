# 项目实践 · 怎么用

这里存“把多个知识点合起来做一件事”的任务和代码。它与日常习题、阶段试卷分别管理。

下一项实践是[00 本地数据清洗小工具](00_本地数据清洗小工具/README.md)，main.py仍为TODO模板。2026-10-03综合卷首测55/100，循环、边界及多步数据流程需订正，E03/E04报告相关两问未答；先按[近期计划](../00_学习计划/近期执行计划.md)分段补练和独立复测，再完成模块、异常与文件前置练习后启动工具。旧函数卷订正证据保留，不计本工具已完成。
后续项目到相应阶段再建立文件夹，不提前铺开所有技术。

每个项目先读README，再读任务书；先确认输入、输出、验收条件，再开始写代码。代码和数据放在项目自己的目录里。
