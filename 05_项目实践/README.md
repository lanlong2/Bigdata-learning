# 项目实践 · 怎么用

这里存“把多个知识点合起来做一件事”的任务和代码。它与日常习题、阶段试卷分别管理。

下一项实践是[00 本地数据清洗小工具](00_本地数据清洗小工具/README.md)，截至2026-10-01仍为TODO模板。函数首测49/100，当前先按[近期计划](../00_学习计划/近期执行计划.md)补清洗、参数与订单函数流程；独立核心通过，再完成模块、异常与文件前置练习后启动工具。
后续项目到相应阶段再建立文件夹，不提前铺开所有技术。

每个项目先读README，再读任务书；先确认输入、输出、验收条件，再开始写代码。代码和数据放在项目自己的目录里。
