# 项目实践

2026-10-23更新：先完成Python大模型应用路线，再学习Java后端路线；Java是主要就业方向。两个方向的主成果分别能够独立运行。项目质量优先，不用项目数量代替能力。

| 方向 | 入口 | 当前用途 |
|---|---|---|
| 大模型应用 | [资料问答服务](大模型应用/00_资料问答服务/README.md) | A05，45小时；形成小而完整的Python大模型应用实习成果 |
| Java后端 | [工单管理后端](Java/00_工单管理后端/README.md) | J06，100小时；深入业务、权限、事务、测试、排障和部署 |
| SQL | [SQL专项实践](SQL/README.md) | 订单查询报告改为可选专项练习，也可用于理解主项目中的数据统计 |
| Python基础历史 | [原项目与记录](Python/README.md) | 保留原代码、数据、输出、任务书与历史评析，不重新设为主线前置 |

主项目分别有明确的输入、业务规则、输出和验收场景。优秀的标准是功能和边界可靠、结果有依据、能复现、能解释设计并修改需求；扩展功能仅在核心完成后选择。

700小时总学习预算中，大模型应用175小时、Java后端450小时均已包含日常练习、排错和各自项目；额外75小时用于技术补弱和项目返修，不能重复计算。现有项目任务书是学习材料，创建材料不代表用户已开始或完成项目。

SQL继续使用MySQL 8.4 LTS与DBeaver，课程数据入口为[重建练习库](../01_学习笔记/SQL/练习数据/00_重建练习库.sql)。主项目使用各自独立数据库，数据库名在任务书中约定，不在课程库混建业务表。
