# 第一部分：知识点详解

# 【上篇】字符串 str

## 1. 字符串是什么

字符串就是**一串字符**（文字、数字、符号都算），用引号包起来。

形象理解：字符串像一张**过了塑封的字条**——你能看、能数、能复印，**但不能在上面涂改**。想改？只能重新打印一张新的。

```python
a = "hello"           # 双引号
b = 'hello'           # 单引号，完全等价
c = """第一行
第二行"""              # 三引号：可以跨行，也常用来写长注释
d = ""                # 空字符串，长度是 0
e = "123"             # ⚠️ 这是字符串，不是数字！"123" + 1 会报错
```

**为什么有单双引号两种？** 为了方便嵌套：

```python
s1 = "他说：'你好'"      # 里面有单引号，外面就用双引号
s2 = '他说："你好"'      # 反过来也行
s3 = "他说：\"你好\""    # 或者用反斜杠转义
```

**常用转义字符**（反斜杠 `\` 开头，表示"这个字符有特殊含义"）：

| 写法 | 含义 | 例子 |
|------|------|------|
| `\n` | 换行 | `print("A\nB")` 打印成两行 |
| `\t` | 制表符（对齐用） | `print("姓名\t分数")` |
| `\` | 一个真正的反斜杠 | `"C:\Users"` |
| `\"` `\'` | 引号本身 | `"他说\"好\""` |

```python
path = "C:\Users\new"       # ⚠️ 坑：\n 被当成换行了！
path = r"C:\Users\new"      # ✓ 前面加 r（raw 原始字符串），反斜杠全当普通字符
```

## 2. 索引与切片：给每个字符发门牌号

字符串是**有序**的，每个字符都有编号，**从 0 开始数**。

```python
s = "Python"
#  正索引:  0 1 2 3 4 5
#  负索引: -6-5-4-3-2-1     负数从右往左数

s[0]        # "P"      第一个字符
s[-1]       # "n"      最后一个字符
s[1:4]      # "yth"    切片：从1取到4，【含头不含尾】
s[:3]       # "Pyt"    从头开始
s[3:]       # "hon"    一直到结尾
s[::2]      # "Pto"    步长2，隔一个取一个
s[::-1]     # "nohtyP" 步长-1 →【反转字符串的经典写法】
len(s)      # 6        总长度
```

形象理解：切片就像用**剪刀在两个字符之间下剪**，剪口编号写在字符**左边**，所以 `s[1:4]` 剪下来的是 1、2、3 号位，**4 号位不要**。

⚠️ `s[0]` 拿到的还是**字符串**——Python 里没有"单个字符"这种类型，`"P"` 就是一个长度为 1 的字符串。

⚠️ 索引越界会报错，但**切片越界不会**：

```python
s[6]        # ✗ IndexError: string index out of range
s[0:100]    # ✓ "Python"   切片越界自动止步，很安全
```

## 3. 不可变性 🔴 字符串最重要的一条

```python
s = "hello"
s[0] = "H"       # ✗ TypeError: 'str' object does not support item assignment
```

**塑封字条模型**：字条塑封了，涂改不了。所有"修改字符串"的方法，本质都是**重新印一张新字条给你**，老字条一个字都没变。

```python
s = "hello"
s.upper()          # 返回了 "HELLO"
print(s)           # 还是 "hello"！  ← 90% 的新手在这里翻车

s = s.upper()      # ✓ 想让改动生效，必须【接住返回值，重新赋值】
print(s)           # "HELLO"
```

> 🔑 口诀：**字符串的方法全是"返回新的"，所以后面几乎永远要跟一个 `=` 去接住。**

## 4. 常用方法大全（全部"返回新串，不动原串"）

**清洗与变形**

```python
s = "  Hello World  "

s.strip()               # "Hello World"   去掉【两端】空白（最常用！）
s.lstrip()              # "Hello World  " 只去左边
s.rstrip()              # "  Hello World" 只去右边
"xxhixx".strip("x")     # "hi"            也可以指定去掉哪些字符

s.upper()               # 全大写
s.lower()               # 全小写（做"忽略大小写的比较"时必用）
"hello world".title()   # "Hello World"   每个单词首字母大写
"hello".capitalize()    # "Hello"         只有第一个字母大写

"a-b-c".replace("-", "+")     # "a+b+c"   替换（默认全部替换）
"aaa".replace("a", "b", 2)    # "bba"     第三个参数 = 最多替换几次
```

**拆与合** ⭐（字符串和列表之间的两扇门）

```python
# split：字符串 →【列表】
"a,b,c".split(",")        # ["a", "b", "c"]
"a b  c".split()          # ["a", "b", "c"]  不给参数 = 按任意空白拆，自动忽略连续空格
"a-b-c".split("-", 1)     # ["a", "b-c"]     第二个参数 = 最多拆几次
"a,b,,c".split(",")       # ["a", "b", "", "c"]  ⚠️ 连续分隔符会拆出空串

# join：列表 →【字符串】
"-".join(["a", "b", "c"])   # "a-b-c"
"".join(["a", "b", "c"])    # "abc"
"、".join(["张三", "李四"])  # "张三、李四"
```

⚠️ `join` 的写法反直觉：**分隔符写在最前面**，而且列表里必须**全是字符串**：

```python
"-".join([1, 2, 3])                    # ✗ TypeError
"-".join([str(x) for x in [1, 2, 3]])  # ✓ "1-2-3"
```

**查找与判断**

```python
s = "hello world"

"world" in s          # True    判断包不包含（最简单，优先用）
s.find("world")       # 6       返回位置，【找不到返回 -1，不报错】
s.find("xyz")         # -1
s.index("world")      # 6       返回位置，【找不到直接 ValueError】
s.count("l")          # 3       出现几次
s.startswith("hello") # True    以什么开头
s.endswith(".txt")    # False   以什么结尾（判断文件类型常用）

"314".isdigit()       # True    纯数字吗
"3.14".isdigit()      # False   ⚠️ 小数点不算数字！
"abc".isalpha()       # True    纯字母吗
"a1".isalnum()        # True    字母或数字
```

## 5. 拼接与重复

```python
"abc" + "def"        # "abcdef"    加号 = 拼接
"ab" * 3             # "ababab"    乘号 = 重复
"-" * 30             # "------..." 画分割线的经典写法

"年龄" + 18          # ✗ TypeError: 只能字符串拼字符串
"年龄" + str(18)     # ✓ "年龄18"
```

⚠️ 循环里用 `+=` 拼接大量字符串会很慢（每次都在印一张新字条）。正确姿势：**先把碎片装进列表，最后 `join` 一次**。

```python
parts = []
for w in ["a", "b", "c"]:
    parts.append(w)          # 列表可变，加起来很快
result = "".join(parts)      # 最后一次性合成
```

## 6. f-string 格式化 ⭐（日常用得最多）

```python
name = "lanlong"
score = 86.3456

f"{name}的分数是{score}"      # 直接把变量塞进大括号
f"{score:.2f}"                # 86.35        保留2位小数
f"{score:.0f}"                # 86           不要小数
f"{1234567:,}"                # 1,234,567    千位分隔符
f"{0.256:.1%}"                # 25.6%        转百分比
f"|{name:<10}|"               # |lanlong   | 左对齐占10格
f"|{name:>10}|"               # |   lanlong| 右对齐
f"|{name:^10}|"               # | lanlong  | 居中
f"{name!r}"                   # 'lanlong'    带引号显示
f"{len(name)=}"               # len(name)=7  调试神器：变量名和值一起打印
f"{2 + 3}"                    # 5            大括号里可放任意表达式
```

对齐在做**表格输出**时特别香：

```python
for name, score in [("张三", 88), ("李四", 95)]:
    print(f"{name:<8}{score:>5}")
```

```python
str(123)               # "123"                   任何东西 → 字符串
```

# 【下篇】元组 tuple

## 9. 元组是什么

元组是**用小括号 `()` 包起来的、装好就不能再改的一组数据**。

形象理解：普通收纳箱（列表）随便加随便删；元组是**焊死的收纳箱**——东西一旦装好，箱子就焊上了，只能看不能动。

```python
point = (3, 4)                   # 一个坐标
rgb = (255, 128, 0)              # 一个颜色
person = ("张三", 18, "男")       # 一条记录
empty = ()                       # 空元组
```

**元组的两个关键特性**：

| 特性 | 含义 |
|------|------|
| **有序** | 元素有固定先后顺序，每个位置有编号（和字符串、列表一样） |
| **不可变** | 创建之后**不能增、不能删、不能改** |

---

## 10. 创建元组的三个坑 ⚠️

**坑1：单元素元组必须带逗号**

```python
x = (7)        # ⚠️ 这是【整数 7】，括号被当成数学括号了
y = (7,)       # ✓ 这才是元组，逗号才是元组的灵魂
type(x)        # <class 'int'>
type(y)        # <class 'tuple'>
len(y)         # 1
```

> 🔑 **是逗号造就了元组，不是括号。**

**坑2：括号可以省略**

```python
t = 1, 2, 3           # ✓ 这就是元组 (1, 2, 3)
a, b = 1, 2           # 这一行的本质就是元组拆包
def f():
    return 1, 2       # 函数"返回多个值"，其实是返回了一个元组
```

**坑3：元组不可变，但里面装的可变对象还能变**（很爱考）

```python
t = (1, 2, [3, 4])
t[0] = 99          # ✗ TypeError: 'tuple' object does not support item assignment
t[2].append(5)     # ✓ 居然成功！t 变成 (1, 2, [3, 4, 5])
```

**为什么？** 焊死的是**格子**——每个格子里放的东西不能被换成别的东西。但如果某个格子里放的是一个**袋子（列表）**，你换不掉这个袋子，却可以往袋子里塞东西。

---

## 11. 元组的读操作：会读列表就会读元组

```python
t = (10, 20, 30, 40, 50)

t[0]           # 10
t[-1]          # 50
t[1:3]         # (20, 30)     切片结果还是【元组】
len(t)         # 5
20 in t        # True
t + (60,)      # (10,20,30,40,50,60)  拼接会生成【新元组】，原来的没变
(0,) * 3       # (0, 0, 0)            重复

for x in t:            # 遍历，和列表写法完全相同
    print(x)
```

## 12. 元组的方法：只有两个！

```python
t = (1, 2, 2, 3)
t.count(2)      # 2    某个值出现几次
t.index(2)      # 1    第一次出现的位置
```

凡是"修改"类的操作，元组一律没有：

```python
t.append(4)     # ✗ AttributeError: 'tuple' object has no attribute 'append'
t.sort()        # ✗ 同样没有
sorted(t)       # ✓ sorted() 可以用！它不改原件，返回一个【新列表】
```

## 13. 拆包（unpacking）⭐ 元组最香的用法

把元组里的值**一次性拆给多个变量**：

```python
point = (3, 4)
x, y = point            # x=3, y=4   ← 变量个数必须和元素个数【严格相等】，多一个少一个都报错

a, b = 1, 2
a, b = b, a             # ⭐ 交换两个变量，不需要临时变量
```

**星号拆包**（吃掉剩下的，剩下的会装进**列表**）：

```python
first, *rest = (10, 20, 30, 40)
print(first, rest)      # 10 [20, 30, 40]

*head, last = (10, 20, 30)
print(head, last)       # [10, 20] 30
```

**函数返回多个值 = 返回一个元组**：

```python
def min_max(nums):
    return min(nums), max(nums)     # 返回的是元组 (2, 9)

lo, hi = min_max([4, 9, 2])         # 直接拆包接住
print(lo, hi)                       # 2 9
```

**其实你早就在用元组了**：

```python
for i, name in enumerate(["张三", "李四"]):
    ...      # enumerate 每轮吐出的 (0, "张三") 就是元组，i, name 就是在拆包

for k, v in {"x": 1, "y": 2}.items():
    ...      # items() 吐出的也是元组
```

## 14. 为什么要用元组？（新手最大的疑问）

| 理由 | 说明 |
|------|------|
| **安全** | 表示"绝不该被改"的数据（配置、坐标、一条已确定的记录）。谁写错代码想改它，Python 立刻报错，而不是悄悄改坏 |
| **能当字典的 key** | 列表不行：`{[0,0]: "原点"}` 直接报 `unhashable type: 'list'`；`{(0,0): "原点"}` 完全没问题 |
| **能放进集合去重** | `{(1,2), (1,2), (3,4)}` → `{(1,2), (3,4)}` |
| **更省内存、创建更快** | 同样 5 个元素：列表 104 字节、元组 80 字节；创建速度快约 3 倍（数据见第六部分，可自己跑） |
| **表达"结构"而不是"集合"** | 列表装"同类的很多个"，元组装"一件事的几个字段" |

> 💡 判断标准：`[88, 92, 79]` 用列表（都是分数，同类并列）；`("张三", 18, "男")` 用元组（姓名/年龄/性别，各是各的字段）。

## 15. 速查表

**字符串**

| 操作 | 写法 | 结果类型 | 改原件吗 |
|------|------|---------|---------|
| 取字符 | `s[0]` | str | — |
| 切片 / 反转 | `s[1:4]` `s[::-1]` | str | — |
| 长度 | `len(s)` | int | — |
| 去空白 | `s.strip()` | str | ✗ 返回新的 |
| 大小写 | `s.upper()` `s.lower()` | str | ✗ |
| 替换 | `s.replace(旧, 新)` | str | ✗ |
| 拆开 | `s.split(分隔符)` | **list** | ✗ |
| 合并 | `分隔符.join(列表)` | str | ✗ |
| 查位置 | `s.find(子串)` / `s.index(子串)` | int | — |
| 数次数 | `s.count(子串)` | int | — |
| 判断 | `子串 in s` / `s.startswith(x)` | bool | — |
| 格式化 | `f"{变量:.2f}"` | str | — |

**元组**

| 操作 | 能不能 | 备注 |
|------|-------|------|
| `t[0]` 读 | ✓ | 和列表一样 |
| `t[0] = x` 写 | ✗ | TypeError |
| 切片 | ✓ | 结果还是元组 |
| `count` / `index` | ✓ | **只有这两个方法** |
| `append/remove/sort` | ✗ | AttributeError |
| `sorted(t)` | ✓ | 返回的是**列表** |
| 拆包 `a, b = t` | ✓ | 元组的招牌用法 |
| 当字典 key / 进集合 | ✓ | 列表做不到 |
| `list(t)` / `tuple(l)` | ✓ | 两种容器随意互转 |

## 大题一 · 详解

```python
raw = "张三,88,92,79;李四,95,60,73;王五,45,100,68"

# 1) 按分号拆学生
parts = raw.split(";")
print(parts)
# ['张三,88,92,79', '李四,95,60,73', '王五,45,100,68']

# 2) 每条再按逗号拆字段 → 装成元组
records = []
for item in parts:
    fields = item.split(",")          # ['张三', '88', '92', '79']
    name = fields[0]                  # 第0个是姓名
    scores = [int(x) for x in fields[1:]]   # 切片拿后面全部，推导式逐个转 int
    records.append((name, sum(scores), sum(scores) / len(scores)))
print(records)
# [('张三', 259, 86.33333333333333), ('李四', 228, 76.0), ('王五', 213, 71.0)]

# 3) 按平均分（元组的第2号位）从高到低排
ranked = sorted(records, key=lambda r: r[2], reverse=True)

# 4) 排行榜
for i, (name, total, avg) in enumerate(ranked, 1):   # enumerate 从1开始编号，同时拆包元组
    print(f"第{i}名 {name:<6}总分{total} 平均{avg:.1f}")
# 第1名 张三    总分259 平均86.3
# 第2名 李四    总分228 平均76.0
# 第3名 王五    总分213 平均71.0

# 5) 不及格科目
for item in parts:
    fields = item.split(",")
    fails = [int(x) for x in fields[1:] if int(x) < 60]
    if fails:
        print(f"{fields[0]} 有 {len(fails)} 科不及格：{fails}")
# 王五 有 1 科不及格：[45]

# 6) 姓名连接
print("、".join([r[0] for r in records]))    # 张三、李四、王五
```

**关键点拆解**

| 步骤 | 用到的知识 | 易错点 |
|------|-----------|-------|
| 1 | `split(";")` | 拆出来是**列表**，不是元组 |
| 2 | 切片 `fields[1:]` + `int()` + 推导式 | `"88"` 是字符串，不转 `int` 就没法求和 |
| 3 | `sorted(key=..., reverse=True)` | `key` 里的 `r[2]` 表示"按元组第3个元素排" |
| 4 | `enumerate(ranked, 1)` + 拆包 + f-string 对齐 | `enumerate` 第二个参数是**起始编号** |
| 6 | `join` 只吃字符串 | 如果拼分数必须先 `str()` |

**第7问（思考题）答案**：
`(姓名, 总分, 平均分)` 是**一条记录的三个不同字段**，字段个数固定、含义固定、一旦算出来就不该被改 → 用**元组**，还能顺手拆包 `name, total, avg = r`。
而 `[88, 92, 79]` 是**同类的多个分数**，数量可能变（加一门课就 append 一个）→ 用**列表**。
`records` 本身是"很多条同类记录"，所以外层用列表、内层用元组，这是数据处理里最常见的组合：**列表装行，元组装字段**。

## 大题二 · 详解

```python
text = "  Python is fun. python is powerful; PYTHON is everywhere!  "

# 1) 长度对比
print(len(text), len(text.strip()))       # 60 56
# 差 4 个字符 = 开头2个空格 + 结尾2个空格，strip() 只去两端、不动中间

# 2) 清洗：去空白 → 转小写 → 去标点
clean = text.strip().lower()
for ch in ".;!":
    clean = clean.replace(ch, "")         # ⚠️ 必须重新赋值给 clean，字符串不可变
print(clean)
# python is fun python is powerful python is everywhere

# 3) 拆成单词
words = clean.split()                     # 不给参数 = 按任意空白拆
print(words, len(words))
# ['python','is','fun','python','is','powerful','python','is','everywhere'] 9

# 4) 去重 + 排序
uniq = sorted(set(words))
# ['everywhere', 'fun', 'is', 'powerful', 'python']

# 5) (单词, 次数) 元组列表
pairs = [(w, words.count(w)) for w in uniq]
# [('everywhere',1), ('fun',1), ('is',3), ('powerful',1), ('python',3)]

# 6) 按次数降序
ranked = sorted(pairs, key=lambda p: p[1], reverse=True)
print(ranked[0])                          # ('is', 3)
# ranked = [('is',3), ('python',3), ('everywhere',1), ('fun',1), ('powerful',1)]

# 7) 词频表
for w, c in ranked:
    print(f"{w:<12}{c}")
# is          3
# python      3
# everywhere  1
# fun         1
# powerful    1

# 8) 出现>=2次
print("|".join([w for w, c in ranked if c >= 2]))    # is|python

# 9) 其它查询
s = text.strip()
print(s.count("is"), s.find("fun"), s.startswith("Python"))   # 3 10 True
```

**关键点拆解**

- **为什么先 `lower()`？** 因为 `"Python"`、`"python"`、`"PYTHON"` 在计算机眼里是三个**不同**的字符串。统计词频前统一大小写，是文本处理的第一原则。
- **为什么要去标点？** 不去的话 `"fun."` 和 `"fun"` 会被算成两个词。
- **`clean = clean.replace(...)` 里的赋值不能省**——省了等于白做（字符串不可变，见知识点 3）。
- **`set` 去重会打乱顺序**，所以外面套了 `sorted()` 让结果稳定可复现。
- **稳定排序**：`is` 和 `python` 都是 3 次，谁在前？`sorted` 是**稳定**的，会保留它们在 `pairs` 里的原顺序（`is` 字母序在前），所以 `is` 排前面。
- `words.count(w)` 是**列表**的方法，`s.count("is")` 是**字符串**的方法，名字一样、对象不同——这正是"字符串就是一串字符组成的序列"的体现。

## 大题三 · 详解

```python
points = [(1, 2), (4, 0), (-3, 5), (0, 0), (2, -7)]

# 1) 遍历 + 拆包（for 后面直接写 (x, y) 就能拆开元组）
for i, (x, y) in enumerate(points):
    print(f"P{i}: x={x}, y={y}, 距离平方={x**2 + y**2}")
# P0: x=1, y=2, 距离平方=5
# P1: x=4, y=0, 距离平方=16
# P2: x=-3, y=5, 距离平方=34
# P3: x=0, y=0, 距离平方=0
# P4: x=2, y=-7, 距离平方=53

# 2) 最远的点
far = max(points, key=lambda p: p[0]**2 + p[1]**2)
print(far)                       # (2, -7)

# 3) 按 y 排序
by_y = sorted(points, key=lambda p: p[1])
print(by_y)                      # [(2,-7), (4,0), (0,0), (1,2), (-3,5)]
#  ⚠️ (4,0) 和 (0,0) 的 y 都是 0，稳定排序保持它们的原顺序

# 4) x、y 互换
swapped = [(y, x) for x, y in points]
print(swapped)                   # [(2,1), (0,4), (5,-3), (0,0), (-7,2)]

# 5) 第一象限
q1 = [p for p in points if p[0] > 0 and p[1] > 0]
print(q1)                        # [(1, 2)]

# 6) 拆成两列再合回去
xs = [x for x, y in points]      # [1, 4, -3, 0, 2]
ys = [y for x, y in points]      # [2, 0, 5, 0, -7]
print(list(zip(xs, ys)) == points)      # True
#  zip 本身是个"懒惰"对象，必须 list() 一下才能看/比较

# 7) 星号拆包 + zip
xs2, ys2 = zip(*points)
print(xs2, type(xs2))            # (1, 4, -3, 0, 2) <class 'tuple'>
#  区别：第6步用推导式得到的是【列表】，zip(*points) 得到的是【元组】

# 8) 配标签
labels = ["P" + str(i) for i in range(len(points))]
print(list(zip(labels, points)))
# [('P0',(1,2)), ('P1',(4,0)), ('P2',(-3,5)), ('P3',(0,0)), ('P4',(2,-7))]

# 9) 连成字符串
print(", ".join([f"({x},{y})" for x, y in points]))
# (1,2), (4,0), (-3,5), (0,0), (2,-7)

# 10) 想改元组里的值
points[0][0] = 99
# ✗ TypeError: 'tuple' object does not support item assignment

# ✓ 正确做法：元组转列表 → 改 → 转回元组 → 放回列表（列表是可变的，所以这一步能成）
tmp = list(points[2])            # [-3, 5]
tmp[0] = 30
points[2] = tuple(tmp)           # (30, 5)
print(points[2])                 # (30, 5)
```

**关键点拆解**

- `zip(*points)` 里的 `*` 是"把列表里的每个元组**摊开**当成独立参数"，等价于 `zip((1,2), (4,0), (-3,5), (0,0), (2,-7))`，效果是**行列互换**（转置）。这是元组列表里最漂亮的一招。
- 第 10 步揭示了一个重要事实：**`points` 是列表（可变），里面的点是元组（不可变）**。所以"换掉整个点"可以，"改点里的一个数"不行。
- 这种设计其实很有道理：一个坐标点是一个**整体**，它要么被整个替换，要么保持不动——不该出现"x 改了一半"的中间状态。

## 大题四 · 详解（全部实际运行验证）

| 行 | 输出 / 结果 | 原因 |
|----|------------|------|
| `print(1, s, a)` | `1 hello HELLO` | `upper()` 返回新串，`s` 纹丝不动 |
| `print(2, s, s2)` | `2 hello heLLo` | `replace` 同理，只有 `s2` 拿到了新串 |
| `print(3, t)` | `3 (1, 2, [3, 4, 5])` | 改的是**元组里那个列表的内部**，元组的格子没换 |
| `t[0] = 99` | ✗ **TypeError**: `'tuple' object does not support item assignment` | 想换掉格子里的东西 → 元组不允许 |
| `print(5, lst, lst2)` | `5 [10,20,30,40] [10,20,30,40]` | `lst2 = lst` 只是**贴了第二张标签**，两个名字指同一个列表 |
| `print(6, tup, lst)` | `6 (10,20,30,40) [10,20,30,40,50]` | `tuple(lst)` 是**照相**，照完再改列表和照片无关 |
| `print(7, type(x), type(y), len(y))` | `7 <class 'int'> <class 'tuple'> 1` | `(7)` 是整数，`(7,)` 才是元组 |
| `print(8, words, joined, len(joined))` | `8 ['a','b','c'] abc 3` | split 得列表、join 得字符串，长度是字符数 |
| `print(9, nums, snap)` | `9 [1, 2, 3] (3, 1, 2)` | `sort()` 就地改列表，`snap` 是排序前的快照，保持原样 |
| `print(11, ...)` | `11 ell olleh o 5` | 切片、反转、末位、长度 |
| `print(12, ...)` | `12 (1, 2, [3, 4, 5], 6) (0, 0, 0)` | 元组 `+` 生成新元组；`*` 是重复 |
| `t.append(9)` | ✗ **AttributeError**: `'tuple' object has no attribute 'append'` | 元组根本没有这个方法 |
| `print(14, t.count(1), t.index(2))` | `14 1 1` | `1` 出现 1 次；`2` 在索引 1 的位置 |

**三个额外问题**

**① 第3行能改、第4行报错？**
`t[2].append(5)` 动的是"格子里那个**袋子的内容**"，`t` 的三个格子分别指向谁**没变**；
`t[0] = 99` 是"把 0 号格子指向的东西**换成别的**"，这才是元组禁止的操作。
一句话：**元组冻结的是"指向关系"，不是"被指向的对象内部"。**

**② 谁是真复制？**
`tup = tuple(lst)` 是真复制（新建了一个对象）；`lst2 = lst` **不是**复制，只是给同一个列表起了第二个名字（`lst is lst2` 为 `True`），改哪个都等于改同一个东西。

**③ `snap` 为什么没变？**
`tuple(nums)` 在那一刻把内容抄成了一个**新的、且永远不会被改**的元组。后面 `nums.sort()` 改的是列表，和这份抄件无关。
所以元组特别适合做 **"快照 / 备份 / 存档"**：你需要一份"绝对不会被后续代码悄悄改掉"的数据时，就把它 `tuple()` 一下——这是元组在真实项目里最实用的价值之一。

# 第六部分：字符串 vs 元组 —— 越比越有意思 🔍

## 1. 惊人的相似：它们其实是**同一类东西**

Python 把"有顺序、能索引、不能改"的容器统称为**不可变序列**。字符串和元组都是它的成员，所以下面这些操作**两边写法一模一样**：

| 能力 | 字符串 | 元组 |
|------|--------|------|
| 索引 | `"abc"[0]` → `"a"` | `(1,2,3)[0]` → `1` |
| 切片 | `"abc"[1:]` → `"bc"` | `(1,2,3)[1:]` → `(2,3)` |
| 反转 | `"abc"[::-1]` → `"cba"` | `(1,2,3)[::-1]` → `(3,2,1)` |
| 长度 | `len("abc")` → 3 | `len((1,2,3))` → 3 |
| 拼接 | `"ab" + "cd"` | `(1,2) + (3,)` |
| 重复 | `"x" * 3` → `"xxx"` | `("x",) * 3` → `('x','x','x')` |
| 遍历 | `for ch in s` | `for x in t` |
| 数次数 | `"aab".count("a")` → 2 | `(1,1,2).count(1)` → 2 |
| 查位置 | `"abc".index("c")` → 2 | `(1,2,3).index(3)` → 2 |
| 比大小 | `"abc" < "abd"` → True | `(1,2) < (1,3)` → True |
| 改元素 | ✗ TypeError | ✗ TypeError |
| 当字典 key | ✓ | ✓ |

> 🔑 **学会一个就等于学会两个**——这是它们最值得新手高兴的一点。
> 而列表虽然索引切片写法也一样，但它**能改**，所以是另一个阵营。

---

## 2. 关键的不同

| 维度 | 字符串 str | 元组 tuple |
|------|-----------|-----------|
| 装什么 | **只能装字符**，元素类型天然统一 | **什么都能装**，还能混装、能嵌套元组 |
| 元素是什么 | 元素还是字符串（`"a"[0][0][0]` 可以无限套下去😄） | 元素可以是数字、字符串、列表、元组…… |
| 方法数量 | 40 多个（`upper/strip/split/replace`…） | **只有 2 个**（`count`、`index`） |
| `in` 的含义 | **子串**匹配：`"ell" in "hello"` → True | **成员**匹配：`(1,2) in (1,2,3)` → **False** |
| 典型用途 | 文本、名字、一行数据 | 一条记录、一个坐标、函数的多返回值 |
| 拆包 | 也能拆（`a,b,c = "abc"`）但很少用 | 招牌用法 |
| 和列表互转 | `list("ab")`、`"".join(lst)` | `list(t)`、`tuple(l)` |

⚠️ 上表里最容易被坑的一行是 **`in`**：

```python
"hlo" in "hello"       # False   字符串要求【连续的子串】
"ell" in "hello"       # True
(1, 2) in (1, 2, 3)    # False   ⚠️ 元组的 in 是"有没有这个元素"，不是"有没有这一段"
(1, 2) in ((1,2), (3,4))   # True    因为 (1,2) 确实是其中一个【元素】
```

---

## 3. 五个动手小实验（都能直接跑，结果已实测）

### 实验1 · 谁更省内存、谁更快
```python
import sys, timeit
print(sys.getsizeof("hello"))          # 46
print(sys.getsizeof((1,2,3,4,5)))      # 80
print(sys.getsizeof([1,2,3,4,5]))      # 104   ← 列表最胖
print(timeit.timeit("[1,2,3,4,5]", number=1000000))   # ≈0.046 秒
print(timeit.timeit("(1,2,3,4,5)", number=1000000))   # ≈0.013 秒  快约 3 倍
```
**为什么？** 列表要为"以后可能变长"预留空间、还要维护可变性；元组一次成型，不用留后路。

### 实验2 · `==` 和 `is` 不是一回事
```python
a = "hello"
b = "hel" + "lo"     # 编译时就能算出来 → Python 直接复用同一个对象
c = "hel"
d = c + "lo"         # 运行时才拼出来 → 是另一个对象
print(a == b, a is b)    # True True
print(a == d, a is d)    # True False   ← 内容相同，但不是同一个对象
```
**结论**：比较内容永远用 `==`；`is` 是问"是不是同一个东西"。不可变对象常被 Python 偷偷复用（这叫**驻留/interning**），正因为它们不会变，复用才安全——**这就是不可变带来的性能红利**。

### 实验3 · 谁能当字典的钥匙
```python
d = {(0, 0): "原点", "name": "lanlong"}   # ✓ 元组和字符串都能当 key
d2 = {[0, 0]: "原点"}                      # ✗ TypeError: unhashable type: 'list'
print(hash((1, 2)) == hash((1, 2)))        # True
hash((1, 2, [3]))                          # ✗ TypeError: unhashable type: 'list'
```
**为什么？** 钥匙必须"形状永远不变"才配得上锁孔。列表随时会变，所以不能当 key；元组能——但如果元组里**藏了一个列表**，它也立刻失去资格。这一条最能说明"不可变"到底值钱在哪。

### 实验4 · 元组比大小 = 字典序
```python
print((1, 2) < (1, 3))         # True   先比第0位，相同再比第1位
print((1, 2, 0) < (1, 3))      # True   第1位分出胜负就不看后面了
print(sorted([(2,"b"), (1,"c"), (1,"a")]))
# [(1, 'a'), (1, 'c'), (2, 'b')]   ← 先按数字，数字相同再按字母
```
**用处**：想"先按 A 排、A 相同再按 B 排"，直接 `key=lambda x: (x[0], x[1])` 返回一个元组就行——**元组是多级排序的天然工具**。

### 实验5 · 字符串是"元素全是字符的元组"
```python
print(tuple("hi"))              # ('h', 'i')
print("".join(("h", "i")))      # "hi"
print(max("hello"), min("hello"))   # o e     按字母序比大小
print("a"[0][0][0])             # a       字符的元素还是字符，可以无限取下去
```

## 4. 三选一：到底该用哪个？

```
要存的是文字？ ──────────────────→ 用【字符串】

要存的是"一堆同类的东西"，
并且以后要增删改？ ─────────────→ 用【列表】

要存的是"一件事的几个固定字段"，
或者要当字典 key / 要做快照？ ──→ 用【元组】
```

| 场景 | 选择 | 理由 |
|------|------|------|
| 一行 CSV 文本 | 字符串 | 本来就是文本 |
| 一个班的所有分数 | 列表 | 同类、数量会变 |
| 一个学生 `("张三", 18, "男")` | 元组 | 字段固定、不该乱改 |
| 一个坐标 `(x, y)` | 元组 | 整体替换，不改一半 |
| 函数返回两个值 | 元组 | 自动拆包 |
| 排序前的备份 | 元组 | 永不被后续代码改坏 |
| 字典的复合 key | 元组 | 列表当不了 key |

> 三者的索引切片语法完全一致，真正的分水岭只有一条：**能不能改。**
