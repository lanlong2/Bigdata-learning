## K01

两行输出分别为 `9 6` 和 `42 6`。b在赋值时已经算出6，后来a改变不会自动重算b。字符串加号连接文字，整数加号做数值相加。

```python
a = 4
b = a + 2
a = 9
b = b + 3
print(b)  # 9
```

## K02

```python
raw = input("购买几本：")
quantity = int(raw)
total = quantity * 3
print(f"合计：{total}元")
```

输入7打印合计21元，输入0打印合计0元。input返回字符串，`"7" * 3` 是重复文字得到 `"777"`，因此先转成整数再计算。

## K03

```python
score = 79
if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("待加强")
```

打印及格。if/elif/else选中第一个成立的分支后跳过其他分支，保证每个分数只进入一档。三个独立if则可能同时成立。题目给的是整数范围；使用下限从高到低判断，没有漏掉79和89。

## K04

```python
for value in range(1, 6):
    if value % 2 == 0:
        continue
    print(value)
```

依次打印1、3、5。range的结束值6不包含。

```python
values = [2, 0, 5, -1, 9]
for value in values:
    if value == 0:
        continue
    if value < 0:
        break
    print(value)
```

依次打印2、5。continue回到for的下一轮，break结束这层循环；values为空时没有轮次。

## K05

```python
commands = ["4", "0", "-1", "6", "stop", "100"]
initial_stock = 1
box_size = 3
total = initial_stock
i = 0
while i < len(commands):
    command = commands[i]
    i += 1
    if command == "stop":
        break
    quantity = int(command)
    if quantity <= 0:
        continue
    total += quantity
print(f"总库存：{total}件")
print(f"整箱：{total // box_size}箱")
print(f"剩余：{total % box_size}件")
```

库存是 `1 + 4 + 6 = 11`，stop后100未读。读取后先推进下标，0和负数也不会让循环停留在同一条记录上。空输入和首条stop都保留初始库存1；无stop时由下标达到列表长度结束。

## K06

```python
scores = [0, 60, 90]
total = 0
count = 0
passed = []
for score in scores:
    total += score
    if score >= 60:
        count += 1
        passed.append(score)
print(f"总分：{total}")
print(f"及格人数：{count}")
print(f"及格分数：{passed}")
if scores:
    print(f"平均分：{total / len(scores):.1f}")
else:
    print("平均分：无")
```

初始化在循环前，才能保留前面已经累计的结果。total保存分数之和，count保存符合条件的条数，passed保存分数本身。空列表不做除法；`[0, 0]` 有两条记录，因此平均分为0.0。循环中没有对scores进行写入，输入保持不变。
