## K01 · 赋值以后，谁发生变化

先写出两次print的结果，并解释字符串的加号与整数的加号有什么区别：

```python
a = 4
b = a + 2
a = 9
print(a, b)
print("4" + "2", 4 + 2)
```

再写代码让b增加3，输出9。不要改回a，也不要直接把答案9赋给b。

## K02 · 把输入变成可计算的数量

终端输入一个非负整数，表示购买本子的数量。每本3元，打印 `合计：21元` 这样的文字。分别输入7和0，预期合计21元和0元。解释为什么不能直接拿input的结果乘3当金额。本题约定输入合法，不要求异常处理。

## K03 · 每个分数只进入一档

先令 `score = 79`，写if/elif/else，打印以下四档之一：90—100优秀、80—89良好、60—79及格、0—59待加强。约定score是0—100的整数。

每次修改score并重新运行，检查59、60、79、80、89、90，预期依次为待加强、及格、及格、良好、良好、优秀。解释为何不使用三个互相独立的if来打印档位。

## K04 · 重复、跳过与停止

1. 用for和range处理1—5，遇到偶数continue，只打印奇数，每个数字占一行。
2. 另写一段独立程序，依次处理 `[2, 0, 5, -1, 9]`：0跳过，负数表示立即停止，其余数字打印。预期只打印2和5，9不出现。

说明第二段中continue与break分别跳到哪里。把数据换成空列表，程序应自然结束，没有数字输出。

## K05 · 用while处理到货指令

```python
commands = ["4", "0", "-1", "6", "stop", "100"]
initial_stock = 1
box_size = 3
```

必须使用while逐条读取。库存从initial_stock开始；正数加入库存，0和负数跳过；stop停止读取，不能把stop转换为整数。约定其余文本可转整数，箱容量为正整数。不改变commands。

最终只输出三行：

```text
总库存：11件
整箱：3箱
剩余：2件
```

再分别改为 `[]`、`["stop", "100"]`、`["4", "0", "6"]`。前两组总库存为1，最后一组为11。解释下标为什么要在continue之前推进。

## K06 · 总分、人数和名单是三种结果

```python
scores = [0, 60, 90]
```

用普通循环算总分、及格人数（≥60）、及格分数列表；计算所有分数的平均分，显示一位小数。不得改变原列表。输出：

```text
总分：150
及格人数：2
及格分数：[60, 90]
平均分：50.0
```

把scores改成 `[]`，总分和人数应为0，名单为空列表，平均分显示 `无`；改成 `[0, 0]` 时平均分应为 `0.0`。说明为什么初始化写在循环前，以及为何人数每次加1而不是加分数。
