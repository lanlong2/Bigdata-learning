## G01 · 作用域预测

输出6、10。函数参数是内部名字，重新赋值不会重绑外部value。

```python
value = 10
def double(value):
    value = value * 2
    return value
print(double(3))
print(value)
```

## G02 · 用关键字传参



```python
def format_record(name, score):
    return f"{name}:{score}"
first = format_record("小林", 86)
second = format_record(score=86, name="小林")
print(first, second)
```

## G04 · 任意数量的数

*numbers把位置参数收集成元组。

```python
def total_numbers(*numbers):
    return sum(numbers)
print(total_numbers(2, 3, 4))
print(total_numbers())
```

## G05 · 关键字信息

**fields收集为字典，get提供缺失时的默认值。

```python
def build_label(**fields):
    name = fields.get("name", "未命名")
    city = fields.get("city", "未知")
    return name + "@" + city
print(build_label(name="小林", city="杭州"))
```

## G06 · 把函数当参数

传twice而不是twice()。调用需要的参数由apply_to_values内部提供。

```python
def apply_to_values(values, operation):
    result = []
    for value in values:
        result.append(operation(value))
    return result

def twice(value):
    return value * 2

print(apply_to_values([1, 2, 3], twice))
```

## G07 · 按成绩排序

稳定排序保留相同分数的相对顺序；sorted返回新列表。

```python
def rank_scores(rows):
    return sorted(rows, key=lambda row: row[1], reverse=True)
print(rank_scores([("小林", 80), ("小周", 95), ("小陈", 80)]))
```

## G08 · 参数控制筛选与汇总



```python
def summarize_orders(orders, min_quantity=1):
    count = 0
    quantity_sum = 0
    for name, quantity in orders:
        if quantity >= min_quantity:
            count += 1
            quantity_sum += quantity
    return count, quantity_sum
print(summarize_orders([("pen", 2), ("book", 0), ("bag", 3)]))
```
