# 函数进阶 · 习题册使用说明

这是日常习题，可分次完成，不设整卷总分或统一考试时限。
前置条件与参考用时：**逐步学P63～70；每题约10～20分钟，G06～G07在学完函数参数与lambda后做**。参考时间不是必须达成的速度要求。

1. 不清楚概念时先看[对应笔记](../../../01_学习笔记/Python/05_函数进阶.md)。
2. 打开[题目](题目.md)，一次选一题。
3. 在[我的作答](我的作答.py)对应题号下填写；解释写注释，代码写空白处。
4. 尝试后再打开[答案解析](答案解析.md)逐题订正。
5. 填本页记录；做错的进入[错题本](../../../04_错题与疑问/错题本.md)。

## 作答规则

每题独立，需复制完整初始数据或函数定义一起运行；空白模板没有输出属正常。
新增题默认尚未完成。允许普通循环等正确等价写法，除非题目指定必须练某个语法。
写出结果后，至少更换一组数据自查；不要直接返回题目给出的固定答案。
