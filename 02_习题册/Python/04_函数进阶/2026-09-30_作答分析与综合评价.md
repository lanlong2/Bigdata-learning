## 当前重点：参数必须真正参与计算

G03定义了threshold，函数体却没有使用它。保留自己的写法，只需让条件比较实际参数：

```python
if score >= threshold:
    return True
else:
    return False
```

自己订正后检查：`is_pass(59)`为False、`is_pass(60)`为True、`is_pass(79,80)`为False、`is_pass(80,80)`为True、`is_pass(50,50)`为True。既测门槛提高，也测降低，才能避免“刚好通过样例”。这与G08已正确使用min_quantity是同一件事，可对照自己的G08理解。
