# 函数进阶 · 日常习题

共8题，按题练习，不按试卷计分。逐步学P63～70；每题约10～20分钟，G06～G07在学完函数参数与lambda后做。

## G01 · 作用域预测

预测下面代码的两行输出，并解释外部value是否改变。

```python
value = 10
def double(value):
    value = value * 2
    return value
print(double(3))
print(value)
```

## G02 · 用关键字传参

定义format_record(name, score)，返回"小林:86"格式。分别用位置参数、把score写在name前的关键字参数调用，结果应相同。

## G03 · 默认分数线

定义is_pass(score, threshold=60)，分数大于等于分数线返回True，否则False。检查59、60以及自定义80分线。

## G04 · 任意数量的数

定义total_numbers(*numbers)，返回所有传入数字之和；不传数字返回0。说明numbers在函数内的类型。

## G05 · 关键字信息

定义build_label(**fields)。name缺失时用"未命名"，city缺失时用"未知"，返回"姓名@城市"。传入的字段值均为字符串，其他字段可以忽略。

## G06 · 把函数当参数

定义apply_to_values(values, operation)，对列表每个元素调用operation，返回新列表，不能修改原列表。再定义twice并传进去；[1,2,3]得到[2,4,6]。

## G07 · 按成绩排序

定义rank_scores(rows)，输入(姓名,分数)元组列表，按分数降序返回新列表。同分保持原顺序；空列表返回空列表；不能改原列表。用lambda作为排序key。

## G08 · 参数控制筛选与汇总

定义summarize_orders(orders, min_quantity=1)。orders是(商品名,数量)列表，保留数量不小于min_quantity的记录，返回(保留记录数, 数量之和)；没有符合项返回(0,0)。
