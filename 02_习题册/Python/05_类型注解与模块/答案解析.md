## M02 · 注解会自动转换吗

原调用输出字符串33，注解不执行转换。int转换可能失败，此题只要求处理给定的合法整数文本。

```python
def twice(value: int) -> int:
    return value * 2

def parse_twice(value):
    return int(value) * 2
print(twice("3"))
print(parse_twice("3"))
```

## M03 · 导入自己的模块

两个文件必须真正分别保存，运行run_examples.py；参考代码中的文件名注释是分界，不是把它们合成一个文件。

```python
# helpers.py
def clean_name(name):
    return name.strip().lower()

# run_examples.py
from helpers import clean_name
print(clean_name(" Alice "))
```

## M04 · 避免导入时自动演示

导入时__name__是模块名，直接运行时是__main__。不要用入口保护把函数定义也藏起来。

```python
# helpers.py（在M03基础上替换为此版本）
def clean_name(name):
    return name.strip().lower()

if __name__ == "__main__":
    print(clean_name(" Alice "))
```

## M05 · 看懂包的路径

导入语句是from tools.cleaning import clean_name。入门示例的__init__.py可以为空；运行入口应在项目根。

```python
from tools.cleaning import clean_name
```

## M06 · 使用标准库JSON



```python
import json
data = {"城市": "杭州", "数量": 3}
text = json.dumps(data, ensure_ascii=False)
restored = json.loads(text)
print(text)
print(restored == data)
```
