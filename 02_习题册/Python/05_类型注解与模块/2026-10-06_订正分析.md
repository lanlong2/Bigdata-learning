## 需要理解的几处区别

### 类型注解与类型转换

`value: int`是在说明希望收到整数，运行时不会把`"3"`自动改成3。字符串乘2得到字符串`"33"`；先用`int(value)`转换，再乘2，才能得到整数6。本题只要求处理给定的合法整数文本，不需要提前加入后续异常处理语法。

### 模块名与函数名

```python
from tools.cleaning import clean_name
```

`tools`是包，`cleaning`是包内模块，`clean_name`是该模块中的函数。本题不要求创建这套目录，因此订正稿中将这行保留为注释。

### JSON字符串与文件

```python
text = json.dumps(a, ensure_ascii=False)
restore = json.loads(text)
```

`dumps`把数据变成字符串，`loads`从字符串还原数据。`dump`需要传入文件对象来写文件，`load`需要文件对象来读文件。`type(text)`可以直接打印；加上`.__name__`只取类型名称，所以打印str而不是`<class 'str'>`。
