## M01 · 给函数加说明类型

定义area(width, height)，两个输入均是整数，返回乘积。为参数与返回值添加int注解，检查area(3,4)。

## M02 · 注解会自动转换吗

预测下面调用的结果，并说明注解是否自动把字符串变为整数。再定义parse_twice，让给定的"3"或整数3都得到数字6。

```python
def twice(value: int) -> int:
    return value * 2
print(twice("3"))
```

## M03 · 导入自己的模块

在同目录的helpers.py定义clean_name：去两端空白、转小写。再在run_examples.py导入并调用，传" Alice "打印alice。两文件均提供了空白模板；不要把文件名本身当代码输入。

## M04 · 避免导入时自动演示

在M03的helpers.py中加一段演示：直接运行它时打印alice，从run_examples.py导入时不额外打印。使用__name__入口保护。run_examples.py仍只输出自己调用的一次结果。

## M05 · 看懂包的路径
