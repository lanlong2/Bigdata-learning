## D01 · 用字段名读写一条记录

给定 `student = {"name": "小林", "score": 60}`：读取姓名；把分数改成75；加入city为杭州，再删除city。安全读取不存在的age，显示未填写。最后student应为 `{'name': '小林', 'score': 75}`。

解释 `student["score"]`、`student.get("age", "未填写")` 分别得到什么；get会不会给原字典添加age？

## D02 · 遍历拿到的是键还是值

给定 `scores = {"小林": 80, "小周": 95}`：打印 `"小林" in scores` 和 `"小林" in scores.values()` 的结果；用items同时打印姓名和分数，每人一行。打印只含分数的列表 `[80, 95]`。

说明为什么字典不能用 `scores[0]` 表示第一项。本题保持字典插入顺序，不要求排名。

## D03 · 合计数量与记录次数

给定 `rows = [("小林", 0), ("小周", 4), ("小林", 2)]`，建立两份字典：每个人的数量合计、每个人的记录次数。

结果分别为 `{'小林': 2, '小周': 4}` 和 `{'小林': 2, '小周': 1}`。输入为空时两份结果都为空字典。0也算一条记录，不能跳过。

## D04 · 集合只保存不同元素

给定 `topics = ["sql", "python", "sql"]`，建立集合，加入excel，安全删除不存在的java，再删除sql。打印集合类型、不同主题数，以及排序展示的 `['excel', 'python']`。不要把add的返回值重新赋给集合。

另给 `a = {"python", "sql"}`、`b = {"sql", "excel"}`，分别求交集和 `a - b`。集合结果保持为set，只在打印时用sorted固定展示顺序。

## D05 · 每个人有自己的主题集合

```python
rows = [("小林", " Python "), ("小周", "sql"),
        ("小林", "python"), ("小林", "Excel"), ("小周", "   ")]
```

清洗主题两端空白并转小写，清洗后空主题跳过。建立姓名→主题集合的字典groups；小林对应python和excel，小周对应sql。重复主题只保存一份。按姓名首次出现顺序打印，每人的主题排序展示：

```text
小林 ['excel', 'python']
小周 ['sql']
```

说明为何不能每轮把groups[name]重建为空集合，以及为何不能让所有姓名共享同一个集合。输入为空时groups为空字典，没有姓名输出。

## D06 · 保留第一条有效记录

```python
orders = [
    {"id": " A01 ", "quantity": 0},
    {"id": "A01", "quantity": 5},
    {"id": "A02", "quantity": 4},
    {"id": "A01", "quantity": 99},
    {"id": "  ", "quantity": 3},
]
```

约定每条记录都有id字符串和quantity整数。id去掉两端空白后非空，且数量大于0，才是有效记录。按清洗后的id查重，保留第一条有效记录和原出现顺序。结果是新列表，每项是新字典，不修改orders：

```text
[{'id': 'A01', 'quantity': 5}, {'id': 'A02', 'quantity': 4}]
```

第一次A01无效，不能提前把它记为“已经保留”。原第一条记录的id仍应为 `" A01 "`。把输入换成 `[]` 时结果为空列表。
