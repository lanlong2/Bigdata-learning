## D01

```python
student = {"name": "小林", "score": 60}
print(student["name"])
student["score"] = 75
student["city"] = "杭州"
del student["city"]
print(student.get("age", "未填写"))
print(student)
```

依次打印小林、未填写、最终字典。`student["score"]` 得到分数75；get缺键时返回默认文字，不给原字典添加字段。

## D02

```python
scores = {"小林": 80, "小周": 95}
print("小林" in scores)           # True
print("小林" in scores.values())  # False
for name, score in scores.items():
    print(name, score)
print(list(scores.values()))      # [80, 95]
```

姓名是键，分数是值；`scores[0]` 查找键0，本题没有这个键，会报KeyError。items每轮提供一对键和值，拆给两个变量。

## D03

```python
rows = [("小林", 0), ("小周", 4), ("小林", 2)]
totals = {}
counts = {}
for name, quantity in rows:
    totals[name] = totals.get(name, 0) + quantity
    counts[name] = counts.get(name, 0) + 1
print(totals)  # {'小林': 2, '小周': 4}
print(counts)  # {'小林': 2, '小周': 1}
```

总量加quantity，次数加1，两份结果分别保留。初始字典在循环外建立；空rows不进入循环，结果自然是两份空字典。

## D04

```python
topics = ["sql", "python", "sql"]
unique = set(topics)
unique.add("excel")
unique.discard("java")
unique.remove("sql")
print(type(unique))    # <class 'set'>
print(len(unique))     # 2
print(sorted(unique)) # ['excel', 'python']
a = {"python", "sql"}
b = {"sql", "excel"}
common = a & b
only_a = a - b
print(sorted(common)) # ['sql']
print(sorted(only_a)) # ['python']
```

common和only_a仍是集合，sorted只创建展示用列表。add修改unique并返回None，所以不用接回unique。

## D05

```python
rows = [("小林", " Python "), ("小周", "sql"),
        ("小林", "python"), ("小林", "Excel"), ("小周", "   ")]
groups = {}
for name, topic in rows:
    topic = topic.strip().lower()
    if not topic:
        continue
    if name not in groups:
        groups[name] = set()
    groups[name].add(topic)
for name, topics in groups.items():
    print(name, sorted(topics))
```

输出与题目一致。只在新姓名第一次出现时建立一个新集合，不清空旧主题，也不让不同姓名共用同一个集合。空输入得到空字典，无姓名输出。

## D06

```python
orders = [
    {"id": " A01 ", "quantity": 0},
    {"id": "A01", "quantity": 5},
    {"id": "A02", "quantity": 4},
    {"id": "A01", "quantity": 99},
    {"id": "  ", "quantity": 3},
]
seen = set()
cleaned = []
for order in orders:
    order_id = order["id"].strip()
    quantity = order["quantity"]
    if not order_id or quantity <= 0:
        continue
    if order_id in seen:
        continue
    seen.add(order_id)
    cleaned.append({"id": order_id, "quantity": quantity})
print(cleaned)
print(orders[0]["id"] == " A01 ")  # True：原数据未修改
```

先校验再记录id。第一条A01数量0无效，没有占用编号；第二条才是第一条有效A01，后面的99被去重。新字典保存清洗后的字段，输入字典保持原样；结果列表依靠append保持首次顺序。
