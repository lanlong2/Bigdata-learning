## A 组 · 字符串

### A1 · 索引与切片
```python
s = "BigData2026"
```
写出表达式，分别得到：
① `"B"` ② `"6"`（最后一个字符）③ `"Big"` ④ `"2026"` ⑤ `"6202ataDgiB"` ⑥ 字符串长度 ⑦ 隔一个取一个的结果

> 💡 提示：⑤ 用步长 `-1`；④ 想想"从倒数第 4 个到结尾"怎么写，不必数出正索引。

### A2 · 不可变性判断题
按顺序推理；遇到报错先记录，推理后续行时跳过该行，沿用此前成功状态。真实程序遇到未处理异常会停止，核对后续行需先注释掉错误行。
```python
s = "python"
s.upper()
s[0] = "P"
s = s.replace("p", "P")
s += "!"
```
> 💡 提示：只有带 `=` 号的那两行才会真正改变 `s` 指向的内容；`s[0] = "P"` 是本题的陷阱。

### A3 · split 与 join 往返
```python
line = "苹果,香蕉,,橘子"
```
① 拆成列表，看看长度是几；② 把拆出来的列表用 `" | "` 合回一个字符串；③ 想办法拆完后**去掉空字符串**再合并。

> 💡 提示：连续的逗号会拆出一个 `""`；③ 用推导式加 `if` 过滤，条件可以直接写 `if x`（空串为假）。

---

### A4 · 清洗一行脏数据
```python
raw = "   Zhang San ,  18  \n"
```
把它清洗成 `"zhangsan|18"`。

> 💡 提示：分三步——先 `strip()` 去两端空白，再按 `","` 拆开，对每一段各自 `strip()`；空格用 `replace` 去掉，大小写用 `lower()`。

> 💡 提示：③ `find` 找不到不报错，返回一个特殊值；⑤ 先 `split()` 再 `len()`。

### A6 · f-string 排版
用一个 for 循环打印下面这张表，要求**姓名左对齐占 8 格、分数右对齐占 6 格、平均分保留 1 位小数**：
```python
rows = [("张三", 88), ("李四", 95), ("王五", 79)]
```
最后再打印一行 `平均分：xx.x`。

> 💡 提示：对齐写在冒号后面 `f"{name:<8}{score:>6}"`；平均分用 `f"{avg:.1f}"`。

### A7 · 字符级操作
```python

```
① 有几个 `"s"` ② 去重后有哪些字母（顺序不限）③ 按字母表排序后拼回一个字符串 ④ 判断它是不是回文（正着反着一样）

> 💡 提示：② `set(word)`；③ `sorted()` 返回列表，要再 `join` 回字符串；④ 拿 `word` 和 `word[::-1]` 比一下就行。

### A8 · 找错题
检查下面5处操作，区分“报错”“合法但没有调用方法”“合法但不符合预期”。说明结果和修改方式；n这一处的意图是把给定文本"3.14"转为小数。
```python
age = 18
msg = "我今年" + age + "岁"
```

## B 组 · 元组

### B1 · 元组还是别的
写出下面每个变量的**类型**和**长度**（不能写长度的说明原因）：
```python
a = (1, 2, 3)
b = (7)
c = (7,)
d = ()
e = 1, 2
f = ("abc")
g = ("abc",)
```
> 💡 提示：单元素元组要有逗号，空元组直接写()；`f` 和 `g` 的长度会差很多，想想 `len("abc")` 是几。

---

### B2 · 能做与不能做
每行独立基于原始t判断，写结果或错误类型；不承接上一行运行：
```python
t = (10, 20, 30)
t[0]
t[1:]
t[0] = 99
t.append(40)
t.count(20)
t + (40,)
sorted(t)
len(t)
```
> 💡 提示：凡是会"改动 t 本身"的都会失败；`t + (40,)` 和 `sorted(t)` 都是**生成新东西**，所以能过。

---

### B3 · 拆包练习
```python
info = ("张三", 18, "计算机", 3.8)
```
① 用拆包一次性取出四个变量并打印 ② 只要姓名和"其余全部" ③ 只要最后一个 GPA 和"前面全部" ④ 把 `x, y = 1, 2` 里的两个值交换

> 💡 提示：②③ 用星号 `*`，星号接住的部分会变成**列表**；④ 一行就够，右边先算完再赋值。

---

### B4 · 元组的"半可变"陷阱
不运行，预测每一步的结果：
```python
t = ("a", [1, 2], 3)
t[1].append(9)
print(t)
t[2] = 30
print(t)
```
> 💡 提示：第 2 行动的是"袋子里的东西"，第 4 行动的是"格子本身"，只有一个会报错。

---

### B5 · 为什么用元组
① 试着用列表 `[0, 0]` 作字典的 key，看报什么错；② 换成元组 `(0, 0)` 再试；③ 用一句话解释为什么会有这个差别。

> 💡 提示：报错关键词是 `unhashable`；字典key必须可哈希；列表不可哈希，元组还要检查每个元素。

---

### B6 · 互相转换
```python
t = (3, 1, 2)
```
在**不允许直接改 t** 的前提下，得到一个排好序的元组 `(1, 2, 3)`。

> 💡 提示：`sorted(t)` 给的是列表，最后需要再包一层转回元组。

## 大题一 · 成绩单解析（字符串 → 列表 → 元组）

```python
raw = "张三,88,92,79;李四,95,60,73;王五,45,100,68"
```

分号 `;` 分隔学生，逗号 `,` 分隔字段，格式是「姓名,语文,数学,英语」。要求：

1. 把 `raw` 拆成**每个学生一条**的字符串列表，打印出来。
2. 把每个学生解析成一个**元组** `(姓名, 总分, 平均分)`，全部装进列表 `records`，打印 `records`。
   （分数从字符串转成整数后再算）
3. 按**平均分从高到低**排序，得到 `ranked`。
4. 用 f-string 打印排行榜，格式：`第1名 张三   总分259 平均86.3`（姓名左对齐 6 格，平均分保留 1 位小数，名次从 1 开始）。
5. 找出**有不及格科目（<60）的学生姓名**，并打印他一共挂了几科。
6. 用 `"、"` 把所有学生姓名连成一个字符串打印出来。
7. 思考题：第 2 步为什么用**元组**装 `(姓名, 总分, 平均分)`，而分数本身用**列表**装？

> 💡 提示：第 1 步用 `split(";")`，第 2 步对每条再 `split(",")`；`fields[0]` 是姓名，`fields[1:]` 是分数（切片得到的还是列表）。
> 💡 排序用 `sorted(records, key=lambda r: r[2], reverse=True)`；名次用 `enumerate(ranked, 1)`。

## 大题二 · 文本词频统计（字符串清洗 + 列表统计 + 元组排序）

```python
text = "  Python is fun. python is powerful; PYTHON is everywhere!  "
```

1. 打印 `len(text)` 和 `len(text.strip())`，说明差了几个字符、为什么。
2. 清洗：去两端空白 → 全部转小写 → 去掉标点 `.` `;` `!`，得到 `clean`，打印它。
3. 把 `clean` 拆成单词列表 `words`，打印它和单词总数。
4. 得到**不重复的单词**并按字母顺序排好，放进列表 `uniq`。
5. 生成 `pairs`：一个**列表**，每个元素是**元组** `(单词, 出现次数)`，顺序按 `uniq` 来。
6. 把 `pairs` 按**次数从高到低**排序得到 `ranked`，打印出现最多的那个元组。
7. 用 f-string 打印词频表：单词左对齐 12 格、次数跟在后面。
8. 把**出现 ≥2 次**的单词用 `"|"` 连成一个字符串打印。
9. 另外求：原始 `text` 里 `"is"` 出现几次、`"fun"` 在 `text.strip()` 中的起始位置、`text.strip()` 是否以 `"Python"` 开头。

> 💡 提示：去标点可以 `for ch in ".;!": clean = clean.replace(ch, "")`；统计次数直接用 `words.count(w)`，配合推导式一行搞定 `pairs`。
> 💡 第 6 步 `sorted(pairs, key=lambda p: p[1], reverse=True)`；次数相同的会保持原来的先后顺序（稳定排序）。

## 大题三 · 坐标点处理（元组列表 + 拆包 + zip）

```python
points = [(1, 2), (4, 0), (-3, 5), (0, 0), (2, -7)]
```

1. 用 `enumerate` 遍历，按 `P0: x=1, y=2, 距离平方=5` 的格式逐行打印（距离平方 = x²+y²，不用开方）。
2. 找出**离原点最远**的点。
3. 按 **y 坐标从小到大**排序，打印结果。
4. 生成一个新列表 `swapped`，把每个点的 x、y 互换（元素仍是元组）。
5. 筛选出**第一象限**（x>0 且 y>0）的点。
6. 把所有 x 装进列表 `xs`、所有 y 装进列表 `ys`；再用 `zip` 把它们**还原**成原来的 `points`，并验证是否相等。
7. 用一行 `xs2, ys2 = zip(*points)` 也做一遍，打印 `type(xs2)`，说明它和第 6 步的 `xs` 有什么不同。
8. 给每个点配一个标签 `["P0", "P1", ...]`，用 `zip` 合成 `[("P0", (1,2)), ...]` 的列表。
9. 把所有点连成一个字符串：`(1,2), (4,0), (-3,5), (0,0), (2,-7)`。
10. 试着执行 `points[0][0] = 99` 会怎样？请写出报错类型，并给出**正确的"修改某个点"的做法**（把 `(-3, 5)` 改成 `(30, 5)`，且不影响原来的元组）。

> 💡 提示：第 2、3 步都用 `key=lambda p: ...`；第 4、5 步用推导式，`for x, y in points` 可以直接在推导式里拆包。
> 💡 第 10 步的正确做法：元组改不了，只能 `list(旧元组)` → 改列表 → `tuple()` 转回来，再赋值回 `points` 的对应位置（列表是可变的，所以这一步能成）。

## 大题四 · 可变与不可变预测（先推理，再分段验证）

按顺序写每个print的输出；报错写错误类型和原因，然后跳过该行继续沿用此前状态。实际运行时须注释预期报错行，否则程序会提前停止。

```python
s = "hello"
t = (1, 2, [3, 4])
lst = [10, 20, 30]

a = s.upper()
print(1, s, a)                 # ?

s2 = s.replace("l", "L")
print(2, s, s2)                # ?

t[2].append(5)
print(3, t)                    # ?

t[0] = 99                      # ? 成功还是报错
lst2 = lst
lst2.append(40)
print(5, lst, lst2)            # ?

tup = tuple(lst)
lst.append(50)
print(6, tup, lst)             # ?

x = (7)
y = (7,)
print(7, type(x), type(y), len(y))     # ?

words = "a-b-c".split("-")
joined = "".join(words)
print(8, words, joined, len(joined))   # ?

nums = [3, 1, 2]
snap = tuple(nums)
nums.sort()
print(9, nums, snap)           # ?

print(11, s[1:4], s[::-1], s[-1], len(s))   # ?
print(12, t + (6,), (0,) * 3)               # ?
t.append(9)                    # ? 成功还是报错
print(14, t.count(1), t.index(2))           # ?
```

额外回答：
- ① 第 3 行为什么能改成功，第 4 行却报错？
- ② 第 5 行 `lst2 = lst` 和第 6 行 `tup = tuple(lst)`，哪一个是"真复制"？
- ③ 第 9 行 `snap` 为什么没跟着 `nums.sort()` 一起变？这说明元组适合用来做什么？

> 💡 提示：把"不可变"想成"这个盒子焊死了"，把 `=` 想成"贴了第二张标签在同一个盒子上"，而 `tuple(lst)` 是"照了一张相"。
> 💡 序号 4、13 是故意留的空号——那两行如果报错，程序其实会停在那里，请当成"单独试验"来判断。
