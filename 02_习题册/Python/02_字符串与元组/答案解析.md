## B1 · 类型与长度

空元组写()；一个字符串放在括号里不会自动成为元组，需要逗号。

```python
a = (1, 2, 3)
b = (7)
c = (7,)
d = ()
e = 1, 2
f = ("abc")
g = ("abc",)
print(type(a), len(a))  # tuple, 3
print(type(b))          # int；len(b)会TypeError，没有长度
print(type(c), len(c))  # tuple, 1
print(type(d), len(d))  # tuple, 0
print(type(e), len(e))  # tuple, 2
print(type(f), len(f))  # str, 3
print(type(g), len(g))  # tuple, 1
```

# 综合习题解析

综合题一～三涉及lambda、zip等拓展；每道综合题的代码独立运行。

## 大题一 · 详解

```python
raw = "张三,88,92,79;李四,95,60,73;王五,45,100,68"

# 1) 按分号拆学生
parts = raw.split(";")
print(parts)
# ['张三,88,92,79', '李四,95,60,73', '王五,45,100,68']

# 2) 每条再按逗号拆字段 → 装成元组
records = []
for item in parts:
    fields = item.split(",")          # ['张三', '88', '92', '79']
    name = fields[0]                  # 第0个是姓名
    scores = [int(x) for x in fields[1:]]   # 切片拿后面全部，推导式逐个转 int
    records.append((name, sum(scores), sum(scores) / len(scores)))
print(records)
# [('张三', 259, 86.33333333333333), ('李四', 228, 76.0), ('王五', 213, 71.0)]

# 3) 按平均分（元组的第2号位）从高到低排
ranked = sorted(records, key=lambda r: r[2], reverse=True)

# 4) 排行榜
for i, (name, total, avg) in enumerate(ranked, 1):   # enumerate 从1开始编号，同时拆包元组
    print(f"第{i}名 {name:<6}总分{total} 平均{avg:.1f}")
# 第1名 张三    总分259 平均86.3
# 第2名 李四    总分228 平均76.0
# 第3名 王五    总分213 平均71.0

# 5) 不及格科目
for item in parts:
    fields = item.split(",")
    fails = [int(x) for x in fields[1:] if int(x) < 60]
    if fails:
        print(f"{fields[0]} 有 {len(fails)} 科不及格：{fails}")
# 王五 有 1 科不及格：[45]

# 6) 姓名连接
print("、".join([r[0] for r in records]))    # 张三、李四、王五
```

**关键点拆解**

| 步骤 | 用到的知识 | 易错点 |
|------|-----------|-------|
| 1 | `split(";")` | 拆出来是**列表**，不是元组 |
| 2 | 切片 `fields[1:]` + `int()` + 推导式 | `"88"` 是字符串，不转 `int` 就没法求和 |
| 3 | `sorted(key=..., reverse=True)` | `key` 里的 `r[2]` 表示"按元组第3个元素排" |
| 4 | `enumerate(ranked, 1)` + 拆包 + f-string 对齐 | `enumerate` 第二个参数是**起始编号** |
| 6 | `join` 只吃字符串 | 如果拼分数必须先 `str()` |

**第7问（思考题）答案**：
`(姓名, 总分, 平均分)` 是**一条记录的三个不同字段**，字段个数固定、含义固定、一旦算出来就不该被改 → 用**元组**，还能顺手拆包 `name, total, avg = r`。
而 `[88, 92, 79]` 是**同类的多个分数**，数量可能变（加一门课就 append 一个）→ 用**列表**。
`records` 本身是"很多条同类记录"，所以外层用列表、内层用元组，这是数据处理里最常见的组合：**列表装行，元组装字段**。

## 大题二 · 详解

```python
text = "  Python is fun. python is powerful; PYTHON is everywhere!  "

# 1) 长度对比
print(len(text), len(text.strip()))       # 60 56
# 差 4 个字符 = 开头2个空格 + 结尾2个空格，strip() 只去两端、不动中间

# 2) 清洗：去空白 → 转小写 → 去标点
clean = text.strip().lower()
for ch in ".;!":
    clean = clean.replace(ch, "")         # ⚠️ 必须重新赋值给 clean，字符串不可变
print(clean)
# python is fun python is powerful python is everywhere

# 3) 拆成单词
words = clean.split()                     # 不给参数 = 按任意空白拆
print(words, len(words))
# ['python','is','fun','python','is','powerful','python','is','everywhere'] 9

# 4) 去重 + 排序
uniq = sorted(set(words))
# ['everywhere', 'fun', 'is', 'powerful', 'python']

# 5) (单词, 次数) 元组列表
pairs = [(w, words.count(w)) for w in uniq]
# [('everywhere',1), ('fun',1), ('is',3), ('powerful',1), ('python',3)]

# 6) 按次数降序
ranked = sorted(pairs, key=lambda p: p[1], reverse=True)
print(ranked[0])                          # ('is', 3)
# ranked = [('is',3), ('python',3), ('everywhere',1), ('fun',1), ('powerful',1)]

# 7) 词频表
for w, c in ranked:
    print(f"{w:<12}{c}")
# is          3
# python      3
# everywhere  1
# fun         1
# powerful    1

# 8) 出现>=2次
print("|".join([w for w, c in ranked if c >= 2]))    # is|python

# 9) 其它查询
s = text.strip()
print(s.count("is"), s.find("fun"), s.startswith("Python"))   # 3 10 True
```

**关键点拆解**

- **为什么先 `lower()`？** 因为 `"Python"`、`"python"`、`"PYTHON"` 在计算机眼里是三个**不同**的字符串。本题要求忽略大小写，因此先统一；实际任务是否区分大小写，要看具体规则。
- **为什么要去标点？** 不去的话 `"fun."` 和 `"fun"` 会被算成两个词。
- **`clean = clean.replace(...)` 里的赋值不能省**——省了等于白做（字符串不可变，见知识点 3）。
- **`set` 不保证保留输入顺序**，所以外面套了 `sorted()` 让结果稳定可复现。
- **稳定排序**：`is` 和 `python` 都是 3 次，谁在前？`sorted` 是**稳定**的，会保留它们在 `pairs` 里的原顺序（`is` 字母序在前），所以 `is` 排前面。
- `words.count(w)` 是**列表**的方法，`s.count("is")` 是**字符串**的方法，名字一样、对象不同——这正是"字符串就是一串字符组成的序列"的体现。

## 大题三 · 详解

```python
points = [(1, 2), (4, 0), (-3, 5), (0, 0), (2, -7)]

# 1) 遍历 + 拆包（for 后面直接写 (x, y) 就能拆开元组）
for i, (x, y) in enumerate(points):
    print(f"P{i}: x={x}, y={y}, 距离平方={x**2 + y**2}")
# P0: x=1, y=2, 距离平方=5
# P1: x=4, y=0, 距离平方=16
# P2: x=-3, y=5, 距离平方=34
# P3: x=0, y=0, 距离平方=0
# P4: x=2, y=-7, 距离平方=53

# 2) 最远的点
far = max(points, key=lambda p: p[0]**2 + p[1]**2)
print(far)                       # (2, -7)

# 3) 按 y 排序
by_y = sorted(points, key=lambda p: p[1])
print(by_y)                      # [(2,-7), (4,0), (0,0), (1,2), (-3,5)]
#  ⚠️ (4,0) 和 (0,0) 的 y 都是 0，稳定排序保持它们的原顺序

# 4) x、y 互换
swapped = [(y, x) for x, y in points]
print(swapped)                   # [(2,1), (0,4), (5,-3), (0,0), (-7,2)]

# 5) 第一象限
q1 = [p for p in points if p[0] > 0 and p[1] > 0]
print(q1)                        # [(1, 2)]

# 6) 拆成两列再合回去
xs = [x for x, y in points]      # [1, 4, -3, 0, 2]
ys = [y for x, y in points]      # [2, 0, 5, 0, -7]
print(list(zip(xs, ys)) == points)      # True
#  zip 本身是个"懒惰"对象，必须 list() 一下才能看/比较

# 7) 星号拆包 + zip
xs2, ys2 = zip(*points)
print(xs2, type(xs2))            # (1, 4, -3, 0, 2) <class 'tuple'>
#  区别：第6步用推导式得到的是【列表】，zip(*points) 得到的是【元组】

# 8) 配标签
labels = ["P" + str(i) for i in range(len(points))]
print(list(zip(labels, points)))
# [('P0',(1,2)), ('P1',(4,0)), ('P2',(-3,5)), ('P3',(0,0)), ('P4',(2,-7))]

# 9) 连成字符串
print(", ".join([f"({x},{y})" for x, y in points]))
# (1,2), (4,0), (-3,5), (0,0), (2,-7)

# 10) 想改元组里的值
# points[0][0] = 99  # 单独执行会TypeError；此处注释才能继续运行正确修改示例
# ✗ TypeError: 'tuple' object does not support item assignment

# ✓ 正确做法：元组转列表 → 改 → 转回元组 → 放回列表（列表是可变的，所以这一步能成）
tmp = list(points[2])            # [-3, 5]
tmp[0] = 30
points[2] = tuple(tmp)           # (30, 5)
print(points[2])                 # (30, 5)
```

**关键点拆解**

- `zip(*points)` 里的 `*` 是"把列表里的每个元组**摊开**当成独立参数"，等价于 `zip((1,2), (4,0), (-3,5), (0,0), (2,-7))`，效果是**行列互换**（转置）。这是元组列表里最漂亮的一招。
- 第 10 步揭示了一个重要事实：**`points` 是列表（可变），里面的点是元组（不可变）**。所以"换掉整个点"可以，"改点里的一个数"不行。
- 这种设计其实很有道理：一个坐标点是一个**整体**，它要么被整个替换，要么保持不动——不该出现"x 改了一半"的中间状态。

## 大题四 · 详解（先记录报错，再跳过错误行继续推理）

| 行 | 输出 / 结果 | 原因 |
|----|------------|------|
| `print(1, s, a)` | `1 hello HELLO` | `upper()` 返回新串，`s` 纹丝不动 |
| `print(2, s, s2)` | `2 hello heLLo` | `replace` 同理，只有 `s2` 拿到了新串 |
| `print(3, t)` | `3 (1, 2, [3, 4, 5])` | 改的是**元组里那个列表的内部**，元组的格子没换 |
| `t[0] = 99` | ✗ **TypeError**: `'tuple' object does not support item assignment` | 想换掉格子里的东西 → 元组不允许 |
| `print(5, lst, lst2)` | `5 [10,20,30,40] [10,20,30,40]` | `lst2 = lst` 只是**贴了第二张标签**，两个名字指同一个列表 |
| `print(6, tup, lst)` | `6 (10,20,30,40) [10,20,30,40,50]` | 这里元素是整数，转换后原列表的外层增删不影响元组 |
| `print(7, type(x), type(y), len(y))` | `7 <class 'int'> <class 'tuple'> 1` | `(7)` 是整数，`(7,)` 才是元组 |
| `print(8, words, joined, len(joined))` | `8 ['a','b','c'] abc 3` | split 得列表、join 得字符串，长度是字符数 |
| `print(9, nums, snap)` | `9 [1, 2, 3] (3, 1, 2)` | `sort()` 就地改列表，`snap` 是排序前的快照，保持原样 |
| `print(11, ...)` | `11 ell olleh o 5` | 切片、反转、末位、长度 |
| `print(12, ...)` | `12 (1, 2, [3, 4, 5], 6) (0, 0, 0)` | 元组 `+` 生成新元组；`*` 是重复 |
| `t.append(9)` | ✗ **AttributeError**: `'tuple' object has no attribute 'append'` | 元组根本没有这个方法 |
| `print(14, t.count(1), t.index(2))` | `14 1 1` | `1` 出现 1 次；`2` 在索引 1 的位置 |

**三个额外问题**

**① 第3行能改、第4行报错？**
`t[2].append(5)` 动的是"格子里那个**袋子的内容**"，`t` 的三个格子分别指向谁**没变**；
`t[0] = 99` 是"把 0 号格子指向的东西**换成别的**"，这才是元组禁止的操作。
一句话：**元组冻结的是"指向关系"，不是"被指向的对象内部"。**

**② 谁是真复制？**
`tup = tuple(lst)` 创建新的外层元组，并不是深度复制；`lst2 = lst` **不是**复制，只是给同一个列表起了第二个名字（`lst is lst2` 为 `True`），改哪个都等于改同一个东西。

**③ `snap` 为什么没变？**

本题nums只包含整数，tuple(nums)保存了当时元素的排列；nums.sort()重新排列原列表，不会重新排列snap。
若元组内引用着列表等可变对象，内部对象仍可能变化，所以tuple不能当作任意数据的深度备份。
