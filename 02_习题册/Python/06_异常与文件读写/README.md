# 异常与文件读写 · 习题册使用说明

这是日常习题，可分次完成，不设整卷总分或统一考试时限。
前置条件与参考用时：**先学模块、异常和文件笔记；每题约10～25分钟，运行保存好的.py文件**。参考时间不是必须达成的速度要求。

1. 不清楚概念时先看[对应笔记](../../../01_学习笔记/Python/07_异常与文件读写.md)。
2. 打开[题目](题目.md)，一次选一题。
3. 在[我的作答](我的作答.py)对应题号下填写；解释写注释，代码写空白处。
4. 尝试后再打开[答案解析](答案解析.md)逐题订正。
5. 填本页记录；做错的进入[错题本](../../../04_错题与疑问/错题本.md)。

## 作答规则

每题独立，需包含完整初始数据或函数定义；空白模板没有输出属正常。
本册使用`__file__`定位练习数据，请保存后运行整个`我的作答.py`，不要运行选中片段。只检查一题时，先把其他题的代码注释掉。
`BASE`表示本习题文件所在文件夹，`OUTPUT`表示它里面的“我的输出”文件夹；首次写文件前调用`OUTPUT.mkdir(exist_ok=True)`创建该文件夹，后续重复调用也可以。
新增题默认尚未完成。允许普通循环等正确等价写法，除非题目指定必须练某个语法。
写出结果后，至少更换一组数据自查；不要直接返回题目给出的固定答案。
