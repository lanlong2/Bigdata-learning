# 异常与文件读写 · 日常习题

共6题，按题练习，不按试卷计分。先学模块、异常和文件笔记；每题约10～25分钟，运行保存好的.py文件。

## I01 · 把坏输入变成可处理结果

定义parse_integer(text)，能转整数则返回整数，转换失败返回None。检查"12"、" abc "、""和" 0 "。只捕获ValueError，不能把失败写成数字0。

## I02 · 转换成功还要检查条件

定义positive_quantity(text)，返回大于0的整数；无法转换、0或负数均返回None。输入"2"、"0"、"-3"、"2.5"各得到什么？

## I03 · 读取文本并过滤空行

读取本目录“练习数据/names.txt”，UTF-8；去每行两端空白、转小写、跳过空行，保留重复名字和原顺序。保存到names列表并打印；给定文件应有3条有效名字。请运行保存好的.py文件。

## I04 · JSON写入后再读回

把{"姓名":"小林","分数":[80,90]}保存到“我的输出/record.json”，保留中文、缩进2格，再读回比较。不能覆盖练习数据。

## I05 · 读取CSV并处理非法数量

读取“练习数据/orders.csv”：product去两端空白、转小写；数量须为大于0的整数。空商品、非法数量计为无效。保留有效记录到clean列表，每条为含product、quantity的字典；保存无效行数invalid_count。给定样例应保留pen和book两条，数量总和5，无效2条。

## I06 · 写CSV并检查结果

本题独立：给定clean=[{"product":"pen","quantity":2},{"product":"book","quantity":3}]，写入“我的输出/clean.csv”，字段按product、quantity排序并写表头；然后读回检查记录数与数量和。再次运行应覆盖本次结果，不追加重复行。也要验证clean为空时只写表头。
