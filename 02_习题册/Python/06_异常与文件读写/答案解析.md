## I01 · 把坏输入变成可处理结果

```python
def parse_integer(text):
    try:
        return int(text)
    except ValueError:
        return None
print(parse_integer("12"), parse_integer("abc"))
```

## I02 · 转换成功还要检查条件



```python
def positive_quantity(text):
    try:
        value = int(text)
    except ValueError:
        return None
    if value <= 0:
        return None
    return value
print([positive_quantity(x) for x in ["2", "0", "-3", "2.5"]])
```

## I04 · JSON写入后再读回



```python

BASE = Path(__file__).resolve().parent
OUTPUT = BASE / "我的输出"
OUTPUT.mkdir(exist_ok=True)
import json
record = {"姓名": "小林", "分数": [80, 90]}
with open(OUTPUT / "record.json", "w", encoding="utf-8") as file:
    json.dump(record, file, ensure_ascii=False, indent=2)
with open(OUTPUT / "record.json", encoding="utf-8") as file:
    restored = json.load(file)
print(restored == record)
```

## I05 · 读取CSV并处理非法数量



```python
from pathlib import Path
BASE = Path(__file__).resolve().parent
OUTPUT = BASE / "我的输出"
OUTPUT.mkdir(exist_ok=True)
import csv
clean = []
invalid_count = 0
with open(BASE / "练习数据" / "orders.csv", encoding="utf-8", newline="") as file:
    for row in csv.DictReader(file):
        product = row["product"].strip().lower()
        try:
            quantity = int(row["quantity"])
        except ValueError:
            invalid_count += 1
            continue
        if not product or quantity <= 0:
            invalid_count += 1
            continue
        clean.append({"product": product, "quantity": quantity})
print(clean)
print(invalid_count)
```

## I06 · 写CSV并检查结果

读回CSV时quantity再次是字符串，需要转换才求和；w模式覆盖，a模式会追加。

```python
from pathlib import Path
BASE = Path(__file__).resolve().parent
OUTPUT = BASE / "我的输出"
OUTPUT.mkdir(exist_ok=True)
import csv
def save_clean(rows, path):
    with open(path, "w", encoding="utf-8", newline="") as file:
        writer = csv.DictWriter(file, fieldnames=["product", "quantity"])
        writer.writeheader()
        writer.writerows(rows)

clean = [{"product": "pen", "quantity": 2}, {"product": "book", "quantity": 3}]
save_clean(clean, OUTPUT / "clean.csv")
with open(OUTPUT / "clean.csv", encoding="utf-8", newline="") as file:
    read_back = list(csv.DictReader(file))
print(len(read_back), sum(int(row["quantity"]) for row in read_back))
```
