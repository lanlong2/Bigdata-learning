## F01 · 让函数返回一句问候

return把结果交给调用者；print放在调用处。

```python
def greet(name):
    return "你好，" + name
print(greet("小林"))
```

## F05 · 处理空列表



```python
def average(scores):
    if not scores:
        return None
    return sum(scores) / len(scores)
print(average([60, 80, 100]))
```

## F06 · 封装名字清洗

这里不能replace所有空格，题目要求保留中间空格。

```python
def normalize_name(name):
    return name.strip().lower()
print(normalize_name(" Alice Smith \n"))
```

## F07 · 返回一条元组记录

split得到两个字符串，拆包后分别处理，返回一个元组。非法输入留到异常章节。

```python
def parse_record(raw):
    name, score_text = raw.split(",")
    return name.strip(), int(score_text.strip())
print(parse_record(" 小林 , 86 "))
```

## F08 · 让函数相互调用

沿调用顺序追踪结果，平均分函数先判断空列表。

```python
def total(scores):
    return sum(scores)

def average(scores):
    if not scores:
        return None
    return total(scores) / len(scores)

def summarize(scores):
    return total(scores), average(scores)

print(summarize([60, 80]))
```
