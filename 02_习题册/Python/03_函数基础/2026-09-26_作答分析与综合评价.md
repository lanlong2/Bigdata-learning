## 为什么错，以及最小订正

### F01：输出文字也是要求的一部分

把返回表达式改为`"你好，" + name`即可。此题无需改变函数结构。

### F03：先算括号里，再做外层转换

`str(name + ":" + score)`不能自动修复里面的类型错误。保留你的拼接方式，可以写：

```python
def score_label(name, score):
    return name + ":" + str(score)
```

重点是把整数score转换为字符串，而不是把一个已经报错的表达式整体转换。

### F04：没有返回计算结果时，默认得到None

原题中，函数内的print打印5；函数没有return，所以result为None，外面的print打印None。**None表示没有返回一个具体计算结果，不是数字0。**

你的改写已经让result得到5。为了让调用者控制显示，可简化为下面的写法；这是职责更清楚的写法，不是因保留print而额外扣分：

```python
def add(a, b):
    return a + b
result = add(2, 3)
print(result)
```

### F06：两端空白与字母大小写分别处理

保留name_c，改成`name_c = name.strip().lower()`，再`return name_c`。不需要删除中间空格。

### F08：让每个函数负责自己的返回结果

你在F05已经正确处理了空列表，F08重新定义average时漏掉了同样的保护。可保留total及循环写法，只调整这两处：

```python
def average(scores):
    if not scores:
        return None
    sum = 0
    for i in scores:
        sum = sum + i
    return sum / len(scores)

def summarize(scores):
    return (total(scores), average(scores))
```

这样summarize对空和非空输入都调用两个函数，空列表也安全。`sum`、`i`、`p`、`raw1`、`i1`、`p1`等变量名不要求改为参考答案命名；本次按类型、逻辑和结果判断。
