# 函数基础 · 日常习题

共8题，按题练习，不按试卷计分。已学P57～62；每题约5～15分钟，按近期计划分次做。

## F01 · 让函数返回一句问候

定义greet(name)，name为字符串，返回“你好，”与名字拼接后的字符串。调用greet("小林")应得到"你好，小林"；函数内部不要print。

## F02 · 计算总价

定义total_cost(price, quantity)。单价和数量均为非负整数，返回乘积；(8, 3)得到24，数量0得到0。

## F03 · 返回格式化记录

定义score_label(name, score)，name是字符串，score为整数。返回"小林:86"这样的文本，姓名与分数之间是英文冒号，不带空格。

## F04 · 区分打印和返回

先预测下方代码两次输出什么，再改写add(a,b)，使result真正得到相加结果。原代码：

```python
def add(a, b):
    print(a + b)
result = add(2, 3)
print(result)
```

## F05 · 处理空列表

定义average(scores)，输入数字列表；非空返回平均数，空列表返回None。[60,80,100]得到80.0。

## F06 · 封装名字清洗

定义normalize_name(name)：去两端空白并转小写，保留名字中间的空格。" Alice Smith \n"得到"alice smith"。

## F07 · 返回一条元组记录

定义parse_record(raw)。输入保证恰有一个英文逗号，左边是姓名，右边能转为整数。去两端空白，返回(姓名, 分数)。" 小林 , 86 "应得到("小林",86)。

## F08 · 让函数相互调用

定义total(scores)、average(scores)、summarize(scores)。summarize必须调用前两个函数，返回(总分, 平均分)；空列表返回(0,None)。三个函数都不在内部print。
