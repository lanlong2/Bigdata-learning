# 列表 · 习题册使用说明

这是日常习题，按知识点练习，不设试卷总分。本册14道原有习题按薄弱点选做，不要求一次清空。列表推导式不熟时，相关题可先选学。

零基础先完成[列表模块](../../../01_学习笔记/Python/01_列表.md)。A1—A3、B1—B3、C1/C2、D1/D3、D2第1/3小问、E1/E3及E2前7步可按本模块练；去重先用普通循环。D2第2小问等字符串upper学完后做，E2第8步等元组enumerate学完后做，set写法等字典与集合后补。前置以[教材学习顺序](../../../01_学习笔记/Python/README.md)为准。

1. [题目](题目.md)：先确认输入和每个小问。
2. [我的作答](我的作答.py)：在对应题号处写自己的代码或注释。
3. [答案解析](答案解析.md)：尝试后按题订正，保留原答案。
4. 不懂时回到[列表模块](../../../01_学习笔记/Python/01_列表.md)找对应解释；是否收录到错题与疑问由你选题后决定。

## 运行规则

每题独立。先预测的题先在注释里写结果，再单独运行；题目明确按顺序变化时才承接上一行状态。
标记报错的行逐条验证，不能期望程序报错后自动继续。集合顺序不限的题不要机械对比显示顺序。
