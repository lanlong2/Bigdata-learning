## E03与E04

以下示例可保存为`tags_app.py`；输入文件由自己在新练习目录建立：

```python
import json
import logging
from pathlib import Path

BASE_DIR = Path(__file__).resolve().parent


def clean_tags(raw: list[str]) -> list[str]:
    if not isinstance(raw, list):
        raise ValueError("输入必须是列表")
    result: list[str] = []
    for value in raw:
        if not isinstance(value, str):
            raise ValueError("标签必须是字符串")
        tag = value.strip().lower()
        if tag and tag not in result:
            result.append(tag)
    return result


def make_summary(raw: list[str]) -> dict:
    tags = clean_tags(raw)
    return {"input_count": len(raw), "kept_count": len(tags), "tags": tags}


def main() -> int:
    logging.basicConfig(level=logging.INFO, format="%(levelname)s %(message)s")
    input_path = BASE_DIR / "data" / "tags.json"
    output_path = BASE_DIR / "output" / "summary.json"
    try:
        raw = json.loads(input_path.read_text(encoding="utf-8"))
        result = make_summary(raw)
        output_path.parent.mkdir(parents=True, exist_ok=True)
        output_path.write_text(
            json.dumps(result, ensure_ascii=False, indent=2), encoding="utf-8"
        )
    except (OSError, ValueError) as exc:
        logging.error("处理失败：%s", exc)
        return 1
    logging.info("保留 %s 个标签", result["kept_count"])
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

题设数据得到`input_count=6`、`kept_count=3`、`tags=["java", "python", "sql"]`。空列表的两个计数均为0、结果为空列表。无效JSON记录错误，退出码为1；旧报告仍可能存在，所以必须结合本次日志和退出码判断。

## E05

```python
from tags_app import clean_tags, make_summary

assert clean_tags([" Java ", "PYTHON", "java", "", "  ", "SQL"]) == [
    "java", "python", "sql"
]
assert clean_tags([]) == []
assert clean_tags(["a", "a"]) == ["a"]
assert clean_tags(["A", " a "]) == ["a"]
assert make_summary(["A", "a"]) == {
    "input_count": 2, "kept_count": 1, "tags": ["a"]
}

for bad_input in (["A", 100], "Java"):
    try:
        clean_tags(bad_input)
    except ValueError:
        pass
    else:
        raise AssertionError("不符合约定的输入必须失败")

print("全部检查通过")
```

预期输出`全部检查通过`。`assert`可能在优化模式被关闭，正式输入校验应该显式判断并抛出异常。

## E06

```powershell
$env:APP_MODE = "practice"
.\.venv\Scripts\python.exe -c "import os; print(os.getenv('APP_MODE', 'local'))"
Remove-Item Env:APP_MODE
.\.venv\Scripts\python.exe -c "import os; print(os.getenv('APP_MODE', 'local'))"
```

输出依次为`practice`、`local`。密钥泄露可能导致别人使用账号额度；源码、日志和截图均可能传播。Python不会自动读取`.env`，需要明确的读取机制。

排错示例：把输入临时改为`["A", 100]`→日志提示标签必须是字符串，退出码1→原因是第二项类型错误→将其改为`"100"`或删除非法项，按真实业务决定→再次运行应成功。这个示例不代表用户已经完成排错活动。
