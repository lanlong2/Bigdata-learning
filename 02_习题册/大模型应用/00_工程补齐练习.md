## E02 路径与目录

在一个新的练习目录保存`paths.py`，用`Path(__file__).resolve().parent`得到脚本目录，构造脚本旁边的`data/titles.json`和`output/summary.json`路径。

1. 打印这两个文件的文件名，预期分别为`titles.json`、`summary.json`。
2. 创建输出文件的父目录，已存在时也能运行，不覆盖其他文件。
3. 用文字解释：如果终端进入另一个目录再用脚本的完整路径运行，输入路径为何不随终端改变？

这题不要求实际读取尚未创建的输入文件。

## E03 清洗规则与返回结果

独立实现`clean_tags(raw: list[str]) -> list[str]`：输入必须为列表且每项必须为字符串；去掉前后空白，转成小写，丢弃空字符串，按第一次出现顺序去重。输入不符合类型时抛出`ValueError`，消息自定。

| 输入 | 预期结果 |
|---|---|
| `[" Java ", "PYTHON", "java", "", "  ", "SQL"]` | `["java", "python", "sql"]` |
| `[]` | `[]` |
| `["A", 100]` | 抛出`ValueError` |
| `"Java"` | 抛出`ValueError`，不能逐字符清洗 |

提示：`lower()`属于已学字符串操作；本题不要求用集合替代列表。

## E04 组合报告与文件流程

实现`make_summary(raw: list[str]) -> dict`，返回：`input_count`为原条数、`kept_count`为E03处理后条数、`tags`为E03结果。

接着编写完整入口：读取脚本旁`data/tags.json`，生成`output/summary.json`，使用UTF-8与`ensure_ascii=False`。读取、清洗、写出失败时记录错误并以非0退出码退出；成功记录保留条数，退出码为0。被导入时不能执行文件读写。

输入文件使用E03第一组数据，报告应为：

```json
{
  "input_count": 6,
  "kept_count": 3,
  "tags": ["java", "python", "sql"]
}
```

排版缩进可以不同，字段和数据必须一致。再测试空列表和无效JSON，说明失败后若旧输出仍存在，为什么不能用它证明本次成功。

## E05 给规则补检查

单独写`check_tags.py`，导入E03/E04中的函数，不触发文件读写。至少检查：普通输入、空列表、重复项、大小写归一后重复、错误元素类型、错误顶层类型、原输入计数与保留计数。

使用`assert`比较具体结果，错误类型输入要验证确实抛出`ValueError`，不能只打印“通过”。用普通Python运行，不使用关闭断言的`-O`。解释为何不能用断言代替处理用户输入的正式校验。
