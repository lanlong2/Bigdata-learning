## 使用方法

1. 在 DBeaver 的 MySQL 8.4 LTS 连接中按 [00 模块](../../../01_学习笔记/SQL/00_环境与关系表.md)执行一次[重建脚本](../../../01_学习笔记/SQL/练习数据/00_重建练习库.sql)。重跑会删除已存在的 `module07_tasks`，并清空重建 `customers`、`products`、`orders`；执行前确认这些表只存课程数据。随后运行[学习环境验证](../../../01_学习笔记/SQL/练习数据/01_验证学习环境.sql)核对数据库和样例数据。
2. 打开 [题目](题目.md)，只做已经学过的阶段。
3. 将自己的 SQL 写入 [我的作答.sql](我的作答.sql)，每题分开执行并记录自己观察到的结果。
4. 需要核对时再打开 [答案解析](答案解析.md)。可采用不同别名和等价写法，但题目要求的列、条件、排序与功能需满足。

本套是学习练习，不设测验总分；提交检查时按题号说明结果和需要修改的地方。新错题不自动加入 `04_错题与疑问`，只有明确选题后再收录。
