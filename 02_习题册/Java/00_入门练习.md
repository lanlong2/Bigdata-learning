# Java入门练习 V01—V06

前置：[认识Java与第一个程序](../../01_学习笔记/Java/00_认识Java与第一个程序.md)。只使用本节中的编译、运行、输出、变量和计算，不要求输入、判断、循环或自定义方法。**大模型路线结束后再开始Java学习。**

先独立完成，再看[参考答案](00_入门练习_参考答案.md)。这不是用户答卷，也不预填完成状态。每个公共类保存到同名`.java`文件。

## V01 认识环境

1. 解释JDK、JVM、`javac`和`java`分别做什么。
2. 写出查看编译器版本和运行工具版本的命令。
3. 解释为什么`.java`修改后只运行`java`，有时还会看到旧结果。

## V02 预测结果

先不运行，写出以下放在`main`中的语句输出，再编译验证：

```java
System.out.println(9 / 2);
System.out.println(9.0 / 2);
System.out.println("合计：" + 4 + 5);
System.out.println("合计：" + (4 + 5));
```

分别解释整数除法、浮点除法和字符串拼接的作用。

## V03 学习时间卡

新建`WeeklyCard.java`。声明每天学习小时数为1.5（`double`）、每周天数为6（`int`）、统计周数为4（`int`），计算每周和4周总小时数，不把最后结果直接写死。

输出应为：

```text
每周小时：9.0
4周小时：36.0
```

这是时间计算练习，不是实际学习用时记录。

## V04 修复语法与类型

下面准备保存在`FixCard.java`，有多处错误。逐个指出原因，修复后让它输出`计划小时：1.5`。

```java
public class WrongName {
    public static void main(String[] args) {
        int hours = 1.5
        system.out.println("计划小时：" + hours);
    }
}
```

解释每次修复后为什么要重新编译，不要只贴正确版本。

## V05 假设预算计算

新建`BudgetCard.java`。假设总预算为700小时，某个虚构场景已经投入175小时，用整数变量计算还剩多少小时，输出：

```text
剩余小时：525
```

然后只改已投入的变量为250，重新编译，输出应变成450。**这些数字只用于题目，不代表用户已经完成相应学习。**

## V06 从文件到运行

独立建立`HelloBackend.java`，运行后输出两行：

```text
你好，后端开发！
我的第一个Java程序。
```

记录实际执行的编译、运行命令，说明`-encoding UTF-8`和`-cp .`的用途。再回答：如果编译失败但目录里存在旧的`.class`，为什么不能把旧程序的输出当成这次修改成功？

遇到报错先根据文件名、行号、标点和类型定位。合法变量名不用改成示例名称；本套练习无默认总分，阶段测验另行安排。
