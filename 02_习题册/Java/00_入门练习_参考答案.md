# Java入门练习 · 参考答案

对应[题目V01—V06](00_入门练习.md)。示例答案不代表用户作答或完成。输出和逻辑满足要求的其他变量名与实现均可。

## V01

JDK包含编译与运行等开发工具；JVM执行字节码；`javac`编译源码；`java`启动程序。查看版本：

```powershell
javac -version
java -version
```

常规两步运行使用上一次成功编译的`.class`。改源码后不重新编译，或新编译失败时，旧字节码可能还在，运行就不是本次修改的内容。

## V02

```text
4
4.5
合计：45
合计：9
```

两个整数相除舍去本例的小数部分；`9.0`使除法按浮点数执行。字符串参与`+`后进行拼接；加括号先完成数字相加。

## V03

```java
public class WeeklyCard {
    public static void main(String[] args) {
        double dailyHours = 1.5;
        int days = 6;
        int weeks = 4;
        double weeklyHours = dailyHours * days;
        double totalHours = weeklyHours * weeks;
        System.out.println("每周小时：" + weeklyHours);
        System.out.println("4周小时：" + totalHours);
    }
}
```

输出为9.0、36.0，与题设标签一致。总小时通过变量计算，不直接输出固定结果。

## V04

```java
public class FixCard {
    public static void main(String[] args) {
        double hours = 1.5;
        System.out.println("计划小时：" + hours);
    }
}
```

公共类名应与`FixCard.java`一致；`int`不能直接保存1.5，改用`double`；赋值语句缺少英文分号；`System`大小写写错。每次修复后重新编译，才能让新源码生成新的字节码。输出`计划小时：1.5`。

## V05

```java
public class BudgetCard {
    public static void main(String[] args) {
        int targetHours = 700;
        int usedHours = 175;
        int remainingHours = targetHours - usedHours;
        System.out.println("剩余小时：" + remainingHours);
    }
}
```

先输出`剩余小时：525`；把`usedHours`改为250并重新编译后输出`剩余小时：450`。都是假设计算，不写入学习进度。

## V06

```java
public class HelloBackend {
    public static void main(String[] args) {
        System.out.println("你好，后端开发！");
        System.out.println("我的第一个Java程序。");
    }
}
```

```powershell
javac -encoding UTF-8 HelloBackend.java
java -cp . HelloBackend
```

`-encoding UTF-8`指定源码编码；`-cp .`要求从当前目录找类。编译失败意味着本次源码没有成功生成可运行的新字节码，旧文件仍可存在，所以旧输出不能证明本次修改正确。
