# SQL 案例学习

当前阶段：已进入 SQL 学习；本目录案例待学习。案例是完整示范，不计为你的独立练习或项目完成。

先按[SQL 教材入口](../../01_学习笔记/SQL/README.md)学习 00—06，再阅读[订单分析讲解](01_订单分析/案例讲解.md)并执行[示例查询](01_订单分析/示例查询.sql)。可以在学完 04 时先看明细和汇总部分，窗口部分等 06 学完再做。

案例与习题共用[练习数据脚本](../../01_学习笔记/SQL/练习数据/00_重建练习库.sql)，使用 PostgreSQL，始终连接个人练习数据库。

案例重点是先说明每个指标统计哪些行，再写查询和核对结果。后续在[订单查询报告项目](../../05_项目实践/SQL/00_订单查询报告/任务书.md)中自行完成同类任务。
