# 学习计划 · 怎么用

这里告诉你“现在在哪、今天做什么、以后往哪走”。它不放知识讲义和题目。

| 文件 | 什么时候打开 | 你需要填写什么 |
|---|---|---|
| [当前进度](当前进度.md) | 每次开始、结束学习 | 课程位置、已做题号、复测结果、下一步 |
| [9 月 17～30 日安排](2026-09-17至09-30计划.md) | 每天开始前 | 实际完成情况；有变动时补一句原因 |
| [年度路线与验收](年度路线与验收.md) | 每月底 | 阶段产出和是否达到验收条件 |
| [预算与实际记录](预算与实际记录.md) | 收到钱、发生支出、月底 | 真正收到、存下、花出的金额 |
| [学习日志](学习日志.md) | 有值得记录的过程时 | 学会什么、卡在哪里、下一步 |

## 填写规则

- 日期统一写 `2026-09-17`；题号写成“列表 A1”或“前56节试卷 S01”，避免混淆。
- `—` 表示尚未填写或未知，不等于 0。
- 看过、做过、复测通过分别记录；创建了一个文件不表示学会了它。
- 新安排从 9 月 17 日开始，旧日志保留原日期，不补写没有发生过的学习记录。
- 计划变动时改近期安排；不要同时维护两份相互冲突的“今天任务”。
