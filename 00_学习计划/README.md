# 学习计划 · 怎么用

**2026-09-26已按真实作答重整。** 旧日期计划已删除，当前只保留一份近期执行安排。

| 文件 | 用途 |
|---|---|
| [当前进度](当前进度.md) | 全部材料的最新状态；区分观看、提交、订正与复测 |
| [近期执行计划](近期执行计划.md) | 下次第一件事、随后任务、推进条件和建议用时 |
| [年度路线与验收](年度路线与验收.md) | 数据方向的阶段产出与优先级，每月底调整 |
| [学习日志](学习日志.md) | 实际发生的学习过程，保留日期，不堆叠旧日程 |
| [预算与实际记录](预算与实际记录.md) | 计划金额与真实收支分别记录 |

阶段判断和阶段历史见[07](../07_学习阶段与下一步/README.md)。题目分析放对应目录，04只由你指定选题后维护。

更新规则：你明确说已完成、已修正、已学完、已达标或报告用时，就直接作为事实写入，无需验证，也不附加待核实条件。日期写你提供的实际学习日；未提供的日期、时间或完成方式留为“未记录”，不影响已经确认的完成状态。不同活动按你说明的范围分别记录；计划改变时直接改当前安排，不追加第二份“今天任务”。具体AI规则见[AGENTS.md](../AGENTS.md#ai记录学习事实的规则)。
