| 文件 | 用途 |
|---|---|
| [当前进度](当前进度.md) | 全部材料的最新状态；区分观看、提交、订正与复测 |
| [近期执行计划](近期执行计划.md) | 下次第一件事、随后任务、推进条件和建议用时 |
| [年度路线与验收](年度路线与验收.md) | 数据方向的阶段产出与优先级，每月底调整 |

阶段判断和阶段历史见[07](../07_学习阶段与下一步/README.md)。题目分析放对应目录，04只由你指定选题后维护。

更新规则：日期写实际学习日；没有提供的时间或完成方式填“未记录”；看过、写过、订正正确和独立复测通过分别记录。新安排不等于已完成；计划改变时直接改当前安排，不追加第二份“今天任务”。
