# SQL近期执行计划 · A00共用基础

**每天90分钟、每周6次。SQL主预算35小时，覆盖原00—07完整教程与配套Q/J练习。** 时间是建议分配，实际学习和用时分别记；没有新增完成记录。

## 下一次第一件事

打开[00 环境与关系表](../../01_学习笔记/SQL/00_环境与关系表.md)，复用本机MySQL 8.4 LTS与DBeaver环境，阅读实际连接说明；未准备课程数据时按模块使用[00_重建练习库.sql](../../01_学习笔记/SQL/练习数据/00_重建练习库.sql)。脚本会清空并重建指定课程表，先读范围，在专用库执行。每个查询窗口先`USE sql_learning;`，再执行`SELECT 1;`，认识表、行、列与主键。

前10分钟确认入口与连接，中间约60分钟完成一个小范围，最后约20分钟核对、解释并保存查询和下次入口。按实际进展续做，不强行要求首个90分钟学完环境模块。
