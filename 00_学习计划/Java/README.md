# Java后端学习计划

**主要就业路线：Java后端实习。** 在大模型应用路线核心成果收尾后开始，主预算450小时；额外巩固从75小时总池调配，示例Java使用60小时。目标在2028年4月底前形成较充分的常规Java后端实习技术准备。

当前尚未开始，不把新教材、练习或任务书生成记为已学习。已有SQL与共用工程知识在本阶段复用，Java语言本身从零学。
