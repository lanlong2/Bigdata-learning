# Java后端近期执行计划

**当前暂不启动，先完成大模型应用整条路线。** 本页描述未来进入Java后的执行顺序，不要求现在同时学习两种语言。

## 开始Java时的第一步

读[Java教材入口](../../01_学习笔记/Java/README.md)，按入口选择兼容学习环境并运行第一个Java程序。保留原Python与SQL环境，不重新收费已完成的基础；使用现有Git保存真实练习。每次90分钟：明确一个目标、自己编写与运行、检查边界并记录下次入口。

## 串行推进

| 顺序 | 主要任务 | 结束时应有的成果 |
|---|---|---|
| J00 | Java语法与面向对象，95小时 | 独立小程序及对象协作练习，能解释类型、方法与状态 |
| J01 | 集合／IO／异常／并发／JVM，55小时 | 容器选择、资源与异常练习，以及线程安全和JVM基础解释 |
| J02 | 算法／网络／操作系统，60小时 | Java算法实作、复杂度说明与网络系统基础 |
| J03 | 数据库工程与JDBC，45小时 | Java访问MySQL，表设计、索引、事务及并发修改练习 |
| J04 | Maven／Spring Boot／MyBatis，75小时 | 有校验、权限、事务、错误、日志与测试的小业务后端 |
| J05 | Redis与工程，20小时 | 明确场景下的缓存与运行维护练习 |
| J06 | 独立业务项目，100小时 | 工单业务核心链路、边界、测试、部署、排错与个人说明 |

练习入口见[Java习题](../../02_习题册/Java/README.md)，项目范围见[工单后端任务书](../../05_项目实践/Java/00_工单管理后端/任务书.md)。J02以后可在本阶段复习已学算法，不另开新就业路线。

额外巩固使用75小时总池中的剩余部分，示例60小时；先补实际卡点，不临时扩展微服务全家桶或堆砌项目。正式简历、投递、模拟及正式面试活动不占本计划，但相关技术学习、项目解释与排错计入。
