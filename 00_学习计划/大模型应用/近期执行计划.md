# 大模型应用近期执行计划

每天90分钟、每周6次；当前只推进A00 SQL／MySQL，不同时学习Java或新AI框架。

## 当前第一步

从[SQL00 环境与关系表](../../01_学习笔记/SQL/00_环境与关系表.md)开始，复用本机MySQL 8.4 LTS与DBeaver连接。首次课程数据初始化按00模块使用专用脚本，之后查询先`USE sql_learning;`再`SELECT 1;`。具体次序与35小时分配见[SQL近期计划](../SQL/近期执行计划.md)。

A00按原教程完成00—07、Q01—Q12、J01—J12，保存并解释自己的SQL。订单报告与基础测验作为可选巩固；旧Python卷与清洗项目历史建议不作为本阶段前置。

## 后续仅按以下顺序解锁

| 前一步完成后 | 下一主要任务 | 先做的小范围练习 |
|---|---|---|
| A00后 | A01 Python工程补齐 | 独立建立虚拟环境、依赖与简单测试，补面向对象所需概念 |
| A01后 | A02 HTTP／FastAPI | 先写能校验输入并返回错误的接口，再接数据库 |
| A02后 | A03 模型API | 先用小样例核对正常与失败结果，不批量调用 |
| A03后 | A04 RAG与评测 | 固定一小组资料和问题，记录基线后再改进 |
| A04后 | A05 独立应用 | 按任务书完成链路、异常、评测、复现与说明 |
| A05核心完成后 | 必要返修，然后进入Java | 从75小时总池调配，示例15小时；达基础即可投递匹配岗位 |

每次只推进一个可解释成果，末尾记清正常结果、异常分支、卡点与下次入口。基础练习不让AI代写；复杂项目可部分使用AI，但自己负责理解、测试和维护。
